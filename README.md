# NEBians

NEBians is a native Android app for Nepali students with categorized learning resources, offline PDF caching, local PDF annotations, a minimalist discussion forum, announcements, notifications, and Material 3 UI.

## Build

```bash
./gradlew :app:assembleMinApi23Release :app:assembleMinApi26Release
```

The release builds are signed with the default repository keystore requested for this project.
