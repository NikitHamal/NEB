JSON format reference

The JSON must be an array of objects (or a single object). Each object represents one chapter:

[
  {
    "grade_level": "Class 12",
    "subject": "Physics",
    "chapter_title": "Chapter 1: Mechanics",
    "chapter_id": "class-12-physics-mechanics",
    "text_content": "## Overview\n\nMechanics is the branch of physics...\n\n### Key Topics\n\n- Newton's Laws\n- Kinematics\n- Dynamics",
    "question_answers": "Q: What is Newton's First Law?\nA: An object at rest stays at rest...",
    "rich_content": {"version": 1, "blocks": []},
    "source_label": "Source notes.pdf",
    "source_resource_id": "",
    "order": 1
  },
  {
    "grade_level": "Class 12",
    "subject": "Physics",
    "chapter_title": "Chapter 2: Heat and Thermodynamics",
    "chapter_id": "class-12-physics-heat",
    "text_content": "## Heat\n\nHeat is a form of energy...",
    "question_answers": "",
    "order": 2
  }
]

Required Fields

  • grade_level — e.g. "Class 11", "Class 12"
  • subject — e.g. "Physics", "English"
  • chapter_title — e.g. "Chapter 1: Mechanics"

Optional Fields

  • chapter_id — URL slug (auto-generated from title if omitted)
  • text_content — Markdown guide/summary
  • question_answers — Q: / A: format text
  • rich_content — structured formula/diagram/interactive blocks
  • source_label / source_resource_id — trace back to the Library PDF
  • order — Sort order (default: 0)
tips_and_updates Tips for AI-generated JSON
  • Use \n for line breaks in text_content and question_answers
  • Markdown is supported in text_content (headings, bold, lists, code blocks)
  • Q&A format: start each question with Q: and each answer with A:, separate blocks with blank lines
  • Valid grade_level values: Class 8, Class 9, Class 10 / SEE, Class 11, Class 12, Diploma, Bachelor, Master, PhD, Entrance Prep, Competitive Exam, Other
  • Set order to control chapter sequence within a subject (1, 2, 3...)
  • Leave question_answers as "" if there are no Q&As for that chapter
