info How it works

  1. Connect GitHub — Authorize with GitHub OAuth (repo scope) to allow the agent to clone, push, and create PRs.
  2. Create a Project — Link a GitHub repository. The agent will clone it to a server-side workspace.
  3. Start a Task — Describe what you want the agent to do. It creates its own branch (never touches main).
  4. Agent Works — The AI explores the codebase, writes code, runs tests, and iterates until the goal is achieved. This runs in the background — you can close the browser.
  5. Review & Merge — Download changes as ZIP, push to GitHub manually, or let the agent open a PR automatically.

AI Providers: Uses the existing Neby AI providers (AI4Bharat Arena, Qwen, DeepAI) with prompt-based tool calling — no native function-call support needed. The agent uses a structured JSON output format that works with any LLM.

Worker: Run python manage.py run_coding_agent_worker as a background process to process tasks. Tasks persist in the database and survive server restarts.
