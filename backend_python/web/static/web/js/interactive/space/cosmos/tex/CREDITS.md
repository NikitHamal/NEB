# Textures and data for the Scale of the Universe sim

- `earth_day_*.jpg`: NASA Visible Earth, Blue Marble Next Generation (world.topo.bathy.200412), public domain.
- `earth_night_2k.jpg`: NASA Earth Observatory, Black Marble 2016, public domain.
- `earth_clouds_2k.jpg`: NASA Visible Earth, cloud_combined_2048, public domain.
- `moon_2k.jpg`: NASA Scientific Visualization Studio, CGI Moon Kit (LRO LROC colour mosaic), public domain.
- `dem_everest_26km.png`, `dem_himalaya_345km.png`: elevation from the AWS Terrain Tiles open dataset (Mapzen Terrarium; SRTM and other public sources), resampled and stored as 16-bit height (R = high byte, G = low byte, 0–8 900 m).
