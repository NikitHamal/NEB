# NEBians Landing Revision

This revision keeps the existing home-page sections and interaction patterns intact while replacing only the landing hero and the home-page topbar presentation.

## Changes

- Removed the "Built for learners across Nepal" eyebrow.
- Replaced the oversized hero with a shorter community-focused message.
- Removed the fabricated dashboard and all floating labels.
- Added a compact preview that renders real resources and a real community discussion from the current page context.
- Removed the three-card feature strip introduced in the previous pass.
- Restored news, resources, discussions, cards, spacing, and content styling to the supplied original backend.
- Removed lift and bounce effects from the new hero.
- Reduced shadows to subtle borders and low-elevation treatment.
- Added a home-only topbar state: compact centered pill at the top of the page, then the original full-width sticky bar after scrolling.

No backend models, migrations, view logic, APIs, authentication, or non-home page styles were changed.
