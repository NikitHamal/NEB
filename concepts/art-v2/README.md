# NEBians M3X Art Library v2 (`NEBians-Art-v2.html`, GitHub Pages: `art-v2.html`)

Next-generation deterministic flat-tonal vector art engine built for the entire NEBians web & Android platform, advancing beyond both the legacy 2D pixel art and the initial M3X Art Library v1 (`concepts/art/`).

## Why V2 is a Major Leap Over V1
1. **39 Scene & Architectural Engines (vs. V1's 18 abstract patterns)**:
   - **20 Handcrafted Domain Scenes** (`v2-scenes-sci.js`, `v2-scenes-hum.js`): Optical prisms dispersing spectrum bands (`physicsOptics`), solenoid dipole fields (`physicsFields`), volumetric Erlenmeyer flasks & hexagonal benzene lattices (`chemistryLab`), twisted DNA double-helix ladders (`biologyHelix`), Fibonacci spirals & Riemann step integrals (`mathFibonacci`), polar rose curves (`mathHarmonic`), framed terminal windows & binary trees (`csArchitecture`), ringed Saturnian planets (`astronomyCosmos`), 30-degree isometric book-N solids (`engineeringIso`), ECG PQRST traces (`medicineVital`), layered Machhapuchhre / Everest ridgelines (`nepalHimalaya`), campus colonnade courtyards (`campusCourtyard`), supply-demand equilibrium ledgers (`economicsLedger`), double-entry balance sheets (`accountancyBalance`), open editorial books (`literatureEditorial`), heritage pagodas (`historyMonument`), civic scales (`lawCivic`), topographic globes (`geographyAtlas`), acoustic staves (`musicAcoustics`), and botanical terraces (`agricultureBotany`).
   - **14 M3 Expressive Architectural & Swiss Poster Compositions** (`v2-layouts-m3x.js`): `isoMonolith`, `expressiveTotem`, `swissGrid`, `contourTopography`, `bauhausChronicle`, `kineticRibbons`, `orbitalResonance`, `stainedMosaic`, `horizonTerrace`, `prismFacets`, `botanicalGrove`, `waveformHarmonic`, `archwayCloister`, and `radialMandala`.
   - **5 Role-Tailored Profile Cover Generators** (`v2-layouts-ui.js`): `roleStudent`, `roleTeacher`, `roleInstitution`, `roleContributor`, and `roleAdmin`.
2. **8-Tone M3X Harmonic Palette Ramp (16 Families, Light + Neutral Graphite Dark `#121318`)**:
   - Strictly zero gradients, zero shadows, zero purple, zero emojis, zero pixel art.
3. **1,116 Deterministic Named Pieces Across 12 UI Categories**:
   - `cover` (220), `school` (96), `thumb` (240), `book` (120), `lab` (60), `pathway` (60), `post` (72), `bg` (60), `tile` (60), `spot` (36), `sticker` (48), `glyph` (36).
4. **4 Interactive Modes in `NEBians-Art-v2.html`**:
   - **Library**: Search & filter all 1,116 pieces across 12 categories.
   - **In-App Preview**: See V2 art live inside Profile v3 headers, site Resource cards, and 3D Interactive Lab cards.
   - **Custom Studio**: Real-time procedural scene, palette & seed builder with Light/Dark preview and SVG/2x PNG export.
   - **V1 vs V2 Compare**: Side-by-side visual diff against V1 (`concepts/art/`).
