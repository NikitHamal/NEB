# Class 12 Computer Science lesson scripts

Shared helpers live in `_cs.py`, which reuses the Mathematics helpers (`worked`, `head`, `bullets`, `reveal_list`, `table`,
`reveal_table`, `neby_in/out`) and adds computing props: `code` (a syntax-coloured code panel in JetBrains Mono for SQL, C,
C++, JavaScript and PHP, with `.lines` and `.box`), `type_code` (types a panel line by line), `dbtable` (a database table
with primary and foreign keys marked), `terminal`, `output`, `browser` (a browser window whose `.area` moves with it),
`node` and `packet`. Minutes are narration length; `python3 tools/lessons/ttskeys.py <script>` lists the narration cache
files a unit uses, so each unit is pushed with only its own audio. Each pushed unit has been checked part by part with
frames.py.

| Unit | Title | Narration | Parts |
|---|---|---|---|
| 1 | Database Management System | 10.9 min | cold open (an office and an exam-section spreadsheet drift apart over one Bhaktapur address), 7 parts (data vs information, the five DBMS components, the three-level architecture and data independence, file system vs DBMS; fields, records, keys; DDL, SELECT … WHERE on a live table, the rest of DML; JOIN, GROUP BY / HAVING, a foreign-key error; data models and an E-R diagram; normalisation UNF → 1NF → 2NF → 3NF with update anomalies; centralised vs distributed databases, security and GRANT), 2 quizzes, recap |
| 2 | Data Communication and Networking | 9.6 min | cold open (a packet's path from Pokhara to a server), 7 parts (five elements of communication, the block diagram with noise; analogue/digital, simplex/half/full duplex, guided and unguided media; attenuation, distortion and noise; LAN/MAN/WAN, client–server vs peer-to-peer, hub vs switch, network devices; bus/star/ring/mesh topologies with the n(n−1)/2 cable count; OSI encapsulation and the seven layers; IPv4 in binary, classes, a /26 subnet, MAC vs IP), 2 quizzes, recap |
| 3 | Web Technology II | 8.0 min | cold open (a browser asks a server for a page), 7 parts (client- vs server-side scripting, URL and DNS steps; JavaScript types, == vs ===, a for-loop trace, control structures, a multiplication table; objects, events, form validation, jQuery; the XAMPP stack and PHP syntax; PHP classes, + vs .; five steps to MySQL, a result set as an HTML table, SQL injection and prepared statements), 2 quizzes, recap |
| 4 | Programming in C | 6.7 min | cold open (the swap function that swaps nothing), 6 parts (prototype, call and definition; auto vs static counters, the storage-class table; recursion as a stack of factorial(4) calls; structure memory as a 40-byte bar, the union overlay; pointers, call by value vs reference, pointer arithmetic; a file's life cycle and modes, file functions, fseek offsets), 2 quizzes, recap |

| 7 | Recent Trends in Technology | 11.5 min | cold open (a dry field in Jhapa: sensor → gateway → cloud → AI → app), 6 parts (AI ⊇ machine learning ⊇ deep learning ⊇ generative AI with milestones, narrow/general/super AI, a robot's sensor–controller–actuator loop, robot types; cloud's five NIST characteristics, a who-manages-what grid for on-premises/IaaS/PaaS/SaaS, deployment models, own server vs cloud cost; the five Vs, data created worldwide in zettabytes, a flood-sensor network's data rate; the VR loop under 20 ms, the real–AR–MR–VR line, uses, a headset's 20 Gbit/s; B2B/B2C/C2C/C2B, telemedicine for Humla, G2C/G2B/G2G/G2E; mobile generations on a log scale, 4G vs 5G download, the four IoT layers, why IoT needs IPv6), 2 quizzes, recap |
