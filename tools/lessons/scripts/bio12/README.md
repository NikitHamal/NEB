# Class 12 Biology lesson scripts

Shared drawing helpers live in `_bio.py`: one colour per tissue (xylem sky, phloem pink, cambium amber, cork brown,
sclerenchyma salmon, collenchyma lime, parenchyma mint), tissue patches (`parenchyma`, `collenchyma` angular/lamellar/lacunar,
`sclerenchyma`, `meristem`, `fibre`, `sclereid`), conducting elements (`vessel` annular/spiral/scalariform/reticulate/pitted,
`tracheid`, `sieve_tube`), transverse sections built from real cell geometry (`RootTS`, `DicotStemTS`, `MonocotStemTS`,
`DicotLeafTS`, `MonocotLeafTS`, `mono_bundle`), `Flow` (dots carried along a path), and `Captions` — a single caption slot
where each new caption replaces the last, so running commentary never piles up. `_phys2.py` adds physiology helpers
(guard cells, bending shoots, Mimosa, tally board). Minutes are narration length from prefetch.py. Each pushed unit has been
checked part by part with frames.py.
