# Class 12 English lesson scripts

Shared helpers live in `_en.py`, which reuses the Mathematics/Biology helpers (`head`, `bullets`, `reveal_list`, `table`,
`reveal_table`, `neby_in/out`) and adds literature props: `quote` (a short quotation card), `card` (titled text card),
`timeline`, `house` and `fence`, `chip`, `arc_curve` (an emotion/plot curve on axes), `device_slide` (device | example |
effect table) and `transform_strip` (before → after for the grammar units). The literature lessons summarise and analyse
each text — plot, characters, themes, structure, devices, exam tips — and quote only short lines; they never reproduce the
text. Minutes are narration length; `python3 tools/lessons/ttskeys.py <script>` lists the narration cache files a unit
uses. Each pushed unit has been checked part by part with frames.py.
