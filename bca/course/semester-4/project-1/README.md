# Project I — BCA 256

Semester IV · 2 credits · a project course. TU does not publish a unit-wise syllabus for it, so this book is a **companion handbook**: it walks one small system, **CampusShelf** (a college library book-issue system), through every phase from idea to viva, so that you can repeat the same steps on your own project.

| Unit | Title |
|---|---|
| 1 | Choosing, Scoping and Justifying a Project |
| 2 | Planning, Teamwork and Version Control |
| 3 | Analysis and Design: Requirements, DFD, ER and Screens |
| 4 | Building and Testing: Code, Test Cases and Defects |
| 5 | The Report, the Presentation and the Viva |

## Verification

Every program in this book was run and the printed output pasted from the real run (Python 3 with the standard `sqlite3` and `unittest` modules). Schedule and score figures were computed by those scripts.

## Source and honesty

**The unit structure is reconstructed.** BCA 256 has no published topic list; colleges set their own proposal and report format. The report structure in Unit 5 follows the common TU project-report pattern (preliminary pages, introduction, requirement analysis and feasibility, system design, implementation and testing, conclusion, references, appendices). **Always follow your own college's project guidelines and your supervisor's instructions first**; where they differ from this book, they win. CampusShelf is an invented teaching example, not a real college's system. Nothing here has had a subject-teacher review.
