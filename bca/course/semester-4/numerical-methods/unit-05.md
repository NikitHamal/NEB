How fast does a cup of tea cool, how does a population grow, how does a capacitor discharge, where does a rocket go? Each is a differential equation, and most have no closed-form solution. The methods here march forward in small steps from a known starting point, using the equation itself to estimate the slope.

## 5.1 Initial value problems

An **initial value problem (IVP)** asks for $y (x)$ satisfying **$y' = f (x ,\  y) ,\  y (x_{0}) = y_{0}$**. The running example of this unit is

**$y' = x + y ,\  y (0) = 1$**, whose exact solution is $y = 2 e^{x} - x - 1$ (so $y (0.5) = 1.797443$).

We want approximate values $y_{i} \approx y (x_{i})$ at $x_{i} = x_{0}$ + ih. A method is **single-step** if $y_{i+1}$ is computed from $y_{i}$ alone (Euler, Runge–Kutta) and **multistep** if it also uses earlier values (Adams). The **local truncation error** is the error made in one step; the **global error** is the accumulated error after many steps, typically one power of *h* *lower* in order. A method of **order *p*** has global error $O (h^{p})$.

## 5.2 Taylor series method

Differentiate the equation repeatedly and evaluate at $x_{0}$: $y (x) = y_{0} + (x - x_{0}) y'_{0} + \frac{(x - x_{0})^{2}}{2 !} y''_{0} + \ldots$

For $y' = x + y ,\  y (0) = 1$: $y' (0) = 0 + 1 = 1 ;\  y'' = 1 + y'$ so $y'' (0) = 2 ;\  y''' = y'' = 2 ;\  y'''' = 2$. Hence

$$y (x) = 1 + x + x^{2} + \frac{x^{3}}{3} + \frac{x^{4}}{12} + \ldots$$

At $x = 0.1$ four terms give $y (0.1) \approx 1.110342$ (the true value agrees to six decimals). At $x = 0.5$ the same polynomial gives 1.796875, error 0.000568; the error grows as *x* moves away from 0, so for long intervals the series is used step by step, re-expanding at each new point. The drawback is that higher derivatives of $f (x ,\  y)$ are tedious to obtain, which is why Runge–Kutta methods were invented.

## 5.3 Picard's method

Write the IVP as the integral equation $y (x) = y_{0} + \int_{x0}^{x} f (t ,\  y (t)) \,d t$ and iterate: **$y_{n+1} (x) = y_{0} + \int f (t ,\  y_{n} (t)) \,d t$**, starting from $y_{0} (x) = y_{0}$.

For $y' = x + y ,\  y (0) = 1$:

- $y_{1} = 1 + \int_{0}^{x} (t + 1) \,d t = \frac{x^{2}}{2} + x + 1$
- $y_{2} = 1 + \int_{0}^{x} (t + y_{1} (t)) \,d t = \frac{x^{3}}{6} + x^{2} + x + 1$
- $y_{3} = \frac{x^{4}}{24} + \frac{x^{3}}{3} + x^{2} + x + 1$

Each iteration adds one more correct term of the series $1 + x + x^{2} + \frac{x^{3}}{3} + \frac{x^{4}}{12} + \ldots$ At $x = 0.5 ,\  y_{3} = 1.794271$ against the true 1.797443. Picard iteration proves existence and uniqueness of solutions (under a Lipschitz condition) but is practical only when the integrals can be done analytically.

## 5.4 Euler's method

Follow the tangent for one step: **$y_{i+1} = y_{i} + h \cdot f (x_{i} ,\  y_{i})$**. This is the first two terms of the Taylor series.

::: example Euler, y′ = x + y, y(0) = 1, h = 0.1
| *i* | $x_{i}$ | $y_{i}$ | $f (x_{i} ,\  y_{i})$ | $y_{i+1}$ | exact $y (x_{i+1})$ | error |

|---|---|---|---|---|---|---|

| 0 | 0.0 | 1.000000 | 1.000000 | 1.100000 | 1.110342 | 0.010342 |

| 1 | 0.1 | 1.100000 | 1.200000 | 1.220000 | 1.242806 | 0.022806 |

| 2 | 0.2 | 1.220000 | 1.420000 | 1.362000 | 1.399718 | 0.037718 |

| 3 | 0.3 | 1.362000 | 1.662000 | 1.528200 | 1.583649 | 0.055449 |

| 4 | 0.4 | 1.528200 | 1.928200 | 1.721020 | 1.797443 | 0.076423 |

At $x = 0.5$ Euler gives 1.721020, the exact value is 1.797443, and the error is 0.076423 (4.3 %). The numerical solution lags behind because the true curve bends upward (convex) and every tangent underestimates it.
:::

**Accuracy.** The local error is $O (h^{2})$ (the first dropped Taylor term, $\frac{h^{2} y''}{2}$) but errors accumulate over $\frac{1}{h}$ steps, so the **global error is $O (h)$**: halving *h* halves the error, as the table of Section 5.6 shows. Euler's method is simple but needs very small steps.

## 5.5 Heun's (improved Euler) method

Euler uses the slope at the start of the step only. Heun averages the slope at both ends, using Euler to *predict* the end value:

**$y \ast = y_{i} + h f (x_{i} ,\  y_{i})$** (predictor), **$y_{i+1} = y_{i} + \left( \frac{h}{2} \right) [f (x_{i} ,\  y_{i}) + f (x_{i+1} ,\  y \ast)]$** (corrector).

It is the trapezoidal rule applied to the equation, a second-order method with global error $O (h^{2})$.

::: example Heun, same problem, h = 0.1
| *i* | $x_{i}$ | $y_{i}$ | predictor $y \ast$ | corrector $y_{i+1}$ | exact |

|---|---|---|---|---|---|

| 0 | 0.0 | 1.000000 | 1.100000 | 1.110000 | 1.110342 |

| 1 | 0.1 | 1.110000 | 1.231000 | 1.242050 | 1.242806 |

| 2 | 0.2 | 1.242050 | 1.386255 | 1.398465 | 1.399718 |

| 3 | 0.3 | 1.398465 | 1.568312 | 1.581804 | 1.583649 |

| 4 | 0.4 | 1.581804 | 1.779985 | 1.794894 | 1.797443 |

At $x = 0.5$, Heun gives 1.794894 with error 0.002549, about 30 times smaller than Euler's error for the same step.
:::

## 5.6 Runge–Kutta methods

Runge–Kutta (RK) methods match the Taylor series to a given order *without* computing derivatives of *f*, by sampling *f* at several points inside the step.

**RK2 (midpoint/Heun family):** $k_{1} = f (x_{i} ,\  y_{i}) ,\  k_{2} = f (x_{i} + h ,\  y_{i} + h k_{1}) ,\  y_{i+1} = y_{i} + \left( \frac{h}{2} \right) (k_{1} + k_{2})$: this is Heun's method.

**Classical RK4** (fourth order, the standard choice):

- $k_{1} = f (x_{i} ,\  y_{i})$
- $k_{2} = f \left( x_{i} + \frac{h}{2} ,\  y_{i} + \frac{h k_{1}}{2} \right)$
- $k_{3} = f \left( x_{i} + \frac{h}{2} ,\  y_{i} + \frac{h k_{2}}{2} \right)$
- $k_{4} = f (x_{i} + h ,\  y_{i} + h k_{3})$
- **$y_{i+1} = y_{i} + \left( \frac{h}{6} \right) (k_{1} + 2 k_{2} + 2 k_{3} + k_{4})$**

It is a Simpson-like weighting: the midpoint slopes count double. Local error $O (h^{5})$, global $O (h^{4})$, at the cost of four evaluations of *f* per step.

::: example RK4, y′ = x + y, y(0) = 1, h = 0.1
First step by hand: $k_{1} = f (0 ,\  1) = 1 ;\  k_{2} = f (0.05 ,\  1.05) = 1.1 ;\  k_{3} = f (0.05 ,\  1.055) = 1.105 ;\  k_{4} = f (0.1 ,\  1.1105) = 1.2105$. The computer gives (1.000000, 1.100000, 1.105000, 1.210500), so $y_{1} = 1 + (0.1 / 6) (1 + 2.2 + 2.21 + 1.2105) = 1.110342$.

| *i* | $x_{i}$ | $y_{i}$ | $k_{1}$ | $k_{2}$ | $k_{3}$ | $k_{4}$ | $y_{i+1}$ | exact |

|---|---|---|---|---|---|---|---|---|

| 0 | 0.0 | 1.000000 | 1.000000 | 1.100000 | 1.105000 | 1.210500 | 1.110342 | 1.110342 |

| 1 | 0.1 | 1.110342 | 1.210342 | 1.320859 | 1.326385 | 1.442980 | 1.242805 | 1.242806 |

| 2 | 0.2 | 1.242805 | 1.442805 | 1.564945 | 1.571052 | 1.699910 | 1.399717 | 1.399718 |

| 3 | 0.3 | 1.399717 | 1.699717 | 1.834703 | 1.841452 | 1.983862 | 1.583648 | 1.583649 |

| 4 | 0.4 | 1.583648 | 1.983648 | 2.132831 | 2.140290 | 2.297677 | 1.797441 | 1.797443 |

At $x = 0.5$, RK4 gives 1.797441; the exact value is 1.797443; the error is only **1.26e-06**, with five steps.
:::

### Order of accuracy, confirmed

Error at $x = 0.5$ as the step is halved:

| *h* | Euler error | Heun error | RK4 error |
|---|---|---|---|
| 0.1 | 7.64e-02 | 2.55e-03 | 1.26e-06 |
| 0.05 | 3.97e-02 | 6.62e-04 | 8.24e-08 |
| 0.025 | 2.02e-02 | 1.69e-04 | 5.26e-09 |

Ratios of error(h = 0.1) / error(h = 0.05): Euler 1.93, Heun 3.85, RK4 15.35. These are close to 2 = 2¹, $4 = 2^{2} ,\  16 = 2^{4}$: the orders 1, 2 and 4. RK4 with $h = 0.1$ beats Euler even with $h = 0.025$ by a factor of thousands, although each step costs four times as much.

**Step-size control.** Practical solvers (RK45, ode45, SciPy's `solve_ivp`) compare a fourth- and a fifth-order estimate and adapt *h* to keep the difference below a tolerance. **Stiff** problems (components decaying at very different rates) need implicit methods because explicit ones need tiny steps for stability.

## 5.7 Higher-order equations and systems

A differential equation of order $\ast n \ast$ converts to $\ast n \ast$ first-order equations. For $y'' = g (x ,\  y ,\  y')$ put $z = y'$:

**$y' = z ,\  z' = g (x ,\  y ,\  z)$**, with $y (x_{0})$ and $z (x_{0}) = y' (x_{0})$ given.

The RK4 formulas are then applied to the *vector* $(y ,\  z)$: compute $k_{1} \ldots k_{4}$ for each component using the current values of both.

::: example y″ = −y, y(0) = 0, y′(0) = 1 (exact solution y = sin x, z = cos x), RK4, h = 0.1
Writing $y' = z ,\  z' = - y$. After the first step $(y ,\  z) = (0.099833 ,\  0.995004)$.

| *x* | *y* (RK4) | $\sin x$ | $z = y'$ (RK4) | $\cos x$ |

|---|---|---|---|---|

| 0.1 | 0.099833 | 0.099833 | 0.995004 | 0.995004 |

| 0.2 | 0.198669 | 0.198669 | 0.980067 | 0.980067 |

| 0.3 | 0.295520 | 0.295520 | 0.955337 | 0.955336 |

| 0.4 | 0.389418 | 0.389418 | 0.921061 | 0.921061 |

| 0.5 | 0.479425 | 0.479426 | 0.877583 | 0.877583 |

The five steps reproduce $\sin x$ and $\cos x$ to about six decimals (differences appear in the sixth decimal only), although we used no trigonometry in the method.
:::

## 5.8 Boundary value problems and the shooting method

In a **boundary value problem (BVP)** the conditions are given at *two* points, such as $y (a) = \alpha$ and $y (b) = \beta$, so we cannot simply march from a known start. The **shooting method** guesses the missing initial slope $s = y' (a)$, integrates the IVP to $x = b$ (using RK4), and compares $y (b)$ with the target *β*. Treat the miss, $\varphi (s) = y (b ;\  s) - \beta$, as a function of *s* and find its root by the secant or bisection methods of Unit 1. For a **linear** BVP *φ* is linear in *s*, so two shots and linear interpolation suffice.

**Algorithm.** (1) Choose two trial slopes $s_{1} ,\  s_{2}$. (2) Integrate to get $y (b ;\  s_{1}) ,\  y (b ;\  s_{2})$. (3) Interpolate: $s_{3} = s_{1} + \frac{(\beta - y_{1}) (s_{2} - s_{1})}{(y_{2} - y_{1})}$. (4) Integrate once more with $s_{3}$ and check $y (b) = \beta$. (For a nonlinear BVP, repeat with the secant formula until $|y (b) - \beta|$ is small.)

::: example y″ = y, y(0) = 0, y(1) = 2
Convert to $y' = z ,\  z' = y$ with $z (0) = s$. Shoot with RK4 $(h = 0.1)$:

| trial | slope $s = y' (0)$ | $y (1)$ by RK4 | target |

|---|---|---|---|

| 1 | 1.0000 | 1.175200 | 2 |

| 2 | 2.0000 | 2.350400 | 2 |

| 3 | 1.701838 | 2.000000 | 2 |

Linear interpolation gives $s_{3}$ = **1.701838**; the exact slope is $\frac{2}{\sinh 1} = 1.701836$, and the third shot hits $y (1) = 2.000000$. The midpoint value $y (0.5)$ from this slope is 0.886819 against the exact 2 $\frac{\sinh (0.5)}{\sinh (1)} = 0.886819$.
:::

An alternative is the **finite-difference method**, which replaces $y''$ by $\frac{y_{i-1} - 2 y_{i} + y_{i+1}}{h^{2}}$ and solves the resulting linear system (Unit 4); it is more robust for hard problems.

### 5.9.1 Eight uses of numerical methods for differential equations

1. **Weather and climate models.** The atmosphere obeys differential equations that cannot be solved exactly. Computers step them forward in small time steps, using methods of Runge-Kutta type. The forecast for the next week is the result of millions of such steps.
2. **Motion of vehicles and rockets.** Position, velocity and fuel change together, and each depends on the others. Engineers integrate the equations step by step to test a flight path before building anything. Satellite orbit prediction works the same way.
3. **Electric circuits.** A circuit with a capacitor or coil is described by a differential equation for charge or current. Simulators such as SPICE solve it numerically for any input signal. Chip designers depend on this.
4. **Population and epidemic models.** The spread of a disease between susceptible and infected people follows coupled equations. Health planners step them forward to compare outcomes of vaccination or lockdown. Planning during the COVID-19 pandemic used models of this kind.
5. **Chemical reactions and drug dosage.** Concentrations change at rates that depend on each other. Numerical solution shows how long a medicine stays active in the body. It guides the dose and the time between doses.
6. **Cooling, heating and mixing.** A cup of tea, a cooling engine and a tank where salt water is mixed all give simple equations that are easy to step. The same method can handle a changing outside temperature, which no formula does. It is a good first exercise.
7. **Games and animation.** Falling objects, springs and cloth in a game are updated each frame by a small step method. A cheap method such as Euler is fast but can drift, so better methods are used for accuracy. Physics engines are made of these steps.
8. **Finance.** Option prices and interest-rate models are described by differential equations that rarely have exact solutions. Banks solve them numerically every day. Accuracy and speed both matter.

## 5.10 Stability, stiffness and implicit methods

Accuracy says how small the error is when $h$ is small. **Stability** says what happens when $h$ is not small enough: errors that should die out may instead grow at every step until the answer is meaningless. The standard test problem is

$$y' = -\lambda y,\qquad y(0) = 1,\qquad \lambda > 0,$$

whose exact solution $e^{-\lambda x}$ decays to zero. A good method must also decay. Euler's method gives $y_{n+1} = y_n + h(-\lambda y_n) = (1 - h\lambda)\,y_n$, so $y_n = (1 - h\lambda)^{n}$. The numbers decay only if $|1 - h\lambda| < 1$, that is, **$h < 2/\lambda$**. Above that limit the computed values alternate in sign and grow.

::: example y′ = −50y, y(0) = 1, integrated to x = 0.2 (exact value $e^{-10} = 0.0000454$)
The Euler factor is $1 - 50h$. Results:

| Step *h* | Factor $1 - 50h$ | First values | $y(0.2)$ by Euler |
|---|---|---|---|
| 0.05 | −1.5 | 1, −1.5, 2.25, −3.375 | 5.0625 (grows) |
| 0.04 | −1.0 | 1, −1, 1, −1 | −1 (never decays) |
| 0.02 | 0.0 | 1, 0, 0, 0 | 0 (decays, but in one step) |
| 0.01 | 0.5 | 1, 0.5, 0.25, 0.125 | 0.000001 (decays) |

The limit is $2/\lambda = 0.04$. With $h = 0.05$ the answer is wrong by a factor of more than 100000 and swings in sign, even though each individual step is a perfectly legitimate Euler step. Accuracy would have asked for $h$ far below the limit anyway; stability sets a hard ceiling.
:::

**Stability limits of other methods.** Heun's method has the same limit $h\lambda < 2$. RK4 multiplies by $R(z) = 1 + z + \frac{z^{2}}{2} + \frac{z^{3}}{6} + \frac{z^{4}}{24}$ with $z = -h\lambda$, and $|R| < 1$ up to $h\lambda \approx 2.785$ (for $\lambda = 50$ this is $h < 0.0557$; $h = 0.05$ gives factor 0.648, but $h = 0.06$ gives 1.375 and blows up). A higher order buys a somewhat larger step, never an unlimited one.

**Stiff problems.** A problem is **stiff** when it contains components that decay at very different rates, for example $y' = -1000\,(y - \cos x) - \sin x$ where a fast transient dies in a few thousandths while the solution of interest changes slowly. An explicit method must keep $h < 2/1000$ for stability *throughout*, long after the fast part is gone, so it crawls. Chemical kinetics, electrical circuits with widely different time constants and heat flow on fine grids are typical stiff problems.

**The implicit remedy.** In the **backward Euler** method the slope is taken at the *new* point:

$$y_{n+1} = y_n + h\,f(x_{n+1}, y_{n+1}).$$

For the test problem this is $y_{n+1} = y_n - h\lambda\,y_{n+1}$, so $y_{n+1} = \dfrac{y_n}{1 + h\lambda}$ and the factor $\dfrac{1}{1 + h\lambda}$ is below 1 for **every** $h > 0$. With $h = 0.1$ and $\lambda = 50$ the first values are $1,\ 0.1667,\ 0.0278$ and with $h = 0.05$ the value at 0.2 is 0.00666: not accurate, but decaying and never exploding. The price is that each step has an equation $y_{n+1} = y_n + h f(x_{n+1}, y_{n+1})$ to solve for $y_{n+1}$ (by Newton's method, Unit 1, or directly when $f$ is linear). Backward Euler is only first order; the trapezoidal (Crank-Nicolson) and higher-order implicit methods keep the stability and improve the accuracy.

::: key Remember
- **Local error** per step, **global error** over the interval (one order lower), **stability** is separate: check both.
- Euler is stable for the decay test only if $h\lambda < 2$; RK4 if $h\lambda < 2.785$; backward Euler for all $h$.
- If halving $h$ changes the answer wildly rather than by the expected factor, suspect instability, not just low accuracy.
:::

## 5.11 Multistep methods: Adams-Bashforth, Adams-Moulton and predictor-corrector

Euler, Heun and Runge-Kutta are **single-step** methods: each step forgets the past and re-evaluates $f$ at several trial points, which costs one to four evaluations per step. A **multistep** method reuses slopes already computed at earlier points. After the first few values, a fourth-order Adams method needs only **one new evaluation of $f$ per step**, which matters when $f$ is expensive.

Write $f_n = f(x_n, y_n)$. Integrating $y' = f$ from $x_n$ to $x_{n+1}$ and replacing $f$ by an interpolating polynomial through earlier points (Unit 2, backward differences) gives the **Adams-Bashforth** (explicit) formulas:

$$\text{AB2: } y_{n+1} = y_n + \frac{h}{2}\,(3f_n - f_{n-1}),\qquad \text{AB4: } y_{n+1} = y_n + \frac{h}{24}\,(55f_n - 59f_{n-1} + 37f_{n-2} - 9f_{n-3}).$$

Including the unknown point $x_{n+1}$ in the interpolation gives the **Adams-Moulton** (implicit) formulas, with a much smaller error constant:

$$\text{AM3: } y_{n+1} = y_n + \frac{h}{24}\,(9f_{n+1} + 19f_n - 5f_{n-1} + f_{n-2}),\qquad \text{trapezoidal (AM2): } y_{n+1} = y_n + \frac{h}{2}\,(f_{n+1} + f_n).$$

AM3 uses three earlier slopes and has global error $O(h^{4})$, the same order as AB4. The right-hand side contains $f_{n+1}$, which depends on the unknown $y_{n+1}$, so it is used as a **corrector** after a **predictor**: predict $y_{n+1}^{(p)}$ with AB4, evaluate $f_{n+1}^{(p)} = f(x_{n+1}, y_{n+1}^{(p)})$, then correct with AM3. This is the **Adams-Bashforth-Moulton predictor-corrector** (PECE: Predict, Evaluate, Correct, Evaluate). The **Milne** pair uses
$y_{n+1}^{(p)} = y_{n-3} + \frac{4h}{3}\,(2f_{n-2} - f_{n-1} + 2f_n)$ and the Simpson corrector $y_{n+1} = y_{n-1} + \frac{h}{3}\,(f_{n-1} + 4f_n + f_{n+1})$.

**Starting values.** A multistep method needs several values before it can begin. They come from a single-step method of the same order (RK4 for AB4/AM3), or from the Taylor series. This is the standard use of Runge-Kutta: starter for Adams.

::: example y′ = x + y, y(0) = 1, h = 0.1: Adams-Bashforth-Moulton with RK4 starters
RK4 starting values (Section 5.6): $y_1 = 1.110342$, $y_2 = 1.242805$, $y_3 = 1.399717$. The slopes are $f_0 = 1.000000$, $f_1 = 1.210342$, $f_2 = 1.442805$, $f_3 = 1.699717$.

*Predict $y_4$ (AB4):* $y_4^{(p)} = 1.399717 + \frac{0.1}{24}\,(55 \times 1.699717 - 59 \times 1.442805 + 37 \times 1.210342 - 9 \times 1.000000) = 1.583640$.

*Evaluate:* $f_4^{(p)} = 0.4 + 1.583640 = 1.983640$.

*Correct (AM3):* $y_4 = 1.399717 + \frac{0.1}{24}\,(9 \times 1.983640 + 19 \times 1.699717 - 5 \times 1.442805 + 1.210342) = 1.583649$.

The exact value $2e^{0.4} - 1.4 = 1.583649$, so the corrected value is right to six decimals while the predictor alone is off by $9 \times 10^{-6}$. Continuing:

| *x* | AB4 predictor | Corrected (AM3) | Exact | Predictor error | Corrector error |
|---|---|---|---|---|---|
| 0.4 | 1.583640 | 1.583649 | 1.583649 | 9.2e-06 | 3.2e-07 |
| 0.5 | 1.797433 | 1.797443 | 1.797443 | 9.7e-06 | 7.5e-08 |
| 0.6 | 2.044227 | 2.044238 | 2.044238 | 1.0e-05 | 5.5e-07 |

Compare Section 5.6: RK4 with the same $h$ has error $1.3 \times 10^{-6}$ at $x = 0.5$; the Adams pair is just as accurate with one new slope per step instead of four.
:::

::: note Predictor-corrector bonus: an error estimate
The gap between predictor and corrector, here $1.0 \times 10^{-5}$, is proportional to the error of the corrected value (about $\frac{19}{270}$ of it for the Adams pair), so it can be used to monitor accuracy and change $h$. Single-step methods get no such estimate for free.
:::

**AB2 from RK4 start, same problem.** With $y_1 = 1.110342$ and AB2 only: $y_2 = 1.241893$ (exact 1.242806, error $9.1 \times 10^{-4}$), $y_3 = 1.397660$, $y_4 = 1.580214$, $y_5 = 1.792363$ (error $5.1 \times 10^{-3}$). Second-order Adams-Bashforth is no better than Heun and is shown mainly for the pattern: each AB formula is a weighted sum of recent slopes whose weights add up to 1 (here $\frac{3}{2} - \frac{1}{2}$), so a constant slope is integrated exactly.

**Comparison.**

| Property | Single-step (RK4) | Multistep (Adams PECE) |
|---|---|---|
| Evaluations of $f$ per step | 4 | 2 (one predict, one correct) or 1 |
| Self-starting | yes | no, needs RK4 or Taylor starters |
| Changing the step size | trivial | awkward (history is at the old spacing) |
| Error estimate | needs extra work | predictor minus corrector |
| Typical use | general purpose, start-up, discontinuities | smooth problems, expensive $f$ |

## 5.12 More on Runge-Kutta: the family, order and automatic step control

Section 5.6 gave RK4, the most used member. All explicit Runge-Kutta methods have the same shape: compute several slopes $k_i = f(x_n + c_i h,\ y_n + h\sum_j a_{ij}k_j)$ using only slopes already found, then combine them with weights $b_i$. The coefficients are conveniently listed in a **Butcher tableau**. The second-order **midpoint method** and the third-order **Kutta method** are

$$\text{Midpoint: } k_1 = f(x_n, y_n),\quad k_2 = f\!\left(x_n + \tfrac{h}{2},\ y_n + \tfrac{h}{2}k_1\right),\quad y_{n+1} = y_n + h\,k_2,$$

$$\text{RK3: } k_1 = f(x_n, y_n),\ \ k_2 = f\!\left(x_n + \tfrac{h}{2},\ y_n + \tfrac{h}{2}k_1\right),\ \ k_3 = f(x_n + h,\ y_n - h k_1 + 2h k_2),\ \ y_{n+1} = y_n + \tfrac{h}{6}(k_1 + 4k_2 + k_3).$$

The order of an explicit method with $s$ slopes cannot exceed $s$, and for $s > 4$ the maximum order is less than $s$ (five slopes still give only order 4, six give order 5). This is the reason RK4 is the sweet spot: four slopes, order four.

::: example Four methods on y′ = x + y, y(0) = 1, h = 0.1, five steps to x = 0.5
Exact value 1.797443. The first step gives 1.100000 (Euler), 1.110000 (midpoint and Heun), 1.110333 (RK3) and 1.110342 (RK4, exact to six places).

| Method | Slopes per step | Order | $y(0.5)$ | Error |
|---|---|---|---|---|
| Euler | 1 | 1 | 1.721020 | 7.6e-02 |
| Midpoint / Heun | 2 | 2 | 1.794894 | 2.5e-03 |
| Kutta RK3 | 3 | 3 | 1.797379 | 6.3e-05 |
| RK4 | 4 | 4 | 1.797441 | 1.3e-06 |

Midpoint and Heun give identical numbers here because $f = x + y$ is linear in $y$; for a nonlinear $f$ they differ in the last digits, though both are second order. Each extra slope buys about a factor of 30 to 50 in accuracy at $h = 0.1$.
:::

**Cost for a target accuracy.** From the error table of Section 5.6 the error at $x = 0.5$ behaves like $0.76\,h$ for Euler and $1.3\times 10^{-2}\,h^{4}$ for RK4 (constants from $h = 0.1$). To reach $10^{-6}$ Euler needs $h \approx 1.3\times 10^{-6}$, about 380 000 steps and as many evaluations of $f$; RK4 needs $h \approx 0.094$, about 5.3 steps, in practice 6 steps or 24 evaluations. The same accuracy costs more than ten thousand times less work. This, not elegance, is why higher order methods exist.

**Automatic step-size control.** A fixed $h$ is wasteful where the solution is smooth and dangerous where it changes quickly. Practical solvers compute **two** answers of different orders from the same slopes, take their difference as an estimate of the local error, and adjust $h$.

::: example Embedded Euler/Heun pair on y′ = x + y, tolerance 0.001 per step
For a step of size $h$ from $(x, y)$ compute $k_1 = f(x, y)$, $k_2 = f(x + h,\ y + hk_1)$, the Euler value $y + hk_1$ and the Heun value $y + \frac{h}{2}(k_1 + k_2)$. The estimate is $\varepsilon = |\text{Heun} - \text{Euler}|$ (it equals $\frac{h}{2}|k_2 - k_1|$). A step is **accepted** if $\varepsilon \le 0.001$, and the next step size is $h_{\text{new}} = 0.9\,h\sqrt{0.001/\varepsilon}$, limited to between $0.3h$ and $2h$.

| Trial | *x* | *h* | Euler | Heun | $\varepsilon$ | Decision |
|---|---|---|---|---|---|---|
| 1 | 0 | 0.2000 | 1.200000 | 1.240000 | 4.0e-02 | reject (too big) |
| 2 | 0 | 0.0600 | 1.060000 | 1.063600 | 3.6e-03 | reject |
| 3 | 0 | 0.0285 | 1.028460 | 1.029270 | 8.1e-04 | accept |
| 4 | 0.0285 | 0.0285 | 1.059374 | 1.060207 | 8.3e-04 | accept |

After 20 accepted and 2 rejected steps the integration reaches $x = 0.5$ with $y = 1.797267$, error $1.8\times 10^{-4}$, much smaller than the fixed-step Heun error of $2.5\times 10^{-3}$ with five steps (the price is more steps: the tolerance of 0.001 per step is strict). The method took the small steps it needed and no smaller. The accuracy of the *whole* run is not the tolerance: per-step tolerances accumulate, so solvers use a smaller tolerance than the accuracy wanted in the end.
:::

Production codes use a higher-order embedded pair. The **Runge-Kutta-Fehlberg (RKF45)** method of Fehlberg and the **Dormand-Prince** pair (used by MATLAB's `ode45` and SciPy's `solve_ivp` with the default method `RK45`) compute a fourth- and a fifth-order result from six or seven slopes and control $h$ in exactly the way above. Section 5.10 explains why they switch to implicit methods for stiff problems.

## 5.13 Applications: cooling, population growth and falling bodies

All three problems below have exact solutions, so the numerical answers can be checked. In practice the methods are used where no exact solution exists.

**Newton's law of cooling.** A cup of tea at $90\,^{\circ}\mathrm{C}$ stands in a $20\,^{\circ}\mathrm{C}$ room; $\dfrac{dT}{dt} = -0.1\,(T - 20)$ with $t$ in minutes. The exact solution is $T = 20 + 70e^{-0.1t}$.

::: example RK4 with the big step h = 5 minutes
| *t* (min) | RK4 | Exact | Error |
|---|---|---|---|
| 5 | 62.4740 | 62.4571 | 0.0169 |
| 10 | 45.7720 | 45.7516 | 0.0204 |
| 15 | 35.6377 | 35.6191 | 0.0186 |
| 20 | 29.4885 | 29.4735 | 0.0150 |

Euler with the same step gives 24.375 at 20 minutes: wrong by 5.1 degrees, because the factor $1 - 0.5 = 0.5$ per step is a poor imitation of $e^{-0.5} = 0.607$. RK4 is accurate to hundredths even with a step this large. The tea reaches $40\,^{\circ}\mathrm{C}$ at $t = \ln(70/20)/0.1 = 12.53$ minutes, which can be read off the RK4 values by interpolating between 10 and 15 minutes.
:::

**Logistic population growth.** $\dfrac{dP}{dt} = 0.5\,P\left(1 - \dfrac{P}{100}\right)$, $P(0) = 10$: growth that slows as the population nears the carrying capacity 100. The exact solution is $P = \dfrac{100}{1 + 9e^{-0.5t}}$. RK4 with $h = 1$ gives

| *t* | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| RK4 | 15.4815 | 23.1939 | 33.2380 | 45.0793 | 57.5058 | 69.0507 |
| Exact | 15.4828 | 23.1969 | 33.2428 | 45.0853 | 57.5121 | 69.0568 |

Errors are of order $10^{-3}$ to $6\times 10^{-3}$ with one step per time unit, tiny against the size of the population. The point of the example is that the equation is nonlinear in $P$ and still no new idea is needed: $f(t, P) = 0.5P(1 - P/100)$ goes into the same four formulas.

**Falling body with air resistance.** A body of unit mass falling with linear drag obeys $\dfrac{dv}{dt} = 9.81 - 0.5v$, $v(0) = 0$. The velocity approaches the **terminal velocity** $9.81/0.5 = 19.62\ \mathrm{m/s}$; the exact solution is $v = 19.62\,(1 - e^{-0.5t})$. RK4 with $h = 0.5$ gives $v(1) = 7.7196$ (exact 7.7199), $v(2) = 12.4019$ (12.4022), $v(3) = 15.2419$ (15.2422): correct to about $3\times 10^{-4}$ with three steps per second of fall.

## 5.14 Boundary value problems by finite differences

The shooting method of Section 5.8 reduces a BVP to repeated IVPs. The **finite-difference method** instead replaces the derivative by its difference at *every grid point at once* and solves one linear system (Unit 4). It is the same idea as the Laplace equation in Unit 6, in one dimension.

::: example y″ = y, y(0) = 0, y(1) = 2, with h = 0.25
Interior points $x_1 = 0.25$, $x_2 = 0.5$, $x_3 = 0.75$; $y_0 = 0$ and $y_4 = 2$ are the boundary values. The central difference $y''_i \approx \dfrac{y_{i-1} - 2y_i + y_{i+1}}{h^{2}}$ turns the equation into $y_{i-1} - (2 + h^{2})\,y_i + y_{i+1} = 0$, and $2 + h^{2} = 2.0625$:

$$\begin{aligned} -2.0625\,y_1 + y_2 &= 0\\ y_1 - 2.0625\,y_2 + y_3 &= 0\\ y_2 - 2.0625\,y_3 &= -2 \end{aligned}$$

The matrix is **tridiagonal**; the elimination of Section 4.8 solves it in about $n$ operations. The solution is $y_1 = 0.430230$, $y_2 = 0.887348$, $y_3 = 1.399926$, against the exact $2\sinh x/\sinh 1$ values $0.429905$, $0.886819$, $1.399448$: errors $3.2\times 10^{-4}$, $5.3\times 10^{-4}$, $4.8\times 10^{-4}$.
:::

The error behaves as $O(h^{2})$: with $N = 8$ and $N = 16$ intervals the largest errors are $1.37\times 10^{-4}$ and $3.44\times 10^{-5}$, a ratio of 3.98. Compared with shooting (Section 5.8, which hit $y(1) = 2$ and found $y(0.5) = 0.886819$ exactly to six places, because RK4 is fourth order):

| | Shooting + RK4 | Finite differences |
|---|---|---|
| Linear problem | two shots and interpolation | one tridiagonal system |
| Nonlinear problem | secant or Newton on the slope, a shot per trial | nonlinear system, Newton's method (Unit 1) |
| Accuracy | follows the IVP solver (here $O(h^{4})$) | $O(h^{2})$ for the central formula |
| Weakness | unstable if the IVP is very sensitive to the slope | larger system, needs good starting guess if nonlinear |
| Strength | simple, reuses the IVP code | robust on hard problems; derivative boundary conditions are easy |

**Derivative boundary conditions.** If the condition at $x = b$ is $y'(b) = \gamma$, add a fictitious point $x_{n+1}$ and use the central difference $\dfrac{y_{n+1} - y_{n-1}}{2h} = \gamma$ to eliminate $y_{n+1}$ from the equation at $x_n$. The same trick appears for an insulated edge in Section 6.9.

## Formula and fact sheet

- Euler: $y_{i+1} = y_{i} + h f (x_{i} ,\  y_{i})$; global error $O (h)$.
- Heun: $y \ast = y_{i} + h f ;\  y_{i+1} = y_{i} + \left( \frac{h}{2} \right) [f (x_{i} ,\  y_{i}) + f (x_{i+1} ,\  y \ast)] ;\  O (h^{2})$.
- RK4: $y_{i+1} = y_{i} + \left( \frac{h}{6} \right) (k_{1} + 2 k_{2} + 2 k_{3} + k_{4}) ;\  O (h^{4})$.
- Picard: $y_{n+1} = y_{0} + \int f (t ,\  y_{n}) \,d t$. Taylor: $y = y_{0} + (x - x_{0}) y'_{0} + \ldots$
- Higher order: put $z = y'$ and solve the system. Shooting: root of $\varphi (s) = y (b ;\  s) - \beta$.
- Stability of Euler on $y' = -\lambda y$: $y_{n+1} = (1 - h\lambda)y_n$, stable for $h < 2/\lambda$; RK4 for $h\lambda < 2.785$; backward Euler factor $1/(1 + h\lambda)$.
- AB4: $y_{n+1} = y_n + \frac{h}{24}(55f_n - 59f_{n-1} + 37f_{n-2} - 9f_{n-3})$; AM3: $y_{n+1} = y_n + \frac{h}{24}(9f_{n+1} + 19f_n - 5f_{n-1} + f_{n-2})$.
- RK3: $y_{n+1} = y_n + \frac{h}{6}(k_1 + 4k_2 + k_3)$ with $k_3 = f(x_n + h,\ y_n - hk_1 + 2hk_2)$.
- Finite-difference BVP: $y_{i-1} - 2y_i + y_{i+1} = h^{2}f_i$, a tridiagonal system, error $O(h^{2})$.

## Chapter summary

- An IVP is solved by stepping from the initial condition: Taylor and Picard give series; Euler, Heun and RK4 give numbers.
- Euler's method is first order, Heun second, RK4 fourth; halving *h* reduces the error by about 2, 4 and 16 respectively.
- Higher-order equations become first-order systems.
- BVPs are solved by shooting (guess the slope, integrate, correct with interpolation or secant steps) or by finite differences.
- Stability limits the step as much as accuracy does: Euler needs $h < 2/\lambda$ on decay problems; stiff problems need implicit methods.
- Adams-Bashforth-Moulton predictor-corrector methods need one or two evaluations of $f$ per step but must be started by RK4; embedded pairs (RKF45, Dormand-Prince) control the step automatically.

**20.** Stiff: components decay at very different rates, so an explicit method must use a step set by the fastest, long after it has vanished. Implicit methods such as backward Euler are stable for any $h$ on decaying problems, so $h$ can follow the slow part; each step costs an equation solve.

**21.** (i) Slopes per step: single-step 1 to 4, Adams 1 to 2. (ii) Starting: single-step self-starting, Adams not. (iii) Step change: easy versus awkward. (iv) Error estimate: extra work versus predictor minus corrector.

**Q1 (5 marks). Use Euler's method with $h = 0.1$ to find $y (0.5)$ for $\frac{d y}{d x} = x + y ,\  y (0) = 1$, and compare with the exact solution $y = 2 e^{x} - x - 1$.**

*Formula.* $y (n + 1) = y (n) + h f (x (n) ,\  y (n))$ with $f = x + y$.

| *n* | $x (n)$ | $y (n)$ | $f = x + y$ | $y (n + 1) = y$ + 0.1f | Exact $y (n + 1)$ | Error |

| 1 | 0.1 | 1.10000 | 1.20000 | 1.22000 | 1.24281 | 0.02281 |

So Euler gives **$y (0.5) = 1.72102$** against the exact **1.79744**, an error of 0.0764 (4.3%) (Figure 5.1). Euler is a first-order method: halving *h* roughly halves the error. *Conclusion:* Euler is simple but needs a very small step for accuracy.

**Q2 (5 marks). Apply one step of the fourth-order Runge-Kutta method to $\frac{d y}{d x} = x + y ,\  y (0) = 1 ,\  h = 0.1$.**

*Formulas.* k1 = $f ( x 0$, y0); k2 = $f ( x 0 + \frac{h}{2}$, y0 + $\frac{h k 1}{2}$); k3 = $f ( x 0 + \frac{h}{2}$, y0 + $\frac{h k 2}{2}$); k4 = $f ( x 0 + h$, y0 + *h* k3); y1 = y0 + ($\frac{h}{6} ) ( k 1$ + 2k2 + 2k3 + k4).

*Calculation.* k1 = $0 + 1$ = **1**. k2 = $f (0.05 ,\  1 + 0.05 x 1) = 0.05 + 1.05$ = **1.1**. k3 = $f (0.05 ,\  1 + 0.05 x 1.1) = 0.05 + 1.055$ = **1.105**. k4 = $f (0.1 ,\  1 + 0.1 x 1.105) = 0.1 + 1.1105$ = **1.2105**. Then y1 = $1 + (0.1 / 6) (1 + 2.2 + 2.21 + 1.2105) = 1 + (0.1 / 6) (6.6205)$ = **1.110342**.

The exact value is $2 e^{0} . 1 - 0.1 - 1 = 1.110342$, so one RK4 step is correct to six decimals (Figure 5.2), while one Euler step gave 1.1. *Conclusion:* RK4 has error $O (h^{4})$ and is the standard general-purpose method.

**Q3 (10 marks). Compare the Taylor, Euler, Heun (improved Euler) and Runge-Kutta methods for the initial value problem $y' = f (x ,\  y) ,\  y (x 0)$ = y0. Illustrate with $y' = x + y ,\  y (0) = 1$.**

*Introduction.* Most differential equations have no closed-form solution, so we compute *y* at the points x0 + *h*, x0 + $2 h ,\  \ldots$ by repeated small steps. All methods in this unit are of this kind; they differ in how many slopes they use per step and hence in order and cost (Plate 5.1).

*Taylor series method.* Expand $y (x + h) = y + h y' + \left( \frac{h^{2}}{2} \right) y'' + \ldots$ using derivatives obtained by differentiating the equation. It is accurate but needs analytic derivatives, so it is used mostly for hand calculation and to start other methods.

*Euler.* $y (n + 1) = y (n) + h f (x (n) ,\  y (n))$: follow the tangent for one step. Local error $O (h^{2})$, global error $O (h)$: first order.

*Heun (improved Euler).* A predictor-corrector: predict $y \ast = y + h f (x ,\  y)$, then correct $y (n + 1) = y + \left( \frac{h}{2} \right) [f (x ,\  y) + f (x + h ,\  y \ast)]$, averaging the slopes at both ends. Second order.

*Runge-Kutta (RK4).* A weighted average of four slopes per step: $y (n + 1) = y + \left( \frac{h}{6} \right) ( k 1$ + 2k2 + 2k3 + k4) (Figure 5.2). Fourth order: global error $O (h^{4})$; no derivatives of *f* are needed.

*Illustration.* For $y' = x + y ,\  y (0) = 1 ,\  h = 0.1$, the exact value $y (0.5) = 1.797443$ is approximated as follows.

| Method | Slopes per step | Order | $y (0.5)$ | Error |
|---|---|---|---|---|
| Euler | 1 | 1 | 1.721020 | 0.076423 |
| Heun | 2 | 2 | 1.794894 | 0.002549 |
| RK4 | 4 | 4 | 1.797441 | 0.0000013 |

Figure 5.3 shows the gain: moving from Euler to RK4 costs four times as many evaluations but reduces the error by a factor of about 60,000.

*Systems and higher-order equations.* A higher-order equation such as $y'' = f (x ,\  y ,\  y')$ is rewritten as a system $u' = v ,\  v' = f (x ,\  u ,\  v)$ and each component is stepped together. *Boundary value problems* are solved by the **shooting method**, adjusting the starting slope until the far boundary is met.

*Stability and step size.* Too large a step can make a method blow up, particularly for stiff problems; the step should be reduced until results stop changing, or an adaptive step controller should be used.

*Conclusion.* Euler is the simplest and least accurate; Heun is a cheap improvement; RK4 is the usual choice because it gives high accuracy at modest cost.

**Q4 (5 marks). Show that Euler's method for $y' = -\lambda y$ is stable only for $h < 2/\lambda$. For $\lambda = 50$ compare $h = 0.05$ and $h = 0.01$ over $x \in [0, 0.2]$.**

*Derivation.* Euler gives $y_{n+1} = y_n + h(-\lambda y_n) = (1 - h\lambda)\,y_n$, so $y_n = (1 - h\lambda)^{n} y_0$. The true solution $e^{-\lambda x}$ decays, so the numerical one must too, which requires $|1 - h\lambda| < 1$, that is $0 < h\lambda < 2$ and **$h < 2/\lambda$**.

*Numbers.* For $\lambda = 50$ the limit is $h < 0.04$.

| $h$ | Factor $1 - 50h$ | Values at steps 0, 1, 2, 3, 4 | $y(0.2)$ | Exact $y(0.2)$ |
|---|---|---|---|---|
| 0.05 | −1.5 | 1, −1.5, 2.25, −3.375, 5.0625 | 5.0625 | 0.0000454 |
| 0.01 | +0.5 | 1, 0.5, 0.25, 0.125, 0.0625 (20 steps to $x = 0.2$) | 0.000001 | 0.0000454 |

*Conclusion.* Above the limit the error is amplified at every step: stability, not accuracy, decides the maximum step. For stiff problems this forces absurdly small steps, which is why implicit methods (backward Euler, factor $1/(1 + h\lambda)$) are used.

**Q5 (5 marks). Explain the Adams-Bashforth-Moulton predictor-corrector method and apply it to find $y(0.4)$ for $y' = x + y$, $y(0) = 1$, $h = 0.1$, starting from the RK4 values.**

*Formulas.* Predictor (AB4): $y_{n+1}^{(p)} = y_n + \frac{h}{24}(55f_n - 59f_{n-1} + 37f_{n-2} - 9f_{n-3})$. Corrector (AM3): $y_{n+1} = y_n + \frac{h}{24}(9f_{n+1}^{(p)} + 19f_n - 5f_{n-1} + f_{n-2})$ with $f_{n+1}^{(p)} = f(x_{n+1}, y_{n+1}^{(p)})$.

*Starting values (RK4):* $y_0 = 1$, $y_1 = 1.110342$, $y_2 = 1.242805$, $y_3 = 1.399717$; slopes $f_0 = 1.000000$, $f_1 = 1.210342$, $f_2 = 1.442805$, $f_3 = 1.699717$.

*Predict:* $y_4^{(p)} = 1.399717 + \frac{0.1}{24}(93.484 - 85.126 + 44.783 - 9) = 1.399717 + \frac{0.1}{24}(44.141) = 1.583640$. *Evaluate:* $f_4^{(p)} = 0.4 + 1.583640 = 1.983640$.

*Correct:* $y_4 = 1.399717 + \frac{0.1}{24}(17.853 + 32.295 - 7.214 + 1.210) = 1.399717 + \frac{0.1}{24}(44.144) = 1.583649$.

*Check:* exact $2e^{0.4} - 1.4 = 1.583649$. The method needs only two new evaluations of $f$ per step against four for RK4 and has a built-in error estimate (predictor minus corrector $= 9 \times 10^{-6}$). *Conclusion:* accurate and economical for smooth problems, but not self-starting.

**Q6 (10 marks). Solve the boundary value problem $y'' = y$, $y(0) = 0$, $y(1) = 2$ by (a) the shooting method and (b) the finite-difference method with $h = 0.25$. Compare with the exact solution $y = 2\sinh x / \sinh 1$.**

*(a) Shooting.* Put $y' = z$, $z' = y$ with $y(0) = 0$, $z(0) = s$. RK4 ($h = 0.1$) with $s = 1$ gives $y(1) = 1.175200$ and with $s = 2$ gives $2.350400$ (the problem is linear, so $y(1)$ is proportional to $s$). Interpolating for the target 2: $s = 1 + \frac{(2 - 1.175200)(2 - 1)}{2.350400 - 1.175200} = 1.701838$; a third shot gives $y(1) = 2.000000$ and $y(0.5) = 0.886819$.

*(b) Finite differences.* With $x_i = 0.25i$, replace $y''$ by $\frac{y_{i-1} - 2y_i + y_{i+1}}{h^{2}}$. Then $y_{i-1} - 2.0625\,y_i + y_{i+1} = 0$ for $i = 1, 2, 3$ with $y_0 = 0$, $y_4 = 2$:

$$-2.0625\,y_1 + y_2 = 0,\qquad y_1 - 2.0625\,y_2 + y_3 = 0,\qquad y_2 - 2.0625\,y_3 = -2.$$

From the first, $y_2 = 2.0625\,y_1$. The second gives $y_3 = 2.0625\,y_2 - y_1 = (4.253906 - 1)\,y_1 = 3.253906\,y_1$. Substituting in the third, $(2.0625 - 2.0625 \times 3.253906)\,y_1 = -2$, that is $-4.648682\,y_1 = -2$, so $y_1 = 0.430230$, $y_2 = 0.887348$, $y_3 = 1.399926$.

*Results.*

| *x* | Shooting | Finite differences | Exact |
|---|---|---|---|
| 0.25 | not a grid point | 0.430230 | 0.429905 |
| 0.50 | 0.886819 | 0.887348 | 0.886819 |
| 0.75 | not a grid point | 1.399926 | 1.399448 |

*Conclusion.* The shooting result is limited only by the RK4 error ($O(h^{4})$), the finite-difference one by its $O(h^{2})$ central formula (errors about $5 \times 10^{-4}$ at $h = 0.25$, quartering when $h$ is halved). Shooting is the simpler to program; finite differences are more robust for hard or nonlinear problems.
