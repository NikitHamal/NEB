How fast does a cup of tea cool, how does a population grow, how does a capacitor discharge, where does a rocket go? Each is a differential equation, and most have no closed-form solution. The methods here march forward in small steps from a known starting point, using the equation itself to estimate the slope.

- Higher-order equations as first-order systems.

## 5.1 Initial value problems

An **initial value problem (IVP)** asks for y(x) satisfying **y′ = f(x, y), y(x₀) = y₀**. The running example of this unit is

**y′ = x + y, y(0) = 1**, whose exact solution is y = 2eˣ − x − 1 (so y(0.5) = 1.797443).

We want approximate values yᵢ ≈ y(xᵢ) at xᵢ = x₀ + ih. A method is **single-step** if yᵢ₊₁ is computed from yᵢ alone (Euler, Runge–Kutta) and **multistep** if it also uses earlier values (Adams). The **local truncation error** is the error made in one step; the **global error** is the accumulated error after many steps, typically one power of h *lower* in order. A method of **order p** has global error O(hᵖ).

## 5.2 Taylor series method

Differentiate the equation repeatedly and evaluate at x₀: y(x) = y₀ + (x − x₀)y₀′ + (x − x₀)²/2! y₀″ + …

For y′ = x + y, y(0) = 1: y′(0) = 0 + 1 = 1; y″ = 1 + y′ so y″(0) = 2; y‴ = y″ = 2; y⁗ = 2. Hence

**y(x) = 1 + x + x² + x³/3 + x⁴/12 + …**

At x = 0.1 four terms give y(0.1) ≈ 1.110342 (the true value agrees to six decimals). At x = 0.5 the same polynomial gives 1.796875, error 0.000568; the error grows as x moves away from 0, so for long intervals the series is used step by step, re-expanding at each new point. The drawback is that higher derivatives of f(x, y) are tedious to obtain, which is why Runge–Kutta methods were invented.

## 5.3 Picard's method

Write the IVP as the integral equation y(x) = y₀ + ∫ₓ₀ˣ f(t, y(t)) dt and iterate: **yₙ₊₁(x) = y₀ + ∫ f(t, yₙ(t)) dt**, starting from y₀(x) = y₀.

For y′ = x + y, y(0) = 1:

- y₁ = 1 + ∫₀ˣ (t + 1) dt = x^2/2 + x + 1
- y₂ = 1 + ∫₀ˣ (t + y₁(t)) dt = x^3/6 + x^2 + x + 1
- y₃ = x^4/24 + x^3/3 + x^2 + x + 1

Each iteration adds one more correct term of the series 1 + x + x² + x³/3 + x⁴/12 + … At x = 0.5, y₃ = 1.794271 against the true 1.797443. Picard iteration proves existence and uniqueness of solutions (under a Lipschitz condition) but is practical only when the integrals can be done analytically.

## 5.4 Euler's method

Follow the tangent for one step: **yᵢ₊₁ = yᵢ + h·f(xᵢ, yᵢ)**. This is the first two terms of the Taylor series.

::: example Euler, y′ = x + y, y(0) = 1, h = 0.1
| i | xᵢ | yᵢ | f(xᵢ,yᵢ) | yᵢ₊₁ | exact y(xᵢ₊₁) | error |
|---|---|---|---|---|---|---|
| 0 | 0.0 | 1.000000 | 1.000000 | 1.100000 | 1.110342 | 0.010342 |
| 1 | 0.1 | 1.100000 | 1.200000 | 1.220000 | 1.242806 | 0.022806 |
| 2 | 0.2 | 1.220000 | 1.420000 | 1.362000 | 1.399718 | 0.037718 |
| 3 | 0.3 | 1.362000 | 1.662000 | 1.528200 | 1.583649 | 0.055449 |
| 4 | 0.4 | 1.528200 | 1.928200 | 1.721020 | 1.797443 | 0.076423 |

At x = 0.5 Euler gives 1.721020, the exact value is 1.797443, and the error is 0.076423 (4.3 %). The numerical solution lags behind because the true curve bends upward (convex) and every tangent underestimates it.
:::

**Accuracy.** The local error is O(h²) (the first dropped Taylor term, h²y″/2) but errors accumulate over 1/h steps, so the **global error is O(h)**: halving h halves the error, as the table of Section 5.6 shows. Euler's method is simple but needs very small steps.

## 5.5 Heun's (improved Euler) method

Euler uses the slope at the start of the step only. Heun averages the slope at both ends, using Euler to *predict* the end value:

**y* = yᵢ + h f(xᵢ, yᵢ)** (predictor), **yᵢ₊₁ = yᵢ + (h/2)[f(xᵢ, yᵢ) + f(xᵢ₊₁, y*)]** (corrector).

It is the trapezoidal rule applied to the equation, a second-order method with global error O(h²).

::: example Heun, same problem, h = 0.1
| i | xᵢ | yᵢ | predictor y* | corrector yᵢ₊₁ | exact |
|---|---|---|---|---|---|
| 0 | 0.0 | 1.000000 | 1.100000 | 1.110000 | 1.110342 |
| 1 | 0.1 | 1.110000 | 1.231000 | 1.242050 | 1.242806 |
| 2 | 0.2 | 1.242050 | 1.386255 | 1.398465 | 1.399718 |
| 3 | 0.3 | 1.398465 | 1.568312 | 1.581804 | 1.583649 |
| 4 | 0.4 | 1.581804 | 1.779985 | 1.794894 | 1.797443 |

At x = 0.5, Heun gives 1.794894 with error 0.002549, about 30 times smaller than Euler's error for the same step.
:::

## 5.6 Runge–Kutta methods

Runge–Kutta (RK) methods match the Taylor series to a given order *without* computing derivatives of f, by sampling f at several points inside the step.

**RK2 (midpoint/Heun family):** k₁ = f(xᵢ, yᵢ), k₂ = f(xᵢ + h, yᵢ + hk₁), yᵢ₊₁ = yᵢ + (h/2)(k₁ + k₂): this is Heun's method.

**Classical RK4** (fourth order, the standard choice):

- k₁ = f(xᵢ, yᵢ)
- k₂ = f(xᵢ + h/2, yᵢ + hk₁/2)
- k₃ = f(xᵢ + h/2, yᵢ + hk₂/2)
- k₄ = f(xᵢ + h, yᵢ + hk₃)
- **yᵢ₊₁ = yᵢ + (h/6)(k₁ + 2k₂ + 2k₃ + k₄)**

It is a Simpson-like weighting: the midpoint slopes count double. Local error O(h⁵), global O(h⁴), at the cost of four evaluations of f per step.

::: example RK4, y′ = x + y, y(0) = 1, h = 0.1
First step by hand: k₁ = f(0, 1) = 1; k₂ = f(0.05, 1.05) = 1.1; k₃ = f(0.05, 1.055) = 1.105; k₄ = f(0.1, 1.1105) = 1.2105. The computer gives (1.000000, 1.100000, 1.105000, 1.210500), so y₁ = 1 + (0.1/6)(1 + 2.2 + 2.21 + 1.2105) = 1.110342.

| i | xᵢ | yᵢ | k₁ | k₂ | k₃ | k₄ | yᵢ₊₁ | exact |
|---|---|---|---|---|---|---|---|---|
| 0 | 0.0 | 1.000000 | 1.000000 | 1.100000 | 1.105000 | 1.210500 | 1.110342 | 1.110342 |
| 1 | 0.1 | 1.110342 | 1.210342 | 1.320859 | 1.326385 | 1.442980 | 1.242805 | 1.242806 |
| 2 | 0.2 | 1.242805 | 1.442805 | 1.564945 | 1.571052 | 1.699910 | 1.399717 | 1.399718 |
| 3 | 0.3 | 1.399717 | 1.699717 | 1.834703 | 1.841452 | 1.983862 | 1.583648 | 1.583649 |
| 4 | 0.4 | 1.583648 | 1.983648 | 2.132831 | 2.140290 | 2.297677 | 1.797441 | 1.797443 |

At x = 0.5, RK4 gives 1.797441; the exact value is 1.797443; the error is only **1.26e-06**, with five steps.
:::

### Order of accuracy, confirmed

Error at x = 0.5 as the step is halved:

| h | Euler error | Heun error | RK4 error |
|---|---|---|---|
| 0.1 | 7.64e-02 | 2.55e-03 | 1.26e-06 |
| 0.05 | 3.97e-02 | 6.62e-04 | 8.24e-08 |
| 0.025 | 2.02e-02 | 1.69e-04 | 5.26e-09 |

Ratios of error(h = 0.1) / error(h = 0.05): Euler 1.93, Heun 3.85, RK4 15.35. These are close to 2 = 2¹, 4 = 2², 16 = 2⁴: the orders 1, 2 and 4. RK4 with h = 0.1 beats Euler even with h = 0.025 by a factor of thousands, although each step costs four times as much.

**Step-size control.** Practical solvers (RK45, ode45, SciPy's `solve_ivp`) compare a fourth- and a fifth-order estimate and adapt h to keep the difference below a tolerance. **Stiff** problems (components decaying at very different rates) need implicit methods because explicit ones need tiny steps for stability.

## 5.7 Higher-order equations and systems

A differential equation of order *n* converts to *n* first-order equations. For y″ = g(x, y, y′) put z = y′:

**y′ = z, z′ = g(x, y, z)**, with y(x₀) and z(x₀) = y′(x₀) given.

The RK4 formulas are then applied to the *vector* (y, z): compute k₁ … k₄ for each component using the current values of both.

::: example y″ = −y, y(0) = 0, y′(0) = 1 (exact solution y = sin x, z = cos x), RK4, h = 0.1
Writing y′ = z, z′ = −y. After the first step (y, z) = (0.099833, 0.995004).

| x | y (RK4) | sin x | z = y′ (RK4) | cos x |
|---|---|---|---|---|
| 0.1 | 0.099833 | 0.099833 | 0.995004 | 0.995004 |
| 0.2 | 0.198669 | 0.198669 | 0.980067 | 0.980067 |
| 0.3 | 0.295520 | 0.295520 | 0.955337 | 0.955336 |
| 0.4 | 0.389418 | 0.389418 | 0.921061 | 0.921061 |
| 0.5 | 0.479425 | 0.479426 | 0.877583 | 0.877583 |

The five steps reproduce sin x and cos x to about six decimals (differences appear in the sixth decimal only), although we used no trigonometry in the method.
:::

## 5.8 Boundary value problems and the shooting method

In a **boundary value problem (BVP)** the conditions are given at *two* points, such as y(a) = α and y(b) = β, so we cannot simply march from a known start. The **shooting method** guesses the missing initial slope s = y′(a), integrates the IVP to x = b (using RK4), and compares y(b) with the target β. Treat the miss, φ(s) = y(b; s) − β, as a function of s and find its root by the secant or bisection methods of Unit 1. For a **linear** BVP φ is linear in s, so two shots and linear interpolation suffice.

**Algorithm.** (1) Choose two trial slopes s₁, s₂. (2) Integrate to get y(b; s₁), y(b; s₂). (3) Interpolate: s₃ = s₁ + (β − y₁)(s₂ − s₁)/(y₂ − y₁). (4) Integrate once more with s₃ and check y(b) = β. (For a nonlinear BVP, repeat with the secant formula until |y(b) − β| is small.)

::: example y″ = y, y(0) = 0, y(1) = 2
Convert to y′ = z, z′ = y with z(0) = s. Shoot with RK4 (h = 0.1):

| trial | slope s = y′(0) | y(1) by RK4 | target |
|---|---|---|---|
| 1 | 1.0000 | 1.175200 | 2 |
| 2 | 2.0000 | 2.350400 | 2 |
| 3 | 1.701838 | 2.000000 | 2 |

Linear interpolation gives s₃ = **1.701838**; the exact slope is 2/sinh 1 = 1.701836, and the third shot hits y(1) = 2.000000. The midpoint value y(0.5) from this slope is 0.886819 against the exact 2 sinh(0.5)/sinh(1) = 0.886819.
:::

An alternative is the **finite-difference method**, which replaces y″ by (yᵢ₋₁ − 2yᵢ + yᵢ₊₁)/h² and solves the resulting linear system (Unit 4); it is more robust for hard problems.

## Formula and fact sheet

- Euler: yᵢ₊₁ = yᵢ + h f(xᵢ, yᵢ); global error O(h).
- Heun: y* = yᵢ + h f; yᵢ₊₁ = yᵢ + (h/2)[f(xᵢ, yᵢ) + f(xᵢ₊₁, y*)]; O(h²).
- RK4: yᵢ₊₁ = yᵢ + (h/6)(k₁ + 2k₂ + 2k₃ + k₄); O(h⁴).
- Picard: yₙ₊₁ = y₀ + ∫ f(t, yₙ) dt. Taylor: y = y₀ + (x − x₀)y₀′ + …
- Higher order: put z = y′ and solve the system. Shooting: root of φ(s) = y(b; s) − β.

## Chapter summary

- An IVP is solved by stepping from the initial condition: Taylor and Picard give series; Euler, Heun and RK4 give numbers.
- Euler's method is first order, Heun second, RK4 fourth; halving h reduces the error by about 2, 4 and 16 respectively.
- Higher-order equations become first-order systems.
- BVPs are solved by shooting (guess the slope, integrate, correct with interpolation or secant steps) or by finite differences.
