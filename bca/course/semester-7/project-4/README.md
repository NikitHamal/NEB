# Project IV — BCA 404

Semester VII · 3 credits · a project course. TU does not publish a unit-wise syllabus for it, so this book is a **companion handbook**. Project I (BCA 256) built a stand-alone program, Project II (BCA 306) a networked web system and Project III (BCA 356) a sensor and mobile system. Project IV is the **final-year capstone**: it adds **data-driven decisions about people**, a trained model, honest evaluation, deployment and monitoring, privacy and ethics, and a final defence that has to stand up to an external examiner. The running example is **SikshyaSignal**, an invented early-warning tool for a college that spots first-year students likely to fail a subject while there is still time to help them.

## Verification

Every program in this book was run and the printed output pasted from the real run (Python 3 plus NumPy, fixed random seed 404). **No real student data was used.** The 600 student records are produced by a documented simulator, so every number is reproducible and no privacy is at risk. Figures in the prose were copied from those runs.

## Source and honesty

**The unit structure is reconstructed.** BCA 404 has no published topic list; colleges set their own proposal, supervisor and report format. **Always follow your own college's project guidelines and your supervisor's instructions first**; where they differ from this book, they win. SikshyaSignal is an invented teaching example, not a product of any college, and the scores in Unit 5 are illustrative, not an official rubric. The legal remarks (Electronic Transactions Act 2063, Individual Privacy Act 2075) are general pointers, not legal advice.
