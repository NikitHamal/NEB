# Internship — BCA 452

Semester VIII · 3 credits · a work-placement course. TU does not publish a unit-wise syllabus for it, so this book is a **companion handbook**. Projects I to IV built things; the internship asks a different question: **can you work inside a real organisation, under a real supervisor, on real deadlines, and then describe honestly what you did and learned?** The running example is **InternTrail**, the invented eight-week placement of a BCA student, Anisha Gurung, at an invented Lalitpur web agency called **Himal Digital**.

| Unit | Title |
|---|---|

| 3 | Working the Weeks: Learning Plan, Daily Log and Weekly Review |
| 4 | Technical Contribution: Tickets, Code Review, Testing and Hand-over |
| 5 | Report, Presentation and Viva: Proving What You Did and Learned |

## Verification

Every program in this book was run and the printed output pasted from the real run (Python 3, fixed random seed 452). **Himal Digital, Anisha, the supervisor and every log entry are invented.** The numbers in the prose were copied from those runs.

## Source and honesty

**The unit structure is reconstructed.** BCA 452 has no published topic list; each college sets its own placement duration, supervisor forms, report format and marking. **Always follow your own college's internship guidelines and your supervisor's instructions first**; where they differ from this book, they win. Marks, rubrics and page limits in Unit 5 are illustrative, not official. Legal remarks (Labour Act 2074, Electronic Transactions Act 2063, Individual Privacy Act 2075) are general pointers, not legal advice. Check the current text before relying on them.
