# Network Administration - BCA (Semester VII/VIII elective, 3 credits)

Study notes for the TU Network Administration elective (course code CACS406 in the TU outline, Year IV, 6 hours a week: 3 theory and 3 practical; full marks 60 + 20 + 20). Five units follow the outline in its order and with its hours (4, 16, 16, 16 and 6). The prescribed text is Limoncelli, Hogan and Chalup, *The Practice of System and Network Administration* (3rd edition); the lab uses Linux (Ubuntu and CentOS-family) and Windows Server.

| Unit | Title | Hours | Outline topics covered |
|---|---|---|---|
| 1 | Introduction | 4 | network administrator as a profession, professional ethics, recent trends in network administration |
| 2 | Workstation, Server and Services | 16 | workstation architecture, hardware strategies, OS installation; server hardware strategies, features and specifications; service requirements, planning and engineering, launch, disaster recovery |
| 3 | Infrastructure | 16 | network architecture, network operations, data centres: overview and running them |
| 4 | Service Recommendation | 16 | server upgrade, centralising a service, monitoring, namespaces, e-mail, print, data storage, backup and restore, software repository, web services |
| 5 | Procurement Plan for an Enterprise Network | 6 | preparing a procurement plan and document for an enterprise-level network set-up (worked example) |

## Verification

Arithmetic (availability, subnetting, RAID capacity, backup windows, capacity and cost figures) is computed by executed Python blocks, so the printed output is real. Linux and Windows Server commands and configuration files are shown in `bash`, `ini` or `powershell` blocks that were **not** run in the build sandbox: they follow current Ubuntu 22.04/24.04, Rocky/Alma/CentOS-family 9 and Windows Server 2019/2022 behaviour. Check each one in your own lab virtual machine before an exam practical.

## Source and honesty

Units, topics and hours follow the TU CACS406 outline as reproduced at notebahadur.com and benchpartner.com.
