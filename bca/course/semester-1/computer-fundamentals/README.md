# Computer Fundamentals and Applications — BCA 101 (old code CACS101)

Semester I · 3 credits (4 in the 2074 curriculum). Seven units in TU order: 16, 3, 4, 8, 10, 6, 13 teaching hours.

| Unit | Title | Hours | What it covers |
|---|---|---|---|
| 1 | Introduction to Computer System | 16 | generations, classification, anatomy, architecture, memory, I/O devices, interfaces |
| 2 | Computer Software | 3 | system/application/utility software, translators, language generations, algorithms and flowcharts, licensing |
| 3 | Operating System | 4 | functions, types, processes and scheduling (worked FCFS/SJF/RR), paging and virtual memory, files, booting |
| 4 | Database Management System | 8 | DBMS vs files, architecture, relational model and keys, ER modelling, normalisation, SQL with checked output |
| 5 | Data Communication and Computer Network | 10 | signals, Shannon capacity, media, topologies, devices, OSI/TCP-IP, IP addressing and subnetting |
| 6 | Internet and the World Wide Web | 6 | history, DNS/URL/HTTP journey, services, search engines, security, Nepal's legal context |
| 7 | Contemporary Technologies | 13 | e-commerce, e-governance, multimedia sizes, AI/ML, IoT, big data, cloud, blockchain, VR/AR, 5G, green computing |
| 8 | Laboratory Applications | 12 | word processor (styles, mail merge, macros), spreadsheet (PMT, validation, what-if, pivot, consolidation), presentation, photo editing (bitmap/vector, colour depth, formats, layers), lab checklist |

**Practical component (Unit 8, added in session 30, covers the application packages):** the TU lab covers an OS, a word processor, a spreadsheet, a presentation package and photo editing. Practise on Windows or Linux with LibreOffice (Writer, Calc, Impress) and GIMP; Unit 8 teaches these packages; the OS and DOS labs rely on units 1–3.

## Verification

- Unit 1 numerics were recomputed (one wrong key found and fixed earlier).
- In units 2–7 every numeric answer was recomputed with a script: Shannon capacities, subnet tables, media sizes, scheduling waits (FCFS 7.25, SJF 6.25, RR 10.75), page-translation arithmetic. The SQL in unit 4 was run on SQLite and the printed results are real output.

## Source and honesty

Unit titles, hours and topic order follow the 2074 CACS101 syllabus as transcribed on notebahadur.com and bcapoint.com (hours 16/3/4/8/10/6/13 cross-read on esikhcha.com, benchpartner.com). The revised 2082-batch BCA 101 PDF could not be retrieved; if TU re-ordered units there, the content here still covers the old topics. Unit 7's topic list is the old "Contemporary Technologies" unit as the secondary sources describe it; the exact sub-topics set by TU could not be confirmed. Facts about Nepal (laws, payment systems, NRB's crypto stance) are as of writing and should be checked against current notices.
