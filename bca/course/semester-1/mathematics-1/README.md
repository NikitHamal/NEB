# Mathematics I — BCA 104 (old code CAMT104)

Semester I · 3 credits. Single-variable calculus for computing students, in six units.

| Unit | Title | Content |
|---|---|---|
| 1 | Functions and Graphs | domain/range, standard families, even/odd, composition, inverse, transformations |
| 2 | Limits and Continuity | techniques, standard limits, infinity, continuity, IVT |
| 3 | Differentiation | first principles, rules, implicit, logarithmic, parametric, higher-order |
| 4 | Applications of Derivatives | tangents, related rates, extrema, optimisation, MVT, L'Hôpital, Maclaurin series |
| 5 | Integration | substitution, parts, partial fractions, FTC, area, volume, improper integrals |
| 6 | Differential Equations | separable, homogeneous, linear, exact, second-order constant-coefficient, modelling |

## Verification

Every derivative, integral, limit, root and numeric answer in the units was checked with SymPy (`bca/tools/check_math1.py`). Where the check found a mistake in a draft answer it was fixed before publishing (see REVIEW_COURSE.md).

## Source and honesty

**The unit division here is reconstructed, not copied.** Secondary sources describe CAMT104 / BCA 104 only loosely (calculus-type content for a computing student), and the TU syllabus PDF with per-unit topic lists and hours was not retrievable. The book therefore teaches the standard single-variable calculus syllabus in the order a student needs it; **hours per unit are not stated** because they could not be verified. If your college's syllabus includes topics outside calculus (for instance matrices or vectors), check Mathematics II and the entrance-mathematics notes in `bca/entrance/mathematics`, which cover algebra, matrices, vectors and coordinate geometry.
