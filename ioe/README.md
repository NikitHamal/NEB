## Rebuild

PDFs are built by the same pipeline as the CEE and Grade 8–12 books (`notes/pipeline/build_pdf.py`, Python 3.12, WeasyPrint 70, the five book fonts from `notes/pipeline/fonts/install.sh`):

```
cd notes/pipeline && python3 build_pdf.py ioe-math ioe-phy ioe-chem ioe-eng ioe-mock    # writes notes/pdf/
python3 bca/tools/qa_pdf.py ioe/pdfs/*.pdf                                              # structural QA
```
`ioe/pdfs/` holds the copies produced for this index (built with `build_pdf.OUT` pointed at `ioe/pdfs`; no content differs from what `build_pdf.py` writes to `notes/pdf/`).

## Honest status

Not reviewed by IOE faculty. Every question is original practice written to the 2083 syllabus; none is a past paper. **No figures** (0 in every chapter) and **MCQ counts are below the authoring contract** — see the review. The exam facts are for the **2083/84 cycle**; re-verify against the next IOE notice before relying on dates, centres or eligibility.
