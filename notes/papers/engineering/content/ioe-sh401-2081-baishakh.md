@s 1
**Leibnitz's theorem.** If $u, v$ are functions of $x$ having $n$th derivatives, then $(uv)_n = \displaystyle\sum_{r=0}^n\binom nr u_{n-r}v_r = u_nv + \binom n1u_{n-1}v_1 + \cdots + uv_n$.

For $y = e^{a\tan^{-1}x}$, $y_1 = \dfrac{ay}{1+x^2}$, so $(1+x^2)y_1 = ay$. Differentiating once:
$$(1+x^2)y_2 + 2xy_1 - ay_1 = 0$$
that is
$$(1+x^2)y_2 + (2x-a)y_1 = 0 \tag{1}$$
Differentiate (1) $n$ times by Leibnitz's theorem:
$$\big[(1+x^2)y_{n+2} + 2nx\,y_{n+1} + n(n-1)y_n\big] + \big[(2x-a)y_{n+1} + 2n\,y_n\big] = 0$$
The coefficient of $y_n$ is $n(n-1) + 2n = n(n+1)$:
$$\boxed{(1+x^2)\,y_{n+2} + (2nx + 2x - a)\,y_{n+1} + n(n+1)\,y_n = 0}$$

@s 2
**Statement.** If $f$ is continuous on $[a,b]$ and differentiable on $(a,b)$, then there is at least one $c\in(a,b)$ with $f'(c) = \dfrac{f(b)-f(a)}{b-a}$.

**Proof.** Define
$$\begin{gathered}\varphi(x) = f(x) - f(a) - \frac{f(b)-f(a)}{b-a}(x-a) \\ x\in[a,b]\end{gathered}$$
$\varphi$ is continuous on $[a,b]$ and differentiable on $(a,b)$, being a combination of $f$ and a linear function. Also $\varphi(a) = 0$ and $\varphi(b) = f(b) - f(a) - (f(b)-f(a)) = 0$. By **Rolle's theorem** there is $c\in(a,b)$ with $\varphi'(c) = 0$:
$$\begin{gathered}\varphi'(c) = f'(c) - \frac{f(b)-f(a)}{b-a} = 0\;\Longrightarrow\;f'(c) = \frac{f(b)-f(a)}{b-a} \\ \blacksquare\end{gathered}$$
*Geometric meaning:* some tangent to the curve between $A(a,f(a))$ and $B(b,f(b))$ is parallel to the chord $AB$.

@s 3
As $x\to0$, $\dfrac{\tan x}{x}\to1$ and $\dfrac1{x^2}\to\infty$: the form is $1^\infty$. With $L$ the limit,
$$\log L = \lim_{x\to0}\frac{\log\tan x - \log x}{x^2}\quad\left(\tfrac00\right)$$
The derivative of the numerator is $\dfrac{\sec^2x}{\tan x} - \dfrac1x = \dfrac{2}{\sin2x} - \dfrac1x = \dfrac{2x - \sin2x}{x\sin2x}$, so
$$\log L = \lim\frac{2x - \sin2x}{2x^2\sin2x}\quad\left(\tfrac00\right)\overset{\text{L'H}}{=}\lim\frac{2 - 2\cos2x}{4x\sin2x + 4x^2\cos2x}\quad\left(\tfrac00\right)\overset{\text{L'H}}{=}\lim\frac{4\sin2x}{4\sin2x + 16x\cos2x - 8x^2\sin2x}\quad\left(\tfrac00\right)$$
$$\overset{\text{L'H}}{=}\lim\frac{8\cos2x}{8\cos2x + 16\cos2x - 32x\sin2x - 16x\sin2x - 16x^2\cos2x} = \frac{8}{24} = \frac13$$
$$\boxed{L = e^{1/3}}\approx1.3956$$
(Series check: $\dfrac{\tan x}{x} = 1 + \dfrac{x^2}3 + \cdots$, so $\log\dfrac{\tan x}x\approx\dfrac{x^2}3$.)

@s 4
$F = x^3 - 2x^2y + xy^2 + x^2 - xy + 2$; $\phi_3 = x^3 - 2x^2y + xy^2 = x(x-y)^2$, $\phi_2 = x^2 - xy$, $\phi_1 = 0$.

*Parallel to the y-axis.* The coefficient of the highest power of $y$ ($y^2$) is $x$; setting it to $0$ gives $x = 0$. As a quadratic in $y$, $xy^2 - (2x^2+x)y + (x^3+x^2+2) = 0$; as $x\to0^-$ the product of the roots is $\dfrac{x^3+x^2+2}{x}\to-\infty$, so $y\to\pm\infty$: **$x = 0$ is an asymptote.**

*Parallel to the x-axis.* The coefficient of $x^3$ is $1\ne0$, so none.

*Oblique.* Put $y/x = m$: $\phi_3(m) = 1 - 2m + m^2 = (m-1)^2$, so $m = 1$ is a **double root**. Also $\phi_2(m) = 1 - m$, so $\phi_2(1) = 0$ (needed for the double-root case). The two parallel asymptotes follow from
$$\frac{c^2}{2}\phi_3''(1) + c\,\phi_2'(1) + \phi_1(1) = 0\;\Longrightarrow\;c^2\cdot1 + c(-1) + 0 = 0\;\Longrightarrow\;c = 0,\ 1$$
(using $\phi_3'' = 2$ and $\phi_2' = -1$).
$$\boxed{x = 0,\qquad y = x,\qquad y = x + 1}$$
*Check:* on $y = x + c$ ($c = 0, 1$) the equation reduces to the constant $2$ (degree $0 < 2$). $\checkmark$

@s 5
**Curvature** $\kappa$ of a curve at a point is the rate at which the direction of the tangent turns per unit arc length, $\kappa = \dfrac{d\psi}{ds}$ ($\psi$ = angle of the tangent). The **radius of curvature** is $\rho = \dfrac1\kappa = \dfrac{ds}{d\psi}$; for a parametric curve,
$$\rho = \frac{(x'^2 + y'^2)^{3/2}}{|x'y'' - y'x''|}$$
The curve $\sqrt x + \sqrt y = \sqrt a$ can be written $x = a\cos^4t$, $y = a\sin^4t$. It meets $y = x$ where $2\sqrt x = \sqrt a$, i.e. $x = y = \dfrac a4$, which is $t = \dfrac\pi4$. Differentiate:
$$x' = -4a\cos^3t\sin t,\quad y' = 4a\sin^3t\cos t$$
$$x'' = 4a\cos^2t\,(3\sin^2t - \cos^2t),\quad y'' = 4a\sin^2t\,(3\cos^2t - \sin^2t)$$
At $t = \dfrac\pi4$, $\sin t = \cos t = \dfrac1{\sqrt2}$: $x' = -a$, $y' = a$, $x'' = 2a$, $y'' = 2a$. Hence
$$\begin{gathered}x'^2 + y'^2 = 2a^2 \\ x'y'' - y'x'' = -2a^2 - 2a^2 = -4a^2\end{gathered}$$
$$\begin{gathered}\rho = \frac{(2a^2)^{3/2}}{4a^2} = \frac{2\sqrt2\,a^3}{4a^2} = \boxed{\frac{a}{\sqrt2}} \\ \blacksquare\end{gathered}$$

Let $J = \displaystyle\int_0^{\pi/2}\log\sin x\,dx$. Using $\displaystyle\int_0^{a}f(x)\,dx = \int_0^af(a-x)\,dx$, also $J = \displaystyle\int_0^{\pi/2}\log\cos x\,dx$. Adding,
$$2J = \int_0^{\pi/2}\log(\sin x\cos x)\,dx = \int_0^{\pi/2}\log\frac{\sin2x}{2}\,dx = \int_0^{\pi/2}\log\sin2x\,dx - \frac\pi2\log2$$
With $\phi = 2x$, $\displaystyle\int_0^{\pi/2}\log\sin2x\,dx = \frac12\int_0^\pi\log\sin\phi\,d\phi = \int_0^{\pi/2}\log\sin\phi\,d\phi = J$ (because $\sin\phi$ is symmetric about $\phi = \pi/2$). Therefore $2J = J - \dfrac\pi2\log2$, so
$$\begin{gathered}\boxed{J = -\frac\pi2\log2 = \frac\pi2\log\frac12} \\ \blacksquare\end{gathered}$$

@s 7
Let $A = a^2$, $B = b^2$ and
$$\Phi(A,B) = \int_0^{\pi/2}\frac{dx}{A\sin^2x + B\cos^2x}$$
Put $t = \tan x$: $\Phi = \displaystyle\int_0^\infty\frac{dt}{At^2 + B} = \frac{1}{\sqrt{AB}}\Big[\tan^{-1}\sqrt{\tfrac AB}\,t\Big]_0^\infty = \frac{\pi}{2\sqrt{AB}}$.

Differentiating under the integral sign with respect to $A$ and $B$ (limits are constants):
$$-\frac{\partial\Phi}{\partial A} = \int_0^{\pi/2}\frac{\sin^2x\,dx}{(A\sin^2x + B\cos^2x)^2} = \frac{\pi}{4A^{3/2}B^{1/2}}$$
$$-\frac{\partial\Phi}{\partial B} = \int_0^{\pi/2}\frac{\cos^2x\,dx}{(A\sin^2x + B\cos^2x)^2} = \frac{\pi}{4A^{1/2}B^{3/2}}$$
Add the two (since $\sin^2x + \cos^2x = 1$):
$$\int_0^{\pi/2}\frac{dx}{(A\sin^2x + B\cos^2x)^2} = \frac\pi4\cdot\frac{B + A}{A^{3/2}B^{3/2}}$$
and with $A = a^2$, $B = b^2$:
$$\begin{gathered}\boxed{\int_0^{\pi/2}\frac{dx}{(a^2\sin^2x + b^2\cos^2x)^2} = \frac{\pi(a^2+b^2)}{4a^3b^3}} \\ \blacksquare\end{gathered}$$

@s 9
$y^2 = \dfrac{x^2(a^2-x^2)}{a^2+x^2}$ is real for $-a\le x\le a$ and symmetric about both axes; it consists of two loops, one in $0\le x\le a$ and one in $-a\le x\le0$, meeting at the origin. The area of one loop is $2\displaystyle\int_0^ay\,dx$:
$$A = 2\int_0^ax\sqrt{\frac{a^2-x^2}{a^2+x^2}}\,dx$$
Put $x^2 = u$, $2x\,dx = du$: $A = \displaystyle\int_0^{a^2}\sqrt{\frac{a^2-u}{a^2+u}}\,du$. Let $u = a^2\cos\varphi$, $du = -a^2\sin\varphi\,d\varphi$, $\varphi: \tfrac\pi2\to0$:

$$A = a^2\int_0^{\pi/2}(1-\cos\varphi)\,d\varphi = \boxed{a^2\left(\frac\pi2 - 1\right)}\approx0.5708\,a^2$$

**The equation as printed**, $y = px + x^4p^2$, is not of Clairaut's form. Put $x = \dfrac1u$, so that $p = -u^2q$ with $q = \dfrac{dy}{du}$; then $px = -uq$ and $x^4p^2 = q^2$, and the equation becomes
$$y = -uq + q^2\tag{1}$$
Differentiate (1) with respect to $u$: $q = -q - u\dfrac{dq}{du} + 2q\dfrac{dq}{du}$, i.e. $2q = (2q - u)\dfrac{dq}{du}$. Treat $u$ as a function of $q$:
$$\begin{gathered}\frac{du}{dq} = \frac{2q-u}{2q} = 1 - \frac{u}{2q}\;\Longrightarrow\;\frac{du}{dq} + \frac{u}{2q} = 1 \\ \text{IF} = \sqrt q\end{gathered}$$
$$u\sqrt q = \frac23q^{3/2} + C\;\Longrightarrow\;u = \frac23q + \frac{C}{\sqrt q}$$
Put back in (1): $y = q^2 - uq = \dfrac{q^2}3 - C\sqrt q$. Hence the general solution in parametric form (parameter $q$, with $x = 1/u$):
$$\boxed{x = \frac{3\sqrt q}{2q^{3/2} + 3C},\qquad y = \frac{q^2}{3} - C\sqrt q}$$
Particular members: $C = 0$ gives $q = \dfrac{3}{2x}$ and $y = \dfrac{3}{4x^2}$ (check: $p = -\dfrac{3}{2x^3}$, $px + x^4p^2 = -\dfrac{3}{2x^2} + \dfrac{9}{4x^2} = \dfrac3{4x^2}$ ✓). Also $y = 0$ satisfies the equation ($p = 0$).

@s 15
**Definition.** An ellipse is the locus of a point $P$ whose distance from a fixed point $S$ (focus) is $e\,(<1)$ times its distance from a fixed line (directrix). Equivalently, $PS + PS' = 2a$ for two foci $S, S'$ with $SS'<2a$.

**Derivation.** Choose axes so that the centre is the origin and the x-axis passes through the focus: $S = (ae, 0)$, directrix $x = \dfrac ae$ (the vertices $A$, $A'$ divide $SZ$ internally and externally in the ratio $e:1$, and $AA' = 2a$). For $P(x,y)$, $SP = e\cdot PM$:
$$(x-ae)^2 + y^2 = e^2\left(\frac ae - x\right)^2 = (a - ex)^2$$
$$x^2 - 2aex + a^2e^2 + y^2 = a^2 - 2aex + e^2x^2\;\Longrightarrow\;(1-e^2)x^2 + y^2 = a^2(1-e^2)$$
With $b^2 = a^2(1-e^2)$ (positive as $e<1$):
$$\boxed{\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1}$$
The symmetry about the $y$-axis gives the second focus $S'(-ae,0)$ and directrix $x = -\dfrac ae$. Centre $(0,0)$; vertices $(\pm a,0)$; foci $(\pm ae,0)$; major axis $2a$; minor axis $2b$; latus rectum $\dfrac{2b^2}{a}$; and $PS + PS' = 2a$.

**OR.** $S = x^2 + 4xy + y^2 - 2x + 2y - 6$: $a = 1$, $h = 2$, $b = 1$, $h^2 - ab = 3>0$ and
$$\Delta = \begin{vmatrix}1&2&-1\\2&1&1\\-1&1&-6\end{vmatrix} = 1(-7) - 2(-11) + (-1)(3) = 12\ne0$$
so the conic is a **hyperbola**.

**Centre.** $\partial S/\partial x = 2x + 4y - 2 = 0$ and $\partial S/\partial y = 4x + 2y + 2 = 0$ give $x + 2y = 1$, $2x + y = -1$, so $x = -1$, $y = 1$. Centre $= \boxed{(-1, 1)}$.

**Reduced form.** Shift to the centre: the constant is $S(-1,1) = 1 - 4 + 1 + 2 + 2 - 6 = -4$, so $X^2 + 4XY + Y^2 = 4$. The matrix $\begin{pmatrix}1&2\\2&1\end{pmatrix}$ has eigenvalues $3$ (eigenvector $(1,1)$) and $-1$ (eigenvector $(-1,1)$); the axes are turned through $45^\circ$:
$$\begin{gathered}3u^2 - v^2 = 4\;\Longrightarrow\;\frac{u^2}{4/3} - \frac{v^2}{4} = 1 \\ a^2 = \frac43,\ b^2 = 4\end{gathered}$$
- Eccentricity: $e = \sqrt{1 + \dfrac{b^2}{a^2}} = \sqrt{1 + 3} = \boxed{2}$.
- $c = ae = \dfrac{2}{\sqrt3}\cdot2 = \dfrac{4}{\sqrt3}$; the foci lie on the transverse axis (direction $(1,1)$ through the centre) at a distance $c$ from it:
$$\boxed{\text{Foci}\;\left(-1\pm\frac{2\sqrt6}{3},\ 1\pm\frac{2\sqrt6}{3}\right)}\approx(0.633,\,2.633)\text{ and }(-2.633,\,-0.633)$$
- Vertices: $\left(-1\pm\sqrt{\tfrac23},\ 1\pm\sqrt{\tfrac23}\right)$; transverse axis $2a = \dfrac{4}{\sqrt3}\approx2.31$, conjugate axis $2b = 4$; asymptotes $X^2 + 4XY + Y^2 = 0$, i.e. $Y = (-2\pm\sqrt3)X$.
