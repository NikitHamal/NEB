@s 1
**(a) Countably infinite set.** An infinite set $S$ is *countably infinite* if there is a one-to-one correspondence (bijection) $f:\mathbb N\to S$, i.e. its elements can be listed as $s_0,s_1,s_2,\dots$ with every element appearing at some finite position. Examples: the integers $\mathbb Z$ ($0,1,-1,2,-2,\dots$), the even numbers, the rationals $\mathbb Q$ and the set $\Sigma^*$ of all strings over a finite alphabet.

**Uncountable set.** An infinite set that is *not* countable, i.e. no bijection with $\mathbb N$ exists. Example: the real numbers in $(0,1)$. *Cantor's diagonal argument:* suppose the reals can be listed $r_1,r_2,\dots$ as decimal expansions. Build $d$ whose $n$-th digit differs from the $n$-th digit of $r_n$ (use 5 if that digit is not 5, otherwise 6). Then $d\in(0,1)$ differs from every $r_n$ in the $n$-th place, so it is not on the list, a contradiction. Another example: the power set $2^{\mathbb N}$, equivalently the set of all languages over $\{0,1\}$.

**Tautology check.** The formula is $((P\to Q)\land(Q\to R))\to(P\to R)$ (hypothetical syllogism). Truth table (computed for all 8 rows):

| $P$ | $Q$ | $R$ | $P\to Q$ | $Q\to R$ | $(P\to Q)\land(Q\to R)$ | $P\to R$ | whole formula |
|---|---|---|---|---|---|---|---|
| T | T | T | T | T | T | T | **T** |
| T | T | F | T | F | F | F | **T** |
| T | F | T | F | T | F | T | **T** |
| T | F | F | F | T | F | F | **T** |
| F | T | T | T | T | T | T | **T** |
| F | T | F | T | F | F | T | **T** |
| F | F | T | T | T | T | T | **T** |
| F | F | F | T | T | T | T | **T** |

The last column is true in every row, so the proposition is a **tautology**. (Algebraic proof: if $P\to Q$ and $Q\to R$ hold and $P$ is true, then $Q$ is true and then $R$ is true; so $P\to R$ cannot be false while the hypothesis is true.)

**(b) Statement:** "I will go swimming only if it is sunny." Let $p$: I go swimming, $q$: it is sunny. "$p$ only if $q$" is $p\to q$.

- *Converse* ($q\to p$): If it is sunny, then I will go swimming.
- *Inverse* ($\lnot p\to\lnot q$): If I do not go swimming, then it is not sunny.
- *Contrapositive* ($\lnot q\to\lnot p$): If it is not sunny, then I will not go swimming. (Equivalent to the original statement.)

**Induction: $3\mid 4^n-1$.**

*Basis* $n=1$ (or $n=0$): $4^1-1=3=3\cdot1$ (and $4^0-1=0$), divisible by 3.

*Step.* Assume $4^k-1=3m$ for some integer $m$. Then

$$4^{k+1}-1 = 4\cdot4^k-1 = 4(4^k-1)+3 = 4\cdot3m+3 = 3(4m+1),$$

which is divisible by 3. By mathematical induction $4^n-1$ is divisible by 3 for all $n\ge1$. $\blacksquare$

**(a) DFA against NFA.**

| Basis | DFA | NFA |
|---|---|---|
| Transition | $\delta:Q\times\Sigma\to Q$ (exactly one next state) | $\delta:Q\times\Sigma\to 2^Q$ (zero, one or many next states; may have $\varepsilon$-moves) |
| Missing moves | every state has a move on every symbol | a move may be undefined (the branch dies) |
| Computation | a single path per input | a tree of paths; accepted if *some* path accepts |
| Implementation | easy, fast | needs back-tracking or conversion to a DFA |
| Size | may need up to $2^n$ states for an $n$-state NFA | usually smaller, easier to design |
| Power | regular languages | same regular languages |

@s 3
**(a) Not closed under intersection.** Let $L_1=\{a^nb^nc^m : n,m\ge0\}$ (grammar $S\to XC$, $X\to aXb\mid\varepsilon$, $C\to cC\mid\varepsilon$) and $L_2=\{a^mb^nc^n : n,m\ge0\}$ (grammar $S\to AY$, $A\to aA\mid\varepsilon$, $Y\to bYc\mid\varepsilon$). Both are context-free, but

$$L_1\cap L_2=\{a^nb^nc^n : n\ge0\},$$

which is not context-free (pumping lemma for CFLs: a pumped string cannot keep the three counts equal). So the class is not closed under intersection.

**Not closed under complement.** Suppose it were closed. Then for CFLs $L_1,L_2$ the language $\overline{\overline{L_1}\cup\overline{L_2}}$ would be context-free, because CFLs are closed under union (new start $S\to S_1\mid S_2$). By De Morgan this language equals $L_1\cap L_2$, contradicting the previous result. Hence CFLs are not closed under complementation. (Concretely, $\overline{\{a^nb^nc^n\}}$ *is* context-free, but the complement of that language is not.)

**Closed under Kleene star.** Let $G=(V,T,P,S)$ generate $L$. Add a new start symbol $S'$ and the rules $S'\to SS'\mid\varepsilon$. Then $S'\Rightarrow^* S^k$ for every $k\ge0$ and each $S$ derives a string of $L$, so the new grammar generates $L^*$. Hence $L^*$ is context-free. $\blacksquare$

**(c) Greibach Normal Form.** A CFG is in GNF if every production has the form $A\to a\alpha$ where $a$ is a terminal and $\alpha\in V^*$ (a string of variables, possibly empty): each right side starts with exactly one terminal followed only by variables (e.g. $A\to aBC$, $B\to b$). GNF guarantees that a leftmost derivation adds one terminal per step, so a string of length $n$ is derived in $n$ steps, and it is used to build PDAs without $\varepsilon$-moves.

**Conversion to CNF.** $G$: $S\to AAC$, $A\to aAb\mid\varepsilon$, $C\to aC\mid a$.

*Step 1: remove $\varepsilon$-productions.* The only nullable variable is $A$. Expand every occurrence of $A$ in all ways:
$S\to AAC\mid AC\mid C$ (the cases "both $A$'s kept", "one removed", "both removed"), $A\to aAb\mid ab$, $C\to aC\mid a$.

*Step 2: remove unit productions.* $S\to C$ is replaced by the rules of $C$: $S\to aC\mid a$. So
$S\to AAC\mid AC\mid aC\mid a$; $A\to aAb\mid ab$; $C\to aC\mid a$.

*Step 3: terminals in long right sides.* Introduce $T_a\to a$, $T_b\to b$:
$S\to AAC\mid AC\mid T_aC\mid a$; $A\to T_aAT_b\mid T_aT_b$; $C\to T_aC\mid a$.

*Step 4: break right sides longer than 2.* $S\to AAC$ becomes $S\to AD_1$, $D_1\to AC$; $A\to T_aAT_b$ becomes $A\to T_aD_2$, $D_2\to AT_b$.

$$\boxed{\begin{aligned}
S&\to AD_1\mid AC\mid T_aC\mid a\\
D_1&\to AC\\
A&\to T_aD_2\mid T_aT_b\\
D_2&\to AT_b\\
C&\to T_aC\mid a\\
T_a&\to a,\qquad T_b\to b
\end{aligned}}$$

Every rule is now $X\to YZ$ or $X\to a$: Chomsky Normal Form. (Computer check: the original grammar and this CNF grammar generate the same 126 strings of length $\le 14$.)

**(c) Multi-tape Turing machine.** A $k$-tape TM has one finite control and $k$ tapes, each with its **own read/write head**. The first tape holds the input, the other tapes start blank. The configuration is $(q;\ \alpha_1 \underline{a_1}\beta_1,\ \dots,\ \alpha_k\underline{a_k}\beta_k)$: the current state plus the content and head position of each tape. One move reads the $k$ scanned symbols together, and depending on the state it writes a new symbol on each tape, moves each head independently (L, R or S) and changes state:

$$\delta(q,a_1,\dots,a_k)=(p,\;b_1,\dots,b_k,\;D_1,\dots,D_k)$$

*Working example.* To test whether $w$ is a palindrome: copy $w$ to tape 2, move head 2 to the end, then compare tape 1 left to right with tape 2 right to left. $a^nb^n$ is recognised in $O(n)$ steps by copying the $a$'s to tape 2 and matching them against the $b$'s. A multi-tape machine recognises exactly the same languages as a single-tape machine (a one-tape machine simulates $k$ tapes on tracks, at the cost of a quadratic slowdown, $O(t^2)$), but programs are much shorter and faster.

**Storage in the states.** The finite control may remember a fixed number of symbols by making each state a pair $[q,x]$. Example: the language of strings over $\{a,b\}$ whose **first and last symbol are equal**. Store the first symbol in the state, run to the end, step back and compare:

| State | Read | Write | Move | Next |
|---|---|---|---|---|
| q0 | a | a | R | q1a |
| q0 | b | b | R | q1b |
| q1a | a | a | R | q1a |
| q1a | b | b | R | q1a |
| q1a | B | B | L | q2a |
| q1b | a | a | R | q1b |
| q1b | b | b | R | q1b |
| q1b | B | B | L | q2b |
| q2a | a | a | S | qf |
| q2b | b | b | S | qf |

States $q_{1a},q_{1b},q_{2a},q_{2b}$ are the pairs "scanning, first symbol is $a$ / $b$" and "checking last symbol, first symbol is $a$ / $b$". The machine accepts $aba$, $b$, $abba$ and rejects $ab$ and the empty string. Trace for $w=abba$:

`[q0]abba` ⊢ `a[q1a]bba` ⊢ `ab[q1a]ba`

`abb[q1a]a` ⊢ `abba[q1a]_` ⊢ `abb[q2a]a`

`abb[qf]a`

No tape cell was needed to remember the first symbol, which is exactly the benefit of storage in states (verified on all strings over $\{a,b\}$ up to length 10).

**(a) Time and space complexity of a TM.** For a TM $M$ that halts on every input, the **time complexity** $T(n)$ is the maximum number of moves made on any input of length $n$; the **space complexity** $S(n)$ is the maximum number of distinct tape cells scanned on any input of length $n$. A language is in **P** if some deterministic TM decides it in $T(n)=O(n^k)$ for some constant $k$; it is in **NP** if a non-deterministic TM decides it in polynomial time (equivalently, a proposed solution can be *verified* in polynomial time). $P\subseteq NP$, and whether $P=NP$ is open.

**NP-complete problems.** A language $L$ is NP-complete if

1. $L\in NP$, and
2. every language $L'\in NP$ is polynomial-time reducible to $L$ ($L'\le_pL$); that is, $L$ is NP-hard.

They are the hardest problems in NP: if any NP-complete problem has a polynomial-time algorithm then $P=NP$. The first one, **SAT** (is a Boolean formula satisfiable?), was proved NP-complete by Cook and Levin; others follow by reduction: $\text{SAT}\le_p\text{3-SAT}\le_p\text{Clique}\le_p\text{Vertex Cover}$, and Hamiltonian cycle, travelling-salesman (decision version), subset-sum, graph 3-colouring, knapsack (decision). To prove a new problem NP-complete show membership in NP (a certificate is checked in polynomial time) and reduce a known NP-complete problem to it.

**(b) Church–Turing thesis.** Every function that can be computed by an effective procedure (an algorithm, in the intuitive sense) can be computed by a Turing machine. It is a *thesis*, not a theorem, because "effective procedure" is informal; all known models (lambda calculus, recursive functions, RAM machines, programming languages) have been shown equivalent to TMs.

**The complement of a recursive language is recursive.** Let $L$ be recursive, so there is a TM $M$ that *halts on every input* and accepts exactly $L$. Build $M'$: it simulates $M$ on $w$; if $M$ accepts, $M'$ rejects (goes to a non-accepting halt); if $M$ rejects, $M'$ accepts. (Make $M$'s halting states explicit: swap the accepting and rejecting halting states.) Because $M$ always halts, $M'$ always halts, and $M'$ accepts $w$ iff $M$ rejects $w$ iff $w\in\overline L$. So $\overline L$ is recursive. $\blacksquare$ (This argument fails for recursively enumerable languages, because $M$ may loop.)

1. **Lexical analysis** groups characters into tokens. 2. **Syntax analysis** builds the parse tree from the tokens using the grammar. 3. **Semantic analysis** checks types, declarations and scope. 4. **Intermediate code generation** produces machine-independent code (three-address code). 5. **Code optimisation** improves speed and size. 6. **Code generation** emits target (assembly / machine) code. The **symbol table** (names, types, scope) and the **error handler** are used by all phases. Front end = phases 1-4 (analysis), back end = 5-6 (synthesis).

**Token generation by the lexical analyzer.** The scanner reads the characters of the source one by one, skips white-space and comments, and matches the longest prefix against the regular-expression patterns of the token classes (compiled into a DFA): keyword (`int`, `if`, `else`, `return`), identifier (letter followed by letters/digits), operator (`>`), punctuation (`( ) { } , ;`). **(b) Syntax analyzer and CFG.** The **CFG** is the *specification* of the syntax of the programming language (rules such as $\textit{stmt}\to \textbf{if}\,(\textit{cond})\,\textit{stmt}\ \textbf{else}\ \textit{stmt}$), and the **syntax analyzer (parser)** is the *implementation* of that specification: it takes the token stream and tries to derive it from the start symbol of the CFG (top-down, as in LL parsing, or bottom-up, as in LR parsing). If a derivation exists the parser outputs the parse tree, otherwise it reports a syntax error. Parser generators (YACC/Bison) turn a CFG directly into a parser.
