@s 1
**Leibnitz's theorem.** If $u$ and $v$ are functions of $x$ with derivatives of every order up to $n$, the $n$th derivative of the product is
$$\boxed{(uv)_n = u_nv + {}^nC_1u_{n-1}v_1 + {}^nC_2u_{n-2}v_2 + \cdots + {}^nC_ru_{n-r}v_r + \cdots + uv_n}$$

**Solving for $y$.** Put $t = y^{1/m}$. Then $t + \dfrac1t = 2x$, i.e. $t^2 - 2xt + 1 = 0$, so $t = x\pm\sqrt{x^2-1}$. Taking the $+$ sign (the $-$ sign gives the same function with $m\to-m$):
$$y = \left(x + \sqrt{x^2 - 1}\right)^m$$
Differentiate: $y_1 = m\left(x+\sqrt{x^2-1}\right)^{m-1}\left(1 + \dfrac{x}{\sqrt{x^2-1}}\right) = \dfrac{m\left(x+\sqrt{x^2-1}\right)^m}{\sqrt{x^2-1}}$, so
$$\begin{gathered}\sqrt{x^2 - 1}\;y_1 = my \\ (1)\end{gathered}$$

**(a)** Differentiate (1) again:
$$\sqrt{x^2-1}\;y_2 + \frac{x}{\sqrt{x^2-1}}\,y_1 = my_1$$
Multiply by $\sqrt{x^2-1}$:
$$(x^2-1)y_2 + xy_1 = m\sqrt{x^2-1}\,y_1 = m(my)$$
$$\begin{gathered}\boxed{(x^2-1)y_2 + xy_1 - m^2y = 0} \\ (2)\end{gathered}$$

**(b)** Differentiate (2) $n$ times with Leibnitz's theorem:

- $\dfrac{d^n}{dx^n}\big[(x^2-1)y_2\big] = (x^2-1)y_{n+2} + n(2x)y_{n+1} + \dfrac{n(n-1)}{2}(2)y_n$
- $\dfrac{d^n}{dx^n}\big[xy_1\big] = xy_{n+1} + n(1)y_n$
- $\dfrac{d^n}{dx^n}\big[m^2y\big] = m^2y_n$

Adding, with the sign as in (2):
$$(x^2-1)y_{n+2} + (2n+1)xy_{n+1} + \big[n(n-1) + n - m^2\big]y_n = 0$$
$$\boxed{(x^2-1)y_{n+2} + (2n+1)xy_{n+1} + (n^2 - m^2)y_n = 0}$$
$\blacksquare$

@s 2
**Rolle's theorem.** If $f$ is (i) continuous on $[a,b]$, (ii) differentiable on $(a,b)$ and (iii) $f(a) = f(b)$, then there is at least one $c\in(a,b)$ with $f'(c) = 0$.

**Mean Value (Lagrange's) theorem.** If $f$ is continuous on $[a,b]$ and differentiable on $(a,b)$, there is at least one $c\in(a,b)$ with
$$f'(c) = \frac{f(b) - f(a)}{b - a}$$

**Geometrical interpretation.** $\dfrac{f(b)-f(a)}{b-a}$ is the slope of the chord $AB$ joining $(a, f(a))$ and $(b, f(b))$ and $f'(c)$ is the slope of the tangent at $x = c$. So, for a smooth arc, there is at least one point $C$ on the arc between $A$ and $B$ where the tangent is parallel to the chord $AB$. For Rolle's theorem the chord is horizontal ($f(a) = f(b)$), so the tangent at $C$ is horizontal.

```figure caption="Question 2: Mean Value theorem: the tangent at C is parallel to the chord AB."

```

**Is it applicable to $f(x) = \dfrac1{x^2}$ on $[-1,1]$?** We have $f(-1) = f(1) = 1$, so condition (iii) holds. But $f$ is **not defined at $x = 0\in[-1,1]$**, and $f(x)\to\infty$ as $x\to0$: $f$ is not continuous on $[-1,1]$, so condition (i) fails (it is not differentiable at $0$ either).
$$f'(x) = -\frac{2}{x^3}\ne0\ \ \text{for every}\ x\ne0$$
so there is no point where $f'(c) = 0$; the conclusion is false. For the Mean Value theorem the chord slope is $\dfrac{f(1)-f(-1)}{2} = 0$, and again $f' = 0$ nowhere.

$$\boxed{\text{Not applicable: }f\text{ is discontinuous (undefined) at }x = 0.}$$
This shows why the continuity condition cannot be dropped from the theorem.

**Indeterminate forms.** A function $f(x) = \dfrac{g(x)}{h(x)}$ (or a combination such as $g - h$, $g\cdot h$, $g^h$) is said to take an indeterminate form at $x = a$ if direct substitution gives a meaningless symbol: $\dfrac00,\ \dfrac\infty\infty,\ 0\cdot\infty,\ \infty - \infty,\ 0^0,\ 1^\infty,\ \infty^0$. Its value (the limit) is found by L'Hôpital's rule or series expansion.

**Limit.** At $x\to0$ the expression is of the form $\infty - \infty$. Combine:
$$\frac1{x^2} - \frac1{\sin^2x} = \frac{\sin^2x - x^2}{x^2\sin^2x}$$
Now use $\sin x = x - \dfrac{x^3}{6} + \cdots$, so $\sin^2x = x^2 - \dfrac{x^4}{3} + \cdots$, and $\sin^2x - x^2 = -\dfrac{x^4}{3} + O(x^6)$. Hence
$$\lim_{x\to0}\frac{-\frac{x^4}{3} + O(x^6)}{x^2\left(x^2 - \frac{x^4}{3}+\cdots\right)} = \lim_{x\to0}\frac{-\frac13 + O(x^2)}{1 - \frac{x^2}3 + \cdots}$$
$$\boxed{\lim_{x\to0}\left(\frac1{x^2} - \frac1{\sin^2x}\right) = -\frac13}$$
(Check by L'Hôpital: $\dfrac{\sin^2x - x^2}{x^2\sin^2x}$, differentiate numerator and denominator repeatedly with $\sin^2x = \tfrac12(1-\cos2x)$; after four differentiations numerator $\to-8$, denominator $\to24$, giving $-\tfrac13$.)

**Asymptote.** A straight line is an asymptote of a curve if the perpendicular distance from a point $P$ on the curve to the line tends to zero as $P$ moves to infinity along the curve (equivalently, the line is a tangent to the curve at infinity).

Write the curve in the form $\phi_3 + \phi_2 + \phi_1 + \phi_0 = 0$ (highest-degree terms first), degree 3:
$$\phi_3 = (x-y)^2(x-2y),\quad\phi_2 = 2(x-y)^2,\quad\phi_1 = -x - 9y,\quad\phi_0 = 2$$
Put $x = 1$, $y = m$:
$$\phi_3(m) = (1-m)^2(1-2m),\quad\phi_2(m) = 2(1-m)^2,\quad\phi_1(m) = -(1+9m)$$
Slopes of asymptotes: $\phi_3(m) = 0\Rightarrow m = 1$ (twice) and $m = \tfrac12$.

**(i) $m = \tfrac12$** (simple root). $y = mx + c$ with $c = -\dfrac{\phi_2(m)}{\phi_3'(m)}$.
$$\begin{gathered}\phi_3'(m) = -2(1-m)(1-2m) - 2(1-m)^2\ \Rightarrow\ \phi_3'(\tfrac12) = 0 - 2\left(\tfrac14\right) = -\tfrac12 \\ \phi_2(\tfrac12) = \tfrac12\end{gathered}$$
$$c = -\frac{1/2}{-1/2} = 1\ \Rightarrow\ y = \frac x2 + 1\ \Rightarrow\ x - 2y + 2 = 0$$
**(ii) $m = 1$** (repeated root). Here $\phi_3(1) = 0$ and $\phi_3'(1) = 0$, so $c$ satisfies
$$\frac{c^2}{2!}\phi_3''(m) + c\,\phi_2'(m) + \phi_1(m) = 0$$
$$\begin{gathered}\phi_3''(1) = 2(1 - 2) = -2 \\ \phi_2'(1) = -4(1-m)\big|_{m=1} = 0 \\ \phi_1(1) = -10\end{gathered}$$
$$-c^2 + 0 - 10 = 0\ \Rightarrow\ c^2 = -10$$
which has no real solution, so there are **no real asymptotes parallel to $x = y$** (the two roots are imaginary, i.e. the curve has no real branch going off in that direction).

$$\boxed{\text{Only one real asymptote: }x - 2y + 2 = 0}$$

For $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ use the parametric form $x = a\cos t,\ y = b\sin t$:
$$\dot x = -a\sin t,\quad\dot y = b\cos t,\quad\ddot x = -a\cos t,\quad\ddot y = -b\sin t$$
$$\rho = \frac{(\dot x^2 + \dot y^2)^{3/2}}{|\dot x\ddot y - \dot y\ddot x|} = \frac{(a^2\sin^2t + b^2\cos^2t)^{3/2}}{|ab\sin^2t + ab\cos^2t|} = \frac{(a^2\sin^2t + b^2\cos^2t)^{3/2}}{ab}$$
The extremities of the major axis (taking $a>b$) are $(\pm a, 0)$, i.e. $t = 0$ or $\pi$; there $\sin t = 0$:
$$\rho = \frac{(b^2)^{3/2}}{ab} = \frac{b^2}{a}$$
The latus rectum of the ellipse is $\dfrac{2b^2}a$ (the chord through a focus perpendicular to the major axis: put $x = ae$ in the equation, $y = \pm\dfrac{b^2}{a}$), so
$$\boxed{\rho_{\text{at extremity}} = \frac{b^2}a = \frac12\,(\text{length of latus rectum})}$$
$\blacksquare$

**Fundamental theorem of integral calculus.** (Part 1) If $f$ is continuous on $[a,b]$ then $F(x) = \displaystyle\int_a^xf(t)\,dt$ is differentiable and $F'(x) = f(x)$: integration and differentiation are inverse processes. (Part 2) If $\phi$ is any antiderivative of $f$ ($\phi' = f$), then
$$\int_a^bf(x)\,dx = \phi(b) - \phi(a)$$

**Evaluation.** Let $I = \displaystyle\int_0^a\frac{\sqrt x}{\sqrt x + \sqrt{a-x}}\,dx$. Use $\displaystyle\int_0^af(x)\,dx = \int_0^af(a-x)\,dx$:
$$I = \int_0^a\frac{\sqrt{a-x}}{\sqrt{a-x} + \sqrt x}\,dx$$
Adding the two expressions:
$$2I = \int_0^a\frac{\sqrt x + \sqrt{a-x}}{\sqrt x + \sqrt{a-x}}\,dx = \int_0^a1\,dx = a$$
$$\boxed{I = \frac a2}$$

@s 7
Let $I(a) = \displaystyle\int_0^\infty\frac{e^{-ax}\sin x}{x}\,dx$, $a\ge0$. Differentiate under the integral sign (Leibnitz rule, limits constant):
$$\frac{dI}{da} = \int_0^\infty\frac{\partial}{\partial a}\left(\frac{e^{-ax}\sin x}{x}\right)dx = -\int_0^\infty e^{-ax}\sin x\,dx$$
Use $\displaystyle\int_0^\infty e^{-ax}\sin bx\,dx = \frac{b}{a^2+b^2}$ with $b = 1$:
$$\frac{dI}{da} = -\frac{1}{1 + a^2}\ \Rightarrow\ I(a) = -\tan^{-1}a + C$$
To find $C$, let $a\to\infty$: $e^{-ax}\to0$ so $I\to0$, giving $0 = -\dfrac\pi2 + C$, $C = \dfrac\pi2$.
$$\boxed{\int_0^\infty\frac{e^{-ax}\sin x}{x}\,dx = \frac\pi2 - \tan^{-1}a = \cot^{-1}a}$$
**Deduction.** Put $a = 0$:
$$\int_0^\infty\frac{\sin x}{x}\,dx = \frac\pi2 - \tan^{-1}0 = \boxed{\frac\pi2}$$
$\blacksquare$

@s 10
**Bernoulli's differential equation** is a first-order equation of the form
$$\begin{gathered}\frac{dy}{dx} + P(x)\,y = Q(x)\,y^n \\ n\ne0,1\end{gathered}$$
It is reduced to a linear equation by dividing by $y^n$ and putting $v = y^{1-n}$. *Example:* $\dfrac{dy}{dx} + \dfrac yx = xy^2$, with $v = 1/y$ it becomes $\dfrac{dv}{dx} - \dfrac vx = -x$, giving $\dfrac1y = x(C - x)$. More generally, an equation that becomes linear after a substitution $v = f(y)$ (here $f = \sin^{-1}$ or $1/\sin y$) is "Bernoulli-type" in $f(y)$.

**Solving the given equation**
$$\frac{dy}{dx} + \frac1x\tan y = \frac1{x^2}\tan y\sin y$$
*Reading note:* the scan shows the right side with its sign/fraction bar blurred; it is taken as $+\dfrac1{x^2}\tan y\sin y$. (For the other sign the method is identical, see the end.)

Divide by $\tan y$:
$$\cot y\,\frac{dy}{dx} + \frac1x = \frac{\sin y}{x^2}$$
Divide by $\sin y$:
$$\frac{\cos y}{\sin^2y}\frac{dy}{dx} + \frac1{x\sin y} = \frac1{x^2}$$
Put $v = \dfrac1{\sin y} = \operatorname{cosec}y$, so $\dfrac{dv}{dx} = -\dfrac{\cos y}{\sin^2y}\dfrac{dy}{dx}$:
$$-\frac{dv}{dx} + \frac vx = \frac1{x^2}\ \Rightarrow\ \frac{dv}{dx} - \frac1xv = -\frac1{x^2}$$
This is linear in $v$, integrating factor $\text{I.F.} = e^{-\int dx/x} = \dfrac1x$:
$$\frac vx = \int\left(-\frac1{x^2}\right)\frac1x\,dx = \int-x^{-3}dx = \frac1{2x^2} + C$$
$$v = \frac1{2x} + Cx$$
$$\boxed{\operatorname{cosec}y = \frac1{2x} + Cx\quad\text{or}\quad\frac{2x}{\sin y} = 1 + 2Cx^2}$$
*Other sign:* with $-\dfrac1{x^2}\tan y\sin y$ on the right, $\dfrac{dv}{dx} - \dfrac vx = \dfrac1{x^2}$ and $\operatorname{cosec}y = -\dfrac1{2x} + Cx$.

$(2x+3)^2y'' + 2(2x+3)y' - 4y = 8x$ is a Legendre linear equation. Put $2x + 3 = e^z$, $z = \ln(2x+3)$, and $\theta = \dfrac{d}{dz}$:
$$\begin{gathered}(2x+3)\frac{dy}{dx} = 2\theta y \\ (2x+3)^2\frac{d^2y}{dx^2} = 4\theta(\theta-1)y\end{gathered}$$
$$4\theta(\theta-1)y + 4\theta y - 4y = 8x\ \Rightarrow\ 4(\theta^2 - 1)y = 8x$$
With $x = \dfrac{e^z - 3}{2}$, $8x = 4(e^z - 3)$:
$$(\theta^2 - 1)y = e^z - 3$$
**C.F.** $m^2 - 1 = 0$, $m = \pm1$: $y_c = C_1e^z + C_2e^{-z}$.

**P.I.** For $e^z$ ($\theta = 1$ is a root of $\theta^2-1$):
$$\frac1{\theta^2 - 1}e^z = \frac{z\,e^z}{2\theta}\Big|_{\theta=1} = \frac{ze^z}{2}$$
For $-3$: $\dfrac1{\theta^2-1}(-3) = \dfrac{-3}{-1} = 3$.

Hence, with $e^z = 2x+3$:
$$\boxed{y = C_1(2x+3) + \frac{C_2}{2x+3} + \frac12(2x+3)\ln(2x+3) + 3}$$
(Checked by direct substitution into the original equation.)

@s 14
Two steps: (1) shift the origin to $(-1, 0)$; (2) rotate the axes through $45^\circ$ (the bisectors of the original axes make $45^\circ$ with them).

**Step 1 (translation).** $x = X - 1,\ y = Y$:
$$(X-1)^2 - 2(X-1)Y + Y^2 + (X-1) - 3Y = 0$$
$$X^2 - 2X + 1 - 2XY + 2Y + Y^2 + X - 1 - 3Y = 0$$
$$X^2 - 2XY + Y^2 - X - Y = 0$$
**Step 2 (rotation through $\theta = 45^\circ$).** $X = \dfrac{X' - Y'}{\sqrt2},\ Y = \dfrac{X' + Y'}{\sqrt2}$:
$$\begin{gathered}X - Y = -\sqrt2\,Y' \\ X + Y = \sqrt2\,X'\end{gathered}$$
$$(X - Y)^2 - (X + Y) = 0\ \Rightarrow\ 2Y'^2 - \sqrt2\,X' = 0$$
$$\boxed{2Y'^2 = \sqrt2\,X'\quad\text{i.e.}\quad Y'^2 = \frac{X'}{\sqrt2}}$$
The equation is a **parabola** (as $h^2 = ab$: $1 = 1\cdot1$) with vertex at the new origin $(-1, 0)$ and axis along the new $X'$ axis.

Combined formula: $x = \dfrac{X' - Y'}{\sqrt2} - 1,\ y = \dfrac{X' + Y'}{\sqrt2}$ (sympy-verified: it gives $2Y'^2 - \sqrt2X' = 0$).

@s 15
**Condition for a line to touch an ellipse.** Substitute $y = mx + c$ in $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$:
$$(b^2 + a^2m^2)x^2 + 2a^2mc\,x + a^2(c^2 - b^2) = 0$$
The line is a tangent if the discriminant is zero: $a^4m^2c^2 = (b^2 + a^2m^2)a^2(c^2 - b^2)$, which simplifies to
$$c^2 = a^2m^2 + b^2$$
The point of contact is $x = -\dfrac{a^2mc}{b^2 + a^2m^2} = -\dfrac{a^2m}{c}$, $y = mx + c = \dfrac{b^2}c$.

**Given line.** $x + y = \sqrt{a^2 + b^2}$ is $y = -x + \sqrt{a^2 + b^2}$: $m = -1$, $c = \sqrt{a^2 + b^2}$.
$$a^2m^2 + b^2 = a^2 + b^2 = c^2\ \checkmark$$
So the line is a tangent to the ellipse. $\blacksquare$

**Point of contact:**
$$\begin{gathered}x = -\frac{a^2m}{c} = \frac{a^2}{\sqrt{a^2+b^2}} \\ y = \frac{b^2}{\sqrt{a^2+b^2}}\end{gathered}$$
$$\boxed{\left(\frac{a^2}{\sqrt{a^2+b^2}},\ \frac{b^2}{\sqrt{a^2+b^2}}\right)}$$
Check: $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = \dfrac{a^2 + b^2}{a^2+b^2} = 1$ ✓ and $x + y = \sqrt{a^2+b^2}$ ✓.

@s 16
$x^2 + 4xy + y^2 - 2x + 2y - 6 = 0$: compare with $ax^2 + 2hxy + by^2 + 2gx + 2fy + c = 0$: $a = 1,\ h = 2,\ b = 1,\ g = -1,\ f = 1,\ c = -6$.

**Identification.**
$$\Delta = abc + 2fgh - af^2 - bg^2 - ch^2 = -6 - 4 - 1 - 1 + 24 = 12\ne0$$
(non-degenerate conic) and $h^2 - ab = 4 - 1 = 3>0$. So the conic is a **hyperbola**.

**Centre.** Solve $\dfrac12F_x = ax + hy + g = 0$ and $\dfrac12F_y = hx + by + f = 0$:
$$\begin{gathered}x + 2y - 1 = 0 \\ 2x + y + 1 = 0\ \Rightarrow\ \boxed{\text{centre }(-1, 1)}\end{gathered}$$
**Equation about the centre.** Shifting the origin to $(-1,1)$: $ax^2 + 2hxy + by^2 + c' = 0$ with
$$c' = gx_0 + fy_0 + c = (-1)(-1) + (1)(1) - 6 = -4$$
$$X^2 + 4XY + Y^2 = 4$$
**Axes.** Rotate by the angle $\tan2\theta = \dfrac{2h}{a - b} = \infty\Rightarrow\theta = 45^\circ$. The quadratic form has eigenvalues $\lambda$ with $\lambda^2 - 2\lambda - 3 = 0$, $\lambda = 3$ (direction $(1,1)$) and $\lambda = -1$ (direction $(1,-1)$):
$$3X'^2 - Y'^2 = 4\ \Rightarrow\ \frac{X'^2}{4/3} - \frac{Y'^2}{4} = 1$$
Semi-transverse axis $A = \dfrac2{\sqrt3}$ and semi-conjugate axis $B = 2$:
$$\boxed{\text{transverse axis }2A = \frac{4}{\sqrt3}\approx2.31,\qquad\text{conjugate axis }2B = 4}$$
The transverse axis is the line $y - 1 = x + 1$, i.e. $y = x + 2$; the conjugate axis is $y - 1 = -(x+1)$, i.e. $x + y = 0$. Eccentricity $e = \sqrt{1 + B^2/A^2} = \sqrt{1 + 3} = 2$ (a hyperbola with $e = 2$).

**OR.** $r = \dfrac{12}{3 - 2\cos\theta}$. Divide numerator and denominator by $3$:
$$r = \frac{4}{1 - \frac23\cos\theta}$$
Compare with the standard form $r = \dfrac{\ell}{1 - e\cos\theta}$: eccentricity $e = \dfrac23<1$ and semi-latus rectum $\ell = 4$. Since $e<1$, the conic is an **ellipse**, with a focus at the pole $O$.

*Description.* For $r = \ell/(1 - e\cos\theta)$ the directrix is $x = -\ell/e = -6$ (to the left of the pole) and the major axis lies along the initial line.
