@s 1
Since $y = e^{a\tan^{-1}x}$, $y_1 = e^{a\tan^{-1}x}\cdot\dfrac{a}{1+x^2}$, that is
$$(1+x^2)\,y_1 = a\,y \tag{1}$$
**(i)** Differentiate (1) once more with respect to $x$:
$$(1+x^2)y_2 + 2x\,y_1 = a\,y_1 \;\Rightarrow\; \boxed{(1+x^2)y_2 + (2x - a)y_1 = 0}$$
**(ii)** Differentiate the result of (i) $n$ times with Leibnitz's theorem, $(uv)_n = \sum\binom nr u_{n-r}v_r$, taking $u = y_2$ or $y_1$ and $v = 1+x^2$ or $2x-a$ (only the first three, respectively two, terms survive):
$$\big[(1+x^2)y_{n+2} + n(2x)y_{n+1} + \tfrac{n(n-1)}{2}(2)\,y_n\big] + \big[(2x-a)y_{n+1} + n(2)\,y_n\big] = 0$$
Collect the terms: the coefficient of $y_n$ is $n(n-1) + 2n = n(n+1)$ and that of $y_{n+1}$ is $2nx + 2x - a$. Hence
$$\boxed{(1+x^2)y_{n+2} + (2nx+2x-a)\,y_{n+1} + n(n+1)\,y_n = 0}$$
(Check: $n = 0$ gives $(1+x^2)y_2 + (2x - a)y_1 = 0$, which is part (i).)

@s 2
Let $f(x) = \log(1+\tan x)$ and write $t = \tan x$, so that $t' = 1 + t^2$ and $t(0) = 0$. Then
$$\begin{gathered}f'(x) = \frac{\sec^2x}{1+\tan x} = \frac{1+t^2}{1+t} \\ \text{i.e.} \\ f'(1+t) = 1 + t^2\end{gathered}$$
Differentiate this relation repeatedly and put $x = 0$ (where $t = 0$, $t' = 1$):

| Step | Relation | Value at $x=0$ |
|---|---|---|
| $f$ | $\log(1+0)$ | $f(0) = 0$ |
| $f'$ | $f'(1+t) = 1+t^2$ | $f'(0) = 1$ |
| $f''$ | $f''(1+t) + f'(1+t^2) = 2t(1+t^2)$ | $f''(0) + 1 = 0 \Rightarrow f''(0) = -1$ |
| $f'''$ | $f'''(1+t) + 2f''(1+t^2) + 2tf'(1+t^2) = 2(1+t^2)^2 + 4t^2(1+t^2)$ | $f'''(0) - 2 = 2 \Rightarrow f'''(0) = 4$ |
| $f^{(4)}$ | continuing the same way | $f^{(4)}(0) = -14$ |

Maclaurin's theorem $f(x) = f(0) + xf'(0) + \dfrac{x^2}{2!}f''(0) + \dfrac{x^3}{3!}f'''(0) + \dfrac{x^4}{4!}f^{(4)}(0) + \cdots$ gives
$$\boxed{\log(1+\tan x) = x - \frac{x^2}{2} + \frac{2x^3}{3} - \frac{7x^4}{12} + \cdots}$$
*Check by composition:* $\log(1+t) = t - \tfrac{t^2}{2} + \tfrac{t^3}{3} - \cdots$ with $t = x + \tfrac{x^3}{3} + \cdots$ gives $x - \tfrac{x^2}{2} + \left(\tfrac13 + \tfrac13\right)x^3 + \cdots$, the same coefficients.

@s 3
**L'Hospital's rule.** If $f(x)$ and $g(x)$ are differentiable near $a$, $f(a) = g(a) = 0$ (or both tend to $\pm\infty$) and $\lim\dfrac{f'(x)}{g'(x)}$ exists, then $\displaystyle\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}$.

At $x = 0$ the numerator is $0 - \log 1 = 0$ and the denominator is $0$, so the form is $\dfrac00$:
$$L = \lim_{x\to0}\frac{\cos x - x\sin x - \dfrac{1}{1+x}}{2x}\quad\left(\tfrac00\text{ again}\right) = \lim_{x\to0}\frac{-\sin x - \sin x - x\cos x + \dfrac{1}{(1+x)^2}}{2} = \frac{1}{2}$$
$$\boxed{L = \tfrac12}$$

@s 4
The curve is $(a^2 - x^2)\,y^2 = x^2(a-x)^2$, i.e.
$$x^2y^2 + x^4 - 2ax^3 - a^2y^2 + a^2x^2 = 0 \;\Longleftrightarrow\; x^2(x^2+y^2) - 2ax^3 + a^2x^2 - a^2y^2 = 0$$

*Asymptotes parallel to the y-axis.* The coefficient of the highest power of $y$ ($y^2$) is $x^2 - a^2$, so these are $x = \pm a$ as candidates.

*Which of them is a genuine asymptote?* The curve has the factor $(a-x)$ on the right-hand side: for $x \ne a$ it is $y^2 = \dfrac{x^2(a-x)}{a+x}$.

- As $x \to -a$ (with $-a < x < a$), $y^2 \to +\infty$: the line $\boxed{x = -a}$ is a vertical asymptote.
- $x = a$ is **not** an asymptote of the curve $y^2 = \dfrac{x^2(a-x)}{a+x}$: the curve meets it at the point $(a, 0)$ only, where $y$ stays finite. In the unreduced equation the whole line $x = a$ satisfies the equation (both sides vanish), so it is a *component line*, not an asymptote.

*Oblique asymptotes.* Put $y = mx + c$ in the highest-degree terms $x^2(x^2+y^2)$: $m^2 + 1 = 0$, so $m = \pm i$. There is no real oblique asymptote (indeed, for $|x| > a$ the right-hand side is negative, so the curve does not extend to large $|x|$).

For $r = a(1-\cos\theta)$: $r_1 = \dfrac{dr}{d\theta} = a\sin\theta$ and $r_2 = a\cos\theta$. The polar formula is
$$\rho = \frac{(r^2 + r_1^2)^{3/2}}{r^2 + 2r_1^2 - r\,r_2}$$
Now
$$r^2 + r_1^2 = a^2\big[(1-\cos\theta)^2 + \sin^2\theta\big] = 2a^2(1-\cos\theta) = 2ar$$
$$r^2 + 2r_1^2 - rr_2 = a^2\big[(1-\cos\theta)^2 + 2\sin^2\theta - (1-\cos\theta)\cos\theta\big] = 3a^2(1-\cos\theta) = 3ar$$
$$\rho = \frac{(2ar)^{3/2}}{3ar} = \frac{2\sqrt2\,(ar)^{3/2}}{3ar}\;\Longrightarrow\;\boxed{\rho = \frac{2}{3}\sqrt{2ar}}$$
In terms of $\theta$: $r = 2a\sin^2\tfrac\theta2$, so $\rho = \tfrac43 a\sin\tfrac\theta2$.

@s 6
Since $1 - x + x^2 > 0$, $\cot^{-1}(1-x+x^2) = \tan^{-1}\dfrac{1}{1-x+x^2}$. Now
$$\tan\big[\tan^{-1}x + \tan^{-1}(1-x)\big] = \frac{x + (1-x)}{1 - x(1-x)} = \frac{1}{1-x+x^2}$$
so for $0 \le x \le 1$ (the sum of the two angles lies between $0$ and $\pi/2$)
$$\cot^{-1}(1-x+x^2) = \tan^{-1}x + \tan^{-1}(1-x)$$
$$I = \int_0^1\tan^{-1}x\,dx + \int_0^1\tan^{-1}(1-x)\,dx = 2\int_0^1\tan^{-1}x\,dx \quad(\text{replace } x\to1-x \text{ in the second})$$
By parts, $\displaystyle\int_0^1\tan^{-1}x\,dx = \Big[x\tan^{-1}x\Big]_0^1 - \int_0^1\frac{x\,dx}{1+x^2} = \frac\pi4 - \frac12\log2$. Hence
$$\begin{gathered}I = 2\left(\frac\pi4 - \frac12\log 2\right) = \boxed{\frac\pi2 - \log2} \\ \text{(numerically }0.87765\text{)}\end{gathered}$$

@s 7
Let $I(a) = \displaystyle\int_0^\infty\frac{\log(1+a^2x^2)}{1+b^2x^2}\,dx$, so $I(0) = 0$. Differentiating under the integral sign (Leibnitz rule, limits constant):
$$\frac{dI}{da} = \int_0^\infty\frac{2ax^2}{(1+a^2x^2)(1+b^2x^2)}\,dx$$
Partial fractions: $\dfrac{x^2}{(1+a^2x^2)(1+b^2x^2)} = \dfrac{1}{b^2-a^2}\left[\dfrac{1}{1+a^2x^2} - \dfrac{1}{1+b^2x^2}\right]$. Using $\displaystyle\int_0^\infty\frac{dx}{1+k^2x^2} = \frac{\pi}{2k}$:
$$\frac{dI}{da} = \frac{2a}{b^2-a^2}\cdot\frac\pi2\left(\frac1a - \frac1b\right) = \frac{2a}{(b-a)(b+a)}\cdot\frac\pi2\cdot\frac{b-a}{ab} = \frac{\pi}{b(a+b)}$$
Integrate with respect to $a$: $I = \dfrac\pi b\log(a+b) + C$. Since $I(0) = 0$, $C = -\dfrac\pi b\log b$:
$$\boxed{\int_0^\infty\frac{\log(1+a^2x^2)}{1+b^2x^2}\,dx = \frac{\pi}{b}\log\frac{a+b}{b}}$$
(Check, $a = 2,\ b = 3$: $\tfrac\pi3\log\tfrac53 = 0.53494$, which agrees with numerical integration.)

@s 8
**Gamma function.** For $n > 0$,
$$\Gamma(n) = \int_0^\infty e^{-x}x^{n-1}\,dx$$
with $\Gamma(n+1) = n\,\Gamma(n)$, $\Gamma(1) = 1$ and $\Gamma(\tfrac12) = \sqrt\pi$. The Beta function $B(m,n) = \displaystyle\int_0^1x^{m-1}(1-x)^{n-1}dx = \dfrac{\Gamma(m)\Gamma(n)}{\Gamma(m+n)}$, and $\Gamma(n)\Gamma(1-n) = \dfrac{\pi}{\sin n\pi}$ for $0<n<1$.

Put $x^6 = t$, $x = t^{1/6}$, $dx = \tfrac16t^{-5/6}dt$:
$$\int_0^1\frac{dx}{(1-x^6)^{1/6}} = \frac16\int_0^1t^{-5/6}(1-t)^{-1/6}\,dt = \frac16B\!\left(\frac16,\frac56\right) = \frac16\,\Gamma\!\left(\frac16\right)\Gamma\!\left(\frac56\right)$$
because $\Gamma(1) = 1$. With $\Gamma(\tfrac16)\Gamma(\tfrac56) = \dfrac{\pi}{\sin(\pi/6)} = 2\pi$,
$$\boxed{\int_0^1\frac{dx}{(1-x^6)^{1/6}} = \frac{2\pi}{6} = \frac\pi3}$$

@s 9
The cycloid $x = a(\theta+\sin\theta)$, $y = a(1+\cos\theta)$ for $-\pi\le\theta\le\pi$ is an arch with its top $(0, 2a)$ on the line $x = 0$ and cusps $(\pm\pi a, 0)$ on the x-axis. Its axis of symmetry is the line $x = 0$ (the y-axis). Revolving the half $0\le\theta\le\pi$ about it sweeps out the whole surface.

$$\frac{dx}{d\theta} = a(1+\cos\theta),\quad\frac{dy}{d\theta} = -a\sin\theta,\quad ds = a\sqrt{(1+\cos\theta)^2 + \sin^2\theta}\,d\theta = a\sqrt{2+2\cos\theta}\,d\theta = 2a\cos\frac\theta2\,d\theta$$
The surface area is
$$S = 2\pi\int x\,ds = 2\pi\int_0^\pi a(\theta+\sin\theta)\cdot2a\cos\frac\theta2\,d\theta = 4\pi a^2\left[\int_0^\pi\theta\cos\frac\theta2\,d\theta + \int_0^\pi\sin\theta\cos\frac\theta2\,d\theta\right]$$
By parts, $\displaystyle\int_0^\pi\theta\cos\frac\theta2\,d\theta = \Big[2\theta\sin\frac\theta2\Big]_0^\pi - \int_0^\pi2\sin\frac\theta2\,d\theta = 2\pi - 4$. Also $\sin\theta\cos\dfrac\theta2 = 2\sin\dfrac\theta2\cos^2\dfrac\theta2$, so $\displaystyle\int_0^\pi = \Big[-\tfrac43\cos^3\tfrac\theta2\Big]_0^\pi = \tfrac43$. Therefore
$$S = 4\pi a^2\left(2\pi - 4 + \frac43\right) = 4\pi a^2\left(2\pi - \frac83\right) = \boxed{\frac{8\pi a^2}{3}\,(3\pi - 4)}\approx 45.45\,a^2$$

*Note.* If the arch is instead revolved about its base (the x-axis, the tangent at the cusps), $S = 2\pi\displaystyle\int_{-\pi}^{\pi}y\,ds = 8\pi a^2\!\int_{-\pi}^{\pi}\!\cos^3\tfrac\theta2\,d\theta = 8\pi a^2\cdot\tfrac83 = \dfrac{64\pi a^2}{3}$, the classical result.

**OR.** From $a^2y^2 = x^2(a^2 - x^2)$ we get $y = \pm\dfrac xa\sqrt{a^2-x^2}$, which is real only for $-a\le x\le a$. The curve is symmetric about both axes and consists of two loops, one for $x\in[0,a]$ and one for $x\in[-a,0]$, joined at the origin. The area of the loop on the right is $2\displaystyle\int_0^a y\,dx$ (upper half doubled):
$$A_1 = 2\int_0^a\frac xa\sqrt{a^2-x^2}\,dx = \frac2a\left[-\frac13(a^2-x^2)^{3/2}\right]_0^a = \frac2a\cdot\frac{a^3}3 = \frac{2a^2}{3}$$
The two loops are equal, so
$$\boxed{A = 2A_1 = \frac{4a^2}{3}}$$

@s 11
The equation is $y = x^4p^2 - px$. Put $x = \dfrac1u$; then $p = \dfrac{dy}{dx} = -u^2\dfrac{dy}{du} = -u^2q$ with $q = \dfrac{dy}{du}$. Substituting,
$$y - uq = q^2$$
that is $y = uq + q^2$.
This is **Clairaut's equation** in the variables $(u, y)$, whose general solution is obtained by replacing $q$ with a constant $c$: $y = cu + c^2$, that is
$$\boxed{y = \frac{c}{x} + c^2}$$
*Check:* $p = -c/x^2$, so $y + px = \dfrac cx + c^2 - \dfrac cx = c^2$ and $x^4p^2 = c^2$. $\checkmark$

*Singular solution (extra).* Differentiating $y = uq + q^2$ with respect to $q$: $u + 2q = 0$, so $q = -u/2$ and $y = -\dfrac{u^2}{4}$, that is $y = -\dfrac{1}{4x^2}$ (i.e. $4x^2y + 1 = 0$).

Let $S(x,y) = 12x^2 - 10xy + 2y^2 + 11x - 5y + 2$. Moving the origin to the centre $(h,k)$ removes the linear terms, and the centre is where $\partial S/\partial x = \partial S/\partial y = 0$:

@s 15
**Definition.** An ellipse is the locus of a point $P$ that moves in a plane so that the sum of its distances from two fixed points $S$ and $S'$ (the foci) is constant and equal to $2a$, which is greater than $SS'$. (Equivalently, it is the locus of a point whose distance from a focus is $e\,(<1)$ times its distance from a fixed line, the directrix.)

**Derivation.** Take the origin at the midpoint of $SS'$ and the x-axis along $S'S$, with $S(c,0)$, $S'(-c,0)$, $c < a$. For $P(x,y)$,
$$\sqrt{(x-c)^2 + y^2} + \sqrt{(x+c)^2 + y^2} = 2a$$
Move one root across and square: $(x+c)^2 + y^2 = 4a^2 - 4a\sqrt{(x-c)^2+y^2} + (x-c)^2 + y^2$, so
$$a\sqrt{(x-c)^2+y^2} = a^2 - cx$$
Square again: $a^2x^2 - 2a^2cx + a^2c^2 + a^2y^2 = a^4 - 2a^2cx + c^2x^2$, i.e. $(a^2-c^2)x^2 + a^2y^2 = a^2(a^2-c^2)$. Put $b^2 = a^2 - c^2$ (positive because $c<a$) and divide by $a^2b^2$:
$$\boxed{\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1,\qquad b^2 = a^2(1-e^2),\ e = \frac ca < 1}$$

**Properties.** Centre $(0,0)$; vertices $(\pm a, 0)$; major axis $2a$, minor axis $2b$; foci $(\pm ae, 0)$; directrices $x = \pm\dfrac ae$ (since $a\sqrt{(x-c)^2+y^2} = a^2 - cx$ says $SP = e\left(\dfrac ae - x\right)$); latus rectum $\dfrac{2b^2}{a}$.

For $S = 9x^2 + 4xy + 6y^2 - 22x - 16y + 9$ we have $a = 9,\ h = 2,\ b = 6$, and $ab - h^2 = 50 > 0$, so the conic is an **ellipse** (the cubic invariant $\Delta = -500 \ne 0$ shows it is not degenerate).

**Centre.** $\partial S/\partial x = 18x + 4y - 22 = 0$ and $\partial S/\partial y = 4x + 12y - 16 = 0$ give $x = 1,\ y = 1$. Centre $= \boxed{(1, 1)}$.

**Reduced equation.** Shift to the centre ($x = X+1,\ y = Y+1$): the constant term is $S(1,1) = 9 + 4 + 6 - 22 - 16 + 9 = -10$, so
$$9X^2 + 4XY + 6Y^2 = 10$$
**Rotation.** The quadratic form has matrix $\begin{pmatrix}9&2\\2&6\end{pmatrix}$ with characteristic equation $\lambda^2 - 15\lambda + 50 = 0$, so $\lambda = 10$ and $\lambda = 5$. The eigenvector for $\lambda = 10$ is along $(2,1)$ and for $\lambda = 5$ along $(-1, 2)$. In the principal axes $(u, v)$ along these directions,
$$10u^2 + 5v^2 = 10 \;\Longrightarrow\; \frac{u^2}{1} + \frac{v^2}{2} = 1$$
So the semi-axes are $1$ (along $(2,1)$) and $\sqrt2$ (along $(-1,2)$):

| Quantity | Value |
|---|---|
| Centre | $(1,1)$ |
| Length of major axis $2\sqrt2$ | $\approx 2.83$ (along the direction $(-1, 2)$, slope $-2$) |
| Length of minor axis $2$ | $2$ (along $(2, 1)$, slope $\tfrac12$) |
| Eccentricity | $e = \sqrt{1 - \dfrac{1}{2}} = \boxed{\dfrac{1}{\sqrt2}}\approx 0.707$ |

Axes' directions: major axis $y - 1 = -2(x-1)$, minor axis $y - 1 = \tfrac12(x-1)$. The angle of rotation of the principal axes satisfies $\tan2\theta = \dfrac{2h}{a-b} = \dfrac{4}{3}$.
