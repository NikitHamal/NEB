### Group A

@s 1
The `<a>` (anchor) tag has these main attributes (properties): `href` (destination URL), `target` (where it opens: `_blank`, `_self`, `_parent`, `_top`), `title` (tool-tip text), `name` or `id` (a named anchor inside the page), `rel` (relation to the linked page, such as `nofollow`) and `download` (downloads the file instead of opening it).

@s 2
Five features of JavaScript: (1) it is a lightweight, interpreted scripting language that runs inside the browser; (2) it is dynamically typed, so a variable takes any type; (3) it is event driven (click, load, submit); (4) it supports objects and functions as first-class values; (5) it can change the HTML and CSS of a page through the DOM and validate forms on the client without contacting the server.

@s 3
A *selector* in CSS is the part of a rule that chooses which HTML elements the declarations apply to. The main kinds are the element selector (`p`), class selector (`.note`), id selector (`#top`), universal selector (`*`), grouping (`h1, h2`) and descendant selector (`div p`). Example: `p.note { color: red; }` colours every paragraph of class `note`.

@s 4
`php.ini` is the main configuration file of PHP. The server reads it at start-up to set options such as `memory_limit`, `upload_max_filesize`, `max_execution_time`, `display_errors` and the extensions to load (`extension=mysqli`). Changing it and restarting the web server changes how every PHP script behaves.

@s 5
SQL (*Structured Query Language*) is the standard language used to create, store, retrieve, update and delete data in a relational database. It has data definition (`CREATE`, `ALTER`, `DROP`), data manipulation (`INSERT`, `UPDATE`, `DELETE`, `SELECT`) and data control (`GRANT`, `REVOKE`) statements.

### Group B

@s 6
**The `<img>` tag (3 marks).** `<img>` embeds a picture in a page. It is an empty tag (it has no closing tag) and its main attributes are `src` (file or URL of the image), `alt` (text shown if the image cannot load, and read by screen readers), `width` and `height`.

**Image as a hyperlink (3 marks).** Put the `<img>` tag inside the `<a>` tag, so clicking the picture follows the link:

```html
<a href="https://www.example.com" target="_blank">
  <img src="logo.png" alt="Visit the site" width="120" height="60">
</a>
```

Many browsers draw a coloured border round a linked image; `style="border:0"` removes it.

@s 7
**JavaScript data types (2 marks).** Primitive types: *Number*, *String*, *Boolean*, *Undefined*, *Null*, *BigInt* and *Symbol*. Non-primitive (reference) types: *Object*, which includes arrays and functions.

**Greatest of five numbers (4 marks).**

```html
<script>
  var n = [45, 12, 78, 34, 60];     // five different numbers
  var max = n[0];
  for (var i = 1; i < n.length; i++) {
    if (n[i] > max) max = n[i];
  }
  document.write("The greatest number is " + max);   // 78
</script>
```

The first number is assumed to be the greatest, each next number is compared with it, and `max` is replaced whenever a bigger number is found. For the sample data the output is 78.

@s 8
**CSS integration (6 marks).** There are three ways to attach CSS to a page.

| Method | Where the rule is written | Scope | Example |
|---|---|---|---|
| Inline | In the `style` attribute of one tag | That element only | `<p style="color:red">Hi</p>` |
| Internal (embedded) | In a `<style>` block in the `<head>` | The whole page | `<style> p { color: blue; } </style>` |
| External | In a separate `.css` file linked with `<link>` | Every page that links it | `<link rel="stylesheet" href="style.css">` |

An inline rule beats an internal rule, and an internal rule beats an external one when they set the same property and have the same specificity, because the closer and later rule wins. The external file is best for a whole site because one change updates every page and the browser caches the file.

```html
<head>
  <link rel="stylesheet" href="style.css">      <!-- external -->
  <style> h1 { text-align: center; } </style>    <!-- internal -->
</head>
<body><h1 style="color:green">Welcome</h1></body>  <!-- inline -->
```

@s 9
**&#36;_GET and &#36;_POST (6 marks).** Both are PHP *superglobal* arrays that hold the data sent from an HTML form.

| Basis | &#36;_GET | &#36;_POST |
|---|---|---|
| Data sent in | The URL query string (`?name=Ram`) | The body of the HTTP request |
| Visible in the address bar | Yes | No |
| Size limit | About 2000 characters | No practical limit |
| Bookmarkable | Yes | No |
| Use for | Searching, filtering, page numbers | Passwords, long text, file upload, data changes |

```php
<form method="post" action="hello.php">
  Name: <input type="text" name="name">
  <input type="submit" value="Send">
</form>
<?php
// hello.php
if (isset($_POST['name'])) {
    echo "Hello, " . htmlspecialchars($_POST['name']);
}
// With method="get" the same value is read as $_GET['name'].
?>
```

`htmlspecialchars()` stops user text from being run as HTML.

@s 10
**RDBMS (6 marks).** A *relational database management system* stores data in *tables* (relations) made of rows (records) and columns (fields), and lets tables be linked by key values. Examples are MySQL, Oracle, SQL Server and PostgreSQL. It is based on the relational model of E. F. Codd.

Main ideas: a *primary key* identifies each row uniquely; a *foreign key* in one table refers to the primary key of another and so creates a relationship; *SQL* is the language for all operations; *normalisation* removes redundancy; *integrity rules* keep data correct; *transactions* follow the ACID properties.

| Student table | | | Result table | |
|---|---|---|---|---|
| **roll (PK)** | name | | roll (FK) | marks |
| 1 | Ram | | 1 | 78 |
| 2 | Sita | | 2 | 85 |

Advantages: less duplication, data integrity, easy querying with joins, multi-user access, security and backup. Disadvantage: it needs more memory and processing than a flat file for a very small job.

### Group C

@s 11
**PHP and MySQL connection (10 marks).** PHP talks to MySQL with the *mysqli* extension (or PDO). The steps are: (1) call `mysqli_connect(host, user, password, database)` to open the connection; (2) check that it succeeded; (3) send SQL with `mysqli_query()` or a prepared statement; (4) read the result rows with `mysqli_fetch_assoc()`; (5) close the connection with `mysqli_close()`.

**Connection function and login check.** The table is `users(id, username, password)`, where the password is stored as a hash made with `password_hash()`.

```php
<?php
// db.php : one function that returns the connection
function db_connect() {
    $conn = mysqli_connect("localhost", "root", "", "schooldb");
    if (!$conn) {
        die("Connection failed: " . mysqli_connect_error());
    }
    return $conn;
}

// login.php : access the login user
function check_login($username, $password) {
    $conn = db_connect();
    $stmt = mysqli_prepare($conn,
        "SELECT password FROM users WHERE username = ?");
    mysqli_stmt_bind_param($stmt, "s", $username);
    mysqli_stmt_execute($stmt);
    mysqli_stmt_bind_result($stmt, $hash);
    $ok = false;
    if (mysqli_stmt_fetch($stmt)) {
        $ok = password_verify($password, $hash);
    }
    mysqli_stmt_close($stmt);
    mysqli_close($conn);
    return $ok;
}

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    if (check_login($_POST["username"], $_POST["password"])) {
        session_start();
        $_SESSION["user"] = $_POST["username"];
        echo "Login successful. Welcome, " . htmlspecialchars($_POST["username"]);
    } else {
        echo "Invalid username or password.";
    }
}
?>
<form method="post">
  Username: <input type="text" name="username"><br>
  Password: <input type="password" name="password"><br>
  <input type="submit" value="Login">
</form>
```

How it works: `db_connect()` opens the connection once and stops with an error message if MySQL is down. `check_login()` uses a *prepared statement* with the placeholder `?`, so the user's text is never joined into the SQL and an injection such as `' OR '1'='1` fails. The stored hash is compared with `password_verify()`, so plain passwords are never kept. On success a session variable remembers the user for the next pages.
