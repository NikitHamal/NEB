**1. A.** The infinite geometric series $a + ar + ar^2 + \dots$ has a finite sum only when $|r|<1$, and then $S_\infty = \dfrac{a}{1-r}$. The partial sum is $S_n = \dfrac{a(1-r^n)}{1-r}$ and $r^n\to0$ as $n\to\infty$.

**2. C.** A matrix is singular when its determinant is zero. For rows $(4,6)$ and $(2,3)$: $4\times3 - 6\times2 = 12 - 12 = 0$. The others give $4-6=-2$, $4-6=-2$ and $1$, which are non-zero.

**3. C.** Fixing one object to remove the rotations that give the same arrangement, the remaining $n-1$ objects can be arranged in $(n-1)!$ ways around the circle.

**4. B.** The cosine law gives $b^2 = c^2 + a^2 - 2ca\cos B$, so $\cos B = \dfrac{c^2+a^2-b^2}{2ac}$. The two sides containing angle $B$ are $a$ and $c$.

**5. B.** Slope of $3x + ky - 6 = 0$ is $-\dfrac{3}{k}$. Setting $-\dfrac{3}{k} = \dfrac{3}{2}$ gives $k = -2$.

**6. A.** Coefficient of quartile deviation $= \dfrac{Q_3 - Q_1}{Q_3 + Q_1} = \dfrac{30}{50} = 0.6$.

**7. B.** $\text{C.V.} = \dfrac{\sigma}{\bar x}\times100$, so $20 = \dfrac{\sigma}{10}\times100$, giving $\sigma = 2$ and variance $\sigma^2 = 4$.

**8. D.** $P(\bar A) = 1 - 0.68 = 0.32$ and $P(\bar B) = 1 - 0.4 = 0.6$. Their sum is $0.92$.

**9. B.** For $x\ne0$, $\dfrac{x^2-x}{2x} = \dfrac{x-1}{2}$. As $x\to0$ this tends to $-\dfrac{1}{2}$. (The form is $\dfrac{0}{0}$, so cancel $x$ first.)

**10. A.** $\dfrac{d(\tan x)}{d(\sec x)} = \dfrac{\sec^2x}{\sec x\tan x} = \dfrac{\sec x}{\tan x} = \dfrac{1}{\sin x} = \operatorname{cosec}x$.

**11. C.** $1 + \sin2x = \sin^2x + \cos^2x + 2\sin x\cos x = (\sin x + \cos x)^2$. So $\sqrt{1+\sin2x} = \sin x + \cos x$ (where it is positive) and $\displaystyle\int(\sin x + \cos x)\,dx = -\cos x + \sin x + C = \sin x - \cos x + C$.

*Basis:* for $n = 1$, LHS $= 1$ and RHS $= \left[\dfrac{1\cdot2}{2}\right]^2 = 1$. So $P(1)$ is true.
*Inductive step:* assume $P(k)$ is true: $1^3 + \dots + k^3 = \dfrac{k^2(k+1)^2}{4}$. Add $(k+1)^3$ to both sides:
$$1^3 + \dots + k^3 + (k+1)^3 = \frac{k^2(k+1)^2}{4} + (k+1)^3 = \frac{(k+1)^2\,[k^2 + 4(k+1)]}{4} = \frac{(k+1)^2(k+2)^2}{4} = \left[\frac{(k+1)(k+2)}{2}\right]^2.$$
This is $P(k+1)$. By the principle of mathematical induction, $P(n)$ is true for all natural numbers $n$.

@s 22
**(a)** *$f(x) = x^2$:* $f(2) = 4$ and $\displaystyle\lim_{x\to2}x^2 = 4$. The limit exists and equals the value of the function, so $f$ is continuous at $x = 2$.
*$g(x) = \dfrac{x^2+2x}{x-2}$:* at $x = 2$ the denominator is zero, so $g(2)$ is not defined. Moreover the numerator tends to $8$, so as $x\to2^+$, $g(x)\to+\infty$ and as $x\to2^-$, $g(x)\to-\infty$; the limit does not exist. A function is continuous at a point only if it is defined there and the limit equals the value, so $g$ is not continuous at $x = 2$.

**(b)** The derivative measures the rate at which one quantity changes with respect to another, so it is essential for finding a rate of measure.
Example: the area of a circle is $A = \pi r^2$. How fast does the area change as the radius grows? $\dfrac{dA}{dr} = 2\pi r$. When $r = 5$ cm, $\dfrac{dA}{dr} = 10\pi \approx 31.4\ \text{cm}^2$ per cm. If the radius increases at $2\ \text{cm s}^{-1}$, then $\dfrac{dA}{dt} = 2\pi r\dfrac{dr}{dt} = 20\pi \approx 62.8\ \text{cm}^2\text{s}^{-1}$. Without the derivative this rate at a particular instant cannot be found. Similarly, velocity is the derivative of distance, $v = \dfrac{ds}{dt}$, and acceleration the derivative of velocity.
