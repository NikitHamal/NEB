### Group A — answer key

**1. C.** The CLR is the execution engine of .NET: it loads the compiled intermediate code (IL), compiles it to machine code with the JIT compiler, and provides memory management, garbage collection, type safety and exception handling. It is a runtime (virtual machine), not a compiler of C# source, an IDE or a database.

**2. A.** Every type in .NET, including `int`, `string` and user classes, derives directly or indirectly from `System.Object`. The other three names do not exist as roots.

**3. A.** The C# loop is `for (initializer; condition; iterator) { ... }`: the initializer runs once, the condition is tested before each pass, and the iterator runs after each pass.

**4. D.** The array type is written with square brackets before the name and the size is given with `new`: `int[] array = new int[5];`. Square brackets after `int` in `new int[]` without a size are not valid on their own.

**5. A.** `ToUpper()` returns the upper-case copy of a string. `ToLower()` does the opposite, `Trim()` removes leading and trailing white space, and `Replace()` swaps substrings.

**6. D.** A structure is a value type. It can implement interfaces, have fields, properties and methods, and cannot inherit from another structure or class. It cannot have a destructor (finalizer), and that is the only statement that is not a feature.

**7. B.** The `ref` keyword passes an argument by reference, so the called method works on the caller's variable (or pointer variable) itself. `out` also passes by reference but needs no initial value, `var` only infers a type and `unsafe` marks a code region.

**8. D.** `System.Data.SqlClient` (SQL Server), `System.Data.OracleClient` (Oracle) and `System.Data.OleDb` (generic OLE DB sources) are all ADO.NET namespaces used to connect to a database.

**9. B.** A structure groups members of different types, for example an `int` ID, a `string` name and a `double` salary. It is not limited to similar types or to integers, so "all of above" is wrong.

### Group B

@s 10
**The .NET framework (5 marks).** .NET is a software development platform from Microsoft for building desktop, web, mobile, cloud and game applications. Source code in C#, VB.NET or F# is compiled to *Intermediate Language* (IL), which the *Common Language Runtime* (CLR) turns into machine code at run time. Its two main parts are the CLR and the *Framework Class Library* (FCL).

| Feature | Meaning |
|---|---|
| Language interoperability | Code written in different .NET languages can be mixed through the Common Type System (CTS) and Common Language Specification (CLS). |
| Automatic memory management | The garbage collector frees objects that are no longer used. |
| Rich class library | Ready classes for collections, files, networking, XML, data access and graphics. |
| Security and type safety | Code access security and strict type checking by the CLR. |
| Platform independence | Modern .NET runs on Windows, Linux and macOS. |
| Easy deployment | Assemblies carry their own version information, so applications are installed without registry changes. |

@s 11
**Variables and data types (5 marks).** A variable is declared by writing the data type, the name and, optionally, an initial value: `int age = 17;`, `string name = "Sita";`. The name must start with a letter or underscore and cannot be a keyword. C# is strongly typed, so the type is fixed at declaration (`var` lets the compiler infer it from the value).

| Category | Types | Example |
|---|---|---|
| Integer | `byte`, `short`, `int`, `long` | `int roll = 12;` |
| Floating point | `float`, `double`, `decimal` | `double price = 99.5;` |
| Character | `char` | `char grade = 'A';` |
| Boolean | `bool` | `bool pass = true;` |
| Text | `string` | `string city = "Pokhara";` |
| Reference types | `object`, arrays, classes, interfaces | `int[] marks = new int[3];` |

*Value types* hold the data directly on the stack, *reference types* hold the address of an object on the heap.

**Or: namespace (5 marks).** A namespace is a named container that groups related classes, structures, interfaces and enums and prevents name clashes between code written by different people. `System`, `System.IO` and `System.Data` are examples. A namespace is declared with `namespace Shop { class Bill { } }` and used in two ways: by the *using directive* at the top of the file, or by the *fully qualified name*.

```csharp
using System;                       // brings in Console
namespace School {
    class Student { public string Name = "Ram"; }
}
class Program {
    static void Main() {
        School.Student s = new School.Student();   // qualified name
        Console.WriteLine(s.Name);                 // Ram
    }
}
```

@s 12
**Greatest of three numbers (5 marks).**

```csharp
using System;
class Greatest {
    static void Main() {
        Console.Write("Enter first number: ");
        double a = Convert.ToDouble(Console.ReadLine());
        Console.Write("Enter second number: ");
        double b = Convert.ToDouble(Console.ReadLine());
        Console.Write("Enter third number: ");
        double c = Convert.ToDouble(Console.ReadLine());

        double max = a;
        if (b > max) max = b;
        if (c > max) max = c;
        Console.WriteLine("The greatest number is " + max);
    }
}
```

Dry run for 12, 40 and 25: `max = 12`, then 40 > 12 so `max = 40`, 25 > 40 is false, and the program prints *The greatest number is 40*.

**Or: Concat() and Trim() (5 marks).** `String.Concat()` joins two or more strings (or objects) and returns a new string. `Trim()` returns a copy with white space (or the given characters) removed from both ends; `TrimStart()` and `TrimEnd()` remove one end only. The original string is never changed because strings are immutable.

```csharp
string first = "Nepal", second = " Exam Board";
string joined = String.Concat(first, second);     // "Nepal Exam Board"
string messy = "   Hello C#   ";
string clean = messy.Trim();                       // "Hello C#"
Console.WriteLine(joined + "|" + clean + "|");     // Nepal Exam Board|Hello C#|
```

@s 13
**Arrays (5 marks).** An array stores a fixed number of values of the *same type* in consecutive memory locations that are reached by a zero-based index. It is declared with `int[] marks = new int[5];` or initialised directly with `int[] marks = {70, 65, 80, 90, 55};`. The first element is `marks[0]` and the last is `marks[marks.Length - 1]`. A `for` or `foreach` loop visits every element. Arrays save declaring many separate variables and make sums, searches and sorts easy.

```csharp
using System;
class ArrayDemo {
    static void Main() {
        int[] marks = { 70, 65, 80, 90, 55 };
        int total = 0;
        foreach (int m in marks) total += m;
        Console.WriteLine("Total = " + total);                 // 360
        Console.WriteLine("Average = " + (double)total / marks.Length);   // 72
    }
}
```

@s 14
**Pointers in C# (5 marks).** A pointer is a variable that stores the memory address of another variable. C# normally hides addresses, so pointers are allowed only inside an `unsafe` context: a method or block marked `unsafe`, and the project must be compiled with *Allow unsafe code*. The operator `&` gives the address, `*` gives the value at the address, and `->` reaches a member of a structure through a pointer. A pointer can be passed to a method like any other parameter, so the method changes the caller's variable.

```csharp
using System;
class PointerDemo {
    static unsafe void AddTen(int* p) {
        *p = *p + 10;                  // changes the caller's variable
    }
    static unsafe void Main() {
        int x = 5;
        AddTen(&x);                    // pass the address of x
        Console.WriteLine(x);          // 15
    }
}
```

Dry run: `x = 5`, `&x` is sent, the method adds 10 to the value stored at that address, so `x` is 15 in `Main`.

@s 15
**while and for loops (8 marks).** Both repeat a block of statements while a condition is true, but they are written for different situations.

| Basis | `while` loop | `for` loop |
|---|---|---|
| Syntax | `while (condition) { ... }` | `for (init; condition; update) { ... }` |
| Initialisation | Written before the loop | Written inside the loop header |
| Update | Written inside the body | Written in the header |
| Type | Entry-controlled, tested before each pass | Entry-controlled, tested before each pass |
| Best used when | The number of repetitions is not known in advance (read until the user types 0) | The number of repetitions is known (print 1 to 10) |
| Risk | Forgetting the update makes an infinite loop | The whole control is in one line, so it is harder to forget |

Example: the sum of the numbers 1 to 5 written both ways.

```csharp
using System;
class Loops {
    static void Main() {
        int sum = 0, i = 1;
        while (i <= 5) {               // while: init before, update inside
            sum += i;
            i++;
        }
        Console.WriteLine("while sum = " + sum);   // 15

        sum = 0;
        for (int j = 1; j <= 5; j++)   // for: init, test, update together
            sum += j;
        Console.WriteLine("for sum = " + sum);     // 15
    }
}
```

Both loops give 1 + 2 + 3 + 4 + 5 = 15.

@s 16
**Database connection in C# (8 marks).** C# uses *ADO.NET*. The steps are:

1. Import the provider namespace (`using System.Data.SqlClient;` for SQL Server).
2. Create a connection string with the server, database and login details.
3. Create a `SqlConnection` object and call `Open()`.
4. Create a `SqlCommand` with the SQL text and the connection.
5. Run it: `ExecuteReader()` for a SELECT, `ExecuteNonQuery()` for INSERT, UPDATE or DELETE, `ExecuteScalar()` for one value.
6. Read the rows with `SqlDataReader.Read()`.
7. Close the reader and the connection (a `using` block does this automatically).

```csharp
using System;
using System.Data.SqlClient;
class DbDemo {
    static void Main() {
        string cs = "Data Source=.;Initial Catalog=SchoolDB;Integrated Security=True";
        using (SqlConnection con = new SqlConnection(cs)) {
            con.Open();
            string sql = "SELECT Id, Name FROM Student";
            using (SqlCommand cmd = new SqlCommand(sql, con))
            using (SqlDataReader rd = cmd.ExecuteReader()) {
                while (rd.Read())
                    Console.WriteLine(rd["Id"] + "  " + rd["Name"]);
            }
        }   // the connection is closed here
    }
}
```

An INSERT is sent in the same way with `cmd.ExecuteNonQuery()`, and values from the user should be added with `cmd.Parameters.AddWithValue("@name", value)` to avoid SQL injection.

**Or: structure with three employees (8 marks).** A structure is a value type that groups members of different types.

```csharp
using System;
struct Employee {
    public int Id;
    public string Name;
}
class StructDemo {
    static void Main() {
        Employee[] emp = new Employee[3];
        for (int i = 0; i < 3; i++) {
            Console.Write("Enter ID of employee " + (i + 1) + ": ");
            emp[i].Id = Convert.ToInt32(Console.ReadLine());
            Console.Write("Enter name of employee " + (i + 1) + ": ");
            emp[i].Name = Console.ReadLine();
        }
        Console.WriteLine("\nID\tName");
        for (int i = 0; i < 3; i++)
            Console.WriteLine(emp[i].Id + "\t" + emp[i].Name);
    }
}
```

With the input (1, Ram), (2, Sita), (3, Hari) the output is the heading `ID  Name` and three rows, one per employee.
