**(a)** The coefficient of $x^n$ in $(1+x)^{2n}$ is ${}^{2n}C_n$, and in $(1+x)^{2n-1}$ it is ${}^{2n-1}C_n$. Then
$${}^{2n}C_n = \frac{(2n)!}{n!\,n!} = \frac{2n\,(2n-1)!}{n\cdot(n-1)!\;n!} = 2\cdot\frac{(2n-1)!}{(n-1)!\,n!}.$$
Because ${}^{2n-1}C_n = \dfrac{(2n-1)!}{n!\,[(2n-1)-n]!} = \dfrac{(2n-1)!}{n!\,(n-1)!}$, we obtain
$${}^{2n}C_n = 2\;{}^{2n-1}C_n.$$
So the coefficient of $x^n$ in $(1+x)^{2n}$ is twice the coefficient of $x^n$ in $(1+x)^{2n-1}$. Example: $n = 2$: ${}^4C_2 = 6$ and $2\times{}^3C_2 = 6$.

**(b)** Let $z = -(2 + 2\sqrt{3}\,i) = -2 - 2\sqrt{3}\,i$. Here $x = -2 < 0$ and $y = -2\sqrt{3} < 0$, so $z$ lies in the third quadrant.
$r = \sqrt{4 + 12} = 4$. The reference angle satisfies $\tan\alpha = \dfrac{2\sqrt{3}}{2} = \sqrt{3}$, so $\alpha = 60^\circ$ and $\theta = 180^\circ + 60^\circ = 240^\circ$.
$$z = 4\,(\cos240^\circ + i\sin240^\circ) = 4\,[\cos(240^\circ + 360^\circ k) + i\sin(240^\circ + 360^\circ k)].$$
By De Moivre's theorem,
$$z^{1/2} = 4^{1/2}\left[\cos\frac{240^\circ + 360^\circ k}{2} + i\sin\frac{240^\circ + 360^\circ k}{2}\right],\quad k = 0, 1.$$
$k = 0$: $2(\cos120^\circ + i\sin120^\circ) = 2\left(-\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i\right) = -1 + \sqrt{3}\,i$.
$k = 1$: $2(\cos300^\circ + i\sin300^\circ) = 2\left(\dfrac{1}{2} - \dfrac{\sqrt{3}}{2}i\right) = 1 - \sqrt{3}\,i$.
So the square roots are $\pm(1 - \sqrt{3}\,i)$. Check: $(1-\sqrt{3} i)^2 = 1 - 2\sqrt{3} i - 3 = -2 - 2\sqrt{3} i$. 

**(c)** *Note on the printed statement.* As printed, $n! < 2^n$ cannot be proved for all natural numbers because it is false from $n = 4$ on: $4! = 24$ but $2^4 = 16$. It holds only for $n = 1, 2, 3$ ($1<2$, $2<4$, $6<8$). The result that induction does prove (and that is the standard exercise) is the reverse inequality for $n \ge 4$, shown below.

*Statement:* $P(n)$: $n! > 2^n$ for all integers $n \ge 4$.
*Basis:* $n = 4$: $4! = 24 > 16 = 2^4$. So $P(4)$ is true.
*Inductive step:* assume $P(k)$: $k! > 2^k$ for some $k \ge 4$. Then
$$(k+1)! = (k+1)\,k! > (k+1)\,2^k \ge 2\cdot2^k = 2^{k+1},$$
because $k + 1 \ge 5 > 2$. So $P(k+1)$ is true.
By the principle of mathematical induction, $n! > 2^n$ for every $n \ge 4$. Together with the direct check of $n = 1, 2, 3$, this shows $n! < 2^n$ only for $n \le 3$ and $n! > 2^n$ for $n \ge 4$.

Equivalently $\cos C = \dfrac{a^2+b^2-c^2}{2ab} = \dfrac{13+6\sqrt{3}}{12+4\sqrt{3}} \approx 1.24 > 1$, which is impossible. So no triangle exists for these printed values; the figures contain a misprint.

*Standard version of this question:* $a = \sqrt{3} + 1$, $b = 2$, $c = \sqrt{6}$ (valid, since $b + c = 4.449 > a = 2.732$). Method for solving it:
$$\cos C = \frac{a^2+b^2-c^2}{2ab} = \frac{(4+2\sqrt{3}) + 4 - 6}{4(\sqrt{3}+1)} = \frac{2(1+\sqrt{3})}{4(\sqrt{3}+1)} = \frac{1}{2},\quad C = 60^\circ.$$
$$\cos A = \frac{b^2+c^2-a^2}{2bc} = \frac{4+6-(4+2\sqrt{3})}{4\sqrt{6}} = \frac{3-\sqrt{3}}{2\sqrt{6}} = 0.2588,\quad A = 75^\circ.$$
$B = 180^\circ - 75^\circ - 60^\circ = 45^\circ$. Solution: $A = 75^\circ$, $B = 45^\circ$, $C = 60^\circ$.

**(b)** The ellipse is $\dfrac{x^2}{25} + \dfrac{y^2}{100} = 1$. The larger denominator is under $y^2$, so the major axis is along the $y$-axis: $a^2 = 100$ (semi-major axis $a = 10$) and $b^2 = 25$ (semi-minor axis $b = 5$).

**(c)** If $\vec a$ and $\vec b$ are the *diagonals* of a parallelogram, its area is $\dfrac{1}{2}|\vec a\times\vec b|$.
Expanding the determinant with rows $(\vec i,\vec j,\vec k)$, $(1,\ 0,\ -2)$, $(4,\ 3,\ 1)$ along the first row:
$$\vec a\times\vec b = \vec i\,(0\cdot1 - (-2)(3)) - \vec j\,(1\cdot1 - (-2)(4)) + \vec k\,(1\cdot3 - 0\cdot4) = 6\vec i - 9\vec j + 3\vec k.$$
$|\vec a\times\vec b| = \sqrt{36 + 81 + 9} = \sqrt{126} = 3\sqrt{14}$.
Area $= \dfrac{1}{2}\times3\sqrt{14} = \dfrac{3\sqrt{14}}{2} \approx 5.61$ square units.

**(a)** Differentiate $y^2 = 8x$ with respect to time: $2y\dfrac{dy}{dt} = 8\dfrac{dx}{dt}$. The abscissa and ordinate change at the same rate, so $\dfrac{dy}{dt} = \dfrac{dx}{dt}$ (and $\ne0$). Then $2y = 8$, so $y = 4$. From the curve, $x = \dfrac{y^2}{8} = \dfrac{16}{8} = 2$.
The point is $(2, 4)$ and the ordinate $4 = 2\times2$ is double the abscissa. Hence the statement is justified.

**(b)** The integral depends on how $a$ and $b$ compare, because the substitution $t = \tan\dfrac x2$ gives $\cos x = \dfrac{1-t^2}{1+t^2}$, $dx = \dfrac{2\,dt}{1+t^2}$ and
$$\int\frac{dx}{a+b\cos x} = \int\frac{2\,dt}{(a+b) + (a-b)t^2},$$
whose result takes a different form according to the signs of $a+b$ and $a-b$:
- If $a = b$: $\displaystyle\int\frac{2\,dt}{2a} = \frac ta = \frac{1}{a}\tan\frac x2 + C$.
- If $a > b$ (so $a^2 > b^2$): the integral is of the inverse-tangent type,
$$\frac{2}{\sqrt{a^2-b^2}}\tan^{-1}\!\left[\sqrt{\frac{a-b}{a+b}}\,\tan\frac x2\right] + C.$$
- If $a < b$ (with $a + b > 0$): it becomes the logarithmic type,
$$\frac{1}{\sqrt{b^2-a^2}}\ln\left|\frac{\sqrt{b+a} + \sqrt{b-a}\,\tan\frac x2}{\sqrt{b+a} - \sqrt{b-a}\,\tan\frac x2}\right| + C.$$
- Special cases: $b = 0$ gives $\dfrac xa + C$, and $a = 0$ gives $\dfrac{1}{b}\ln|\sec x + \tan x| + C$.

Example: $a = 2$, $b = 1$ gives $\dfrac{2}{\sqrt{3}}\tan^{-1}\!\left(\dfrac{1}{\sqrt{3}}\tan\dfrac x2\right) + C$, but $a = 1$, $b = 2$ gives $\dfrac{1}{\sqrt{3}}\ln\left|\dfrac{\sqrt{3} + \tan(x/2)}{\sqrt{3} - \tan(x/2)}\right| + C$. Two different functions, so the value of the integral depends on $a$ and $b$.

**(c)** An equation $M(x,y)\,dx + N(x,y)\,dy = 0$ is exact when it is the total differential $df$ of some function $f(x,y)$, that is $M = \dfrac{\partial f}{\partial x}$ and $N = \dfrac{\partial f}{\partial y}$. The characteristic (test) is
$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}.$$
Example: $(2x + y)\,dx + (x + 2y)\,dy = 0$. Here $M = 2x + y$, $N = x + 2y$; $\dfrac{\partial M}{\partial y} = 1 = \dfrac{\partial N}{\partial x}$, so it is exact.
Solution: $f = \int M\,dx = x^2 + xy + g(y)$; $\dfrac{\partial f}{\partial y} = x + g'(y) = x + 2y$ gives $g = y^2$. So $x^2 + xy + y^2 = C$.
Counter-example: $y\,dx - x\,dy = 0$ has $\dfrac{\partial M}{\partial y} = 1$ but $\dfrac{\partial N}{\partial x} = -1$, so it is not exact.
