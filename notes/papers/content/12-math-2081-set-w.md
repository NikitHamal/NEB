**(a)** The triangle law of forces: if three forces acting at a point can be represented in magnitude and direction by the three sides of a triangle taken in order, they are in equilibrium. *Example:* a lamp (or picture) of weight $W$ hung from the ceiling by two strings. The weight $W$ and the tensions $T_1$ and $T_2$ in the strings act at the knot and balance, so drawn head to tail as three vectors they form a closed triangle.

**(b)** Let the speed of projection be $u$ and the angle $\theta$, so $H = \dfrac{u^2\sin^2\theta}{2g}$.
At the greatest height the velocity is horizontal: $v_1 = u\cos\theta$.
At half the greatest height $y = \dfrac H2$: the horizontal component is still $u\cos\theta$ and the vertical component satisfies
$$v_y^2 = u^2\sin^2\theta - 2g\cdot\frac H2 = u^2\sin^2\theta - \frac{u^2\sin^2\theta}{2} = \frac{u^2\sin^2\theta}{2}.$$

**(c)** Let $P(n)$: $n^3 + 2n$ is divisible by 3.

*Step 1 (basis).* $P(1)$: $1 + 2 = 3$, divisible by 3. True.

*Step 2 (hypothesis).* Assume $P(k)$ is true for some positive integer $k$: $k^3 + 2k = 3m$ for some integer $m$.

*Step 3 (induction step).*
$$(k+1)^3 + 2(k+1) = k^3 + 3k^2 + 3k + 1 + 2k + 2 = (k^3 + 2k) + 3(k^2 + k + 1) = 3m + 3(k^2 + k + 1) = 3\,(m + k^2 + k + 1).$$
This is divisible by 3, so $P(k+1)$ is true.

By the principle of mathematical induction, $n^3 + 2n$ is divisible by 3 for every positive integer $n$. ∎

**(a)** Circle $x^2 + y^2 = 25$ has centre $(0,0)$ and radius $5$. The point $(13,0)$ is outside it ($13 > 5$), so there are two tangents. The vertical line $x = 13$ is at distance 13 from the centre, so it is not a tangent. Let the tangent have slope $m$: $y = m(x - 13)$, i.e. $mx - y - 13m = 0$. It must be at distance 5 from the origin:
$$\frac{|-13m|}{\sqrt{m^2+1}} = 5 \ \Rightarrow\ 169m^2 = 25(m^2 + 1) \ \Rightarrow\ 144m^2 = 25 \ \Rightarrow\ m = \pm\frac{5}{12}.$$
Tangents: $y = \dfrac{5}{12}(x - 13)$ and $y = -\dfrac{5}{12}(x - 13)$, i.e.
$$5x - 12y - 65 = 0\qquad\text{and}\qquad 5x + 12y - 65 = 0.$$
Check: distance of $5x - 12y - 65 = 0$ from the origin is $\dfrac{65}{13} = 5$ ✓.

**(c)** Let $A(2,-1,3)$, $B(1,-1,-2)$ and $C(1,2,3)$.
$\vec{AB} = (1-2,\,-1+1,\,-2-3) = (-1, 0, -5)$ and $\vec{AC} = (1-2,\,2+1,\,3-3) = (-1, 3, 0)$.
Expand the determinant with rows $(\vec i,\vec j,\vec k)$, $(-1, 0, -5)$ and $(-1, 3, 0)$ along the first row:
$$\vec{AB}\times\vec{AC} = \vec i\,(0\cdot0 + 15) - \vec j\,(0 - 5) + \vec k\,(-3 - 0) = 15\vec i + 5\vec j - 3\vec k.$$
$$|\vec{AB}\times\vec{AC}| = \sqrt{225 + 25 + 9} = \sqrt{259}.$$
$$\text{Area} = \tfrac12\left|\vec{AB}\times\vec{AC}\right| = \frac{\sqrt{259}}{2} \approx 8.05\ \text{square units}.$$

**(a)** Dividing by $\sin x$: $\dfrac{dy}{dx} + (\cot x)\,y = x$. This is a **first-order linear differential equation** of the form $\dfrac{dy}{dx} + Py = Q$ with $P = \cot x$ and $Q = x$.

Integrating factor: $\text{I.F.} = e^{\int\cot x\,dx} = e^{\log\sin x} = \sin x$.
The solution is $y\cdot\text{I.F.} = \int Q\cdot\text{I.F.}\,dx + C$:
$$y\sin x = \int x\sin x\,dx.$$
Integrate by parts ($u = x$, $dv = \sin x\,dx$): $\int x\sin x\,dx = -x\cos x + \int\cos x\,dx = -x\cos x + \sin x$. Hence
$$y\sin x = -x\cos x + \sin x + C\ \Rightarrow\ y = 1 - x\cot x + C\,\text{cosec}\,x.$$
(The left side of the original equation is $\dfrac{d}{dx}(y\sin x)$, which confirms the step.)

**(b)** Resolve into partial fractions:
$$\frac{x}{(x-1)(x^2+1)} = \frac{A}{x-1} + \frac{Bx + C}{x^2+1}\ \Rightarrow\ x = A(x^2+1) + (Bx + C)(x-1).$$
Put $x = 1$: $1 = 2A$, so $A = \tfrac12$. Compare $x^2$: $0 = A + B$, so $B = -\tfrac12$. Constant term: $0 = A - C$, so $C = \tfrac12$. (Check the $x$ term: $C - B = 1$ ✓.)
$$\int\frac{x\,dx}{(x-1)(x^2+1)} = \frac12\int\frac{dx}{x-1} - \frac12\int\frac{x\,dx}{x^2+1} + \frac12\int\frac{dx}{x^2+1}$$
$$= \frac12\log_e|x-1| - \frac14\log_e(x^2+1) + \frac12\tan^{-1}x + C.$$

**(c)** Let $x$ = distance of the first car east of the starting point, $y$ = distance of the second car south of it, and $z$ = distance between them. The directions are at right angles, so
$$z^2 = x^2 + y^2.$$
Differentiate with respect to time $t$:
$$2z\frac{dz}{dt} = 2x\frac{dx}{dt} + 2y\frac{dy}{dt}\ \Rightarrow\ \frac{dz}{dt} = \frac{x\dfrac{dx}{dt} + y\dfrac{dy}{dt}}{z}.$$
Here $\dfrac{dx}{dt} = 60$ and $\dfrac{dy}{dt} = 80$ km/hr; after time $t$, $x = 60t$, $y = 80t$ and $z = 100t$. So
$$\frac{dz}{dt} = \frac{60t(60) + 80t(80)}{100t} = \frac{10000t}{100t} = 100\ \text{km/hr}.$$
**The distance between the cars is increasing at 100 km/hr.**
