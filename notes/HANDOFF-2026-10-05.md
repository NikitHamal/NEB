## How to push (the owner's repo is private; `git push` cannot work)

The only write credential is the AgentSky GitHub connector. Blobs are sent
through the connector's own HTTP endpoint, not `actl connector call` (which is
capped by `ARG_MAX`):

```
cd <repo>
NEB_BRANCH=resources/class10-class8-agent-a \
  python3 notes/tools/push_branch.py push "message" <files...>     # or --all-changed
```

Files over ~25 MB are refused by the connector (HTTP 413); run an oversized
book through `notes/tools/shrink_pdf.py` first.

Reading the repo (no credentials needed for public data, but this repo is
private): `actl connector call github --url "https://api.github.com/..."`.
A `temp_clone_token` from the repo API works for a **read-only** blobless clone
(`git clone --filter=blob:none --sparse`). It does **not** work for `git push`.

## Environment recipe (rebuilt from scratch each session)

```
apt-get install -y libpango-1.0-0 libpangoft2-1.0-0 libpangocairo-1.0-0 \
    libgobject-2.0-0 libcairo2 shared-mime-info fonts-dejavu-core fontconfig
pip install weasyprint numpy matplotlib pymupdf markdown pillow
bash notes/pipeline/fonts/install.sh
cd notes/pipeline && python3 check.py ../content/<slug>/unit-NN.md
python3 build_pdf.py <slug>          # -> notes/pdf/
```

`check.py` takes about 15 s per chapter; `build_pdf.py` about 1–3 minutes per
book on 2 cores.
