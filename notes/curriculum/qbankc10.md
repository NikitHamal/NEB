# SUBJECT: Commerce Question Bank | GRADE: 10 | CODE: QB-COMM-10 | WORKING_HOURS: revision
# EXAM: SEE (Secondary Education Examination), the commerce/management electives of this series — Accountancy (कार्यालय सञ्चालन तथा लेखा, subject code 104) and Economics (अर्थशास्त्र, subject code 104/ECO). Both papers: Full Marks 75 written (+25 internal/practical), Time 3 hours, Group A very short answer 11 × 1, Group B short answer 8 × 5, Group C long answer 3 × 8, 22 questions in all.
