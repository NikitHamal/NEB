## 1. Computer Network and Communication [14]
- Concept of telecommunication: bandwidth, throughput, broadband, mobile generations (3G, 4G, 5G), data packets, frequency and communication modes (simplex, half duplex, full duplex)
- Communication media: guided media (twisted pair and CAT6, coaxial, optical fibre) and unguided media (radio wave, microwave, infrared, satellite, Wi-Fi, Bluetooth)
- Connectors: RJ-45, RJ-11, BNC, fibre connectors (ST, SC, SMA) and the media converter
- Networking devices: NIC, repeater, hub, switch, router, modem, wireless access point and gateway
- Network topology: bus, ring, star, mesh and tree/hybrid
- Networks by coverage: PAN, LAN, MAN and WAN
- Network architecture: client-server and peer-to-peer
- IP addressing: IPv4 and IPv6, private and public addresses, static and dynamic addresses, checking an IP address and default gateway
- Internet, intranet and extranet
## 2. Database Management System [10]
- Introduction to database; data, information, database and DBMS; advantages of a DBMS
- Data types in MySQL: numeric, string and date/time types
- Table: field, record, and table design
- Keys: primary key, foreign key, composite and candidate keys; types of relationship (one-to-one, one-to-many, many-to-many)
- Introduction to MySQL: features, installing MySQL 8 and working in MySQL Workbench
- Data Definition Language (DDL): CREATE, ALTER, DROP and TRUNCATE
- Data Manipulation Language (DML): INSERT, SELECT with WHERE, ORDER BY and LIKE, UPDATE and DELETE
## 3. Multimedia [10]
- Introduction to multimedia, its elements and applications
- Text: fonts, typography and text file formats
- Graphics: raster and vector images, pixels and resolution, graphics file formats, and editing images in Pixlr and Canva
- Audio: digital sound, audio file formats, and recording and editing audio in Audacity
- Video: frames, frame rate and resolution, video file formats, and editing and exporting video in CapCut
- Concept of animation: 2D and 3D animation, frame-by-frame and keyframe animation, and where animation is used
## 4. Programming in Python [16]
- Revision of the basics of Python: data types, variables, operators, input/output, selection and loops
- User-defined functions: defining and calling functions, passing parameters and returning values
- Concept of library and packages in Python: modules, math, random, datetime and pip
- Graphics using Turtle
- Error handling: syntax errors, runtime errors and exceptions, try-except blocks
- File handling: text files, and CSV files with the pandas library
- Introduction to data visualization with Matplotlib: line, bar and pie charts
## 5. AI and Contemporary Technologies [14]
- Artificial Intelligence and Machine Learning: meaning, types and applications
- Learning techniques: supervised, unsupervised and reinforcement learning
- AI in robotics: sensing, deciding and acting; simulating simple robotic tasks
- Generative AI: how large language models and image generators work, prompting and limitations
- Application of integrated AI tools in study and work
- Ethics in AI: bias, privacy and security
- Internet of Things (IoT) and its applications
- Virtual reality, augmented reality and extended reality (XR)
- Cloud computing: service models (IaaS, PaaS, SaaS) and applications
- e-Commerce, e-Governance and e-Education in Nepal
