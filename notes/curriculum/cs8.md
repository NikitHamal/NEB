# AREA: Computer Fundamentals
## 1. Fundamentals of Computer
- Computer: definition; data, information and program; hardware and software
- Working principle of a computer: input, process, output and storage (the IPOS cycle)
- Characteristics of a computer: speed, accuracy, diligence, versatility, storage and automation
- Limitations of a computer and its effects on society
- Uses of computers in Nepal: education, banking, health, communication, agriculture and government
## 2. History of Computer
- Early calculating devices: abacus, Napier's bones and the slide rule
- Mechanical calculators: Pascaline, Leibniz's stepped reckoner and the Jacquard loom
- Charles Babbage's Difference Engine and Analytical Engine; Ada Lovelace
- Electromechanical and electronic machines: Hollerith's tabulating machine, Mark I, ABC, ENIAC, EDVAC and UNIVAC
- Computers in Nepal: from the census of 2028 BS to today
## 3. Generations of Computer
- Meaning of a computer generation
- First generation: vacuum tubes
- Second generation: transistors
- Third generation: integrated circuits
- Fourth generation: microprocessors
- Fifth generation: artificial intelligence and parallel processing
## 4. Types of Computer
- Classification by working principle: analog, digital and hybrid computers
- Classification by size: supercomputer, mainframe, minicomputer and microcomputer
- Microcomputers: desktop, laptop, tablet, smartphone and workstation
- Classification by purpose: general-purpose and special-purpose computers
- Choosing a computer for a task
## 5. Computer Software
- Software: meaning and importance; how hardware and software work together
- System software: operating system, device drivers, utility programs and language processors
- Application software: packaged and tailor-made software
- Software licences: proprietary, freeware, shareware and open-source software
- Installing, updating and removing software safely
## 6. Operating System
- Operating system: meaning and functions
- Types of operating system: single-user and multi-user, CUI and GUI, desktop and mobile
- Common operating systems: Windows, Linux, macOS, Android and iOS
- Working with Windows: desktop, taskbar, Start menu, windows and dialog boxes
- File management: files, folders, paths and extensions; copy, move, rename and delete; Recycle Bin
- Settings: date and time, display, user accounts, installing and removing programs
# AREA: Application Software
## 7. Word Processing
- Word processor: features and examples
- Creating, saving, opening and printing a document
- Editing: select, cut, copy, paste, undo, find and replace, spelling and grammar check
- Formatting: font, paragraph, bullets and numbering, page layout, header, footer and page numbers
- Tables, pictures, shapes and WordArt
- Mail merge
## 8. Spreadsheet Software
- Spreadsheet: workbook, worksheet, row, column, cell, cell address and range
- Entering and editing data; data types; AutoFill
- Formulas and operators; relative and absolute cell references
- Functions: SUM, AVERAGE, MAX, MIN, COUNT and IF
- Formatting cells; sorting and filtering data
- Charts: column, bar, line and pie
## 9. Presentation Software
- Presentation software: features and examples
- Creating a presentation: slides, layouts, themes and placeholders
- Inserting text, pictures, tables, charts, audio and video
- Transitions and animations
- Slide views, the slide master and running a slide show
- Designing an effective presentation
# AREA: Web, Communication and Society
## 10. Web Page Design
- World Wide Web: web page, website, web browser, URL and HTML
- Structure of an HTML document: html, head, title and body
- Formatting tags: headings, paragraphs, line breaks, bold, italic, underline and font
- Lists, images and hyperlinks
- Tables in HTML
- Creating and viewing a small website
## 11. Information and Communication Technology
- ICT: meaning, components and uses
- Communication technologies: telephone, mobile, radio, television, satellite and the internet
- Internet services: WWW, e-mail, search engines, chat, video conferencing and cloud storage
- ICT in Nepal: e-governance, online banking and digital payments, e-learning
- Advantages and disadvantages of ICT; the digital divide
## 12. Computer Ethics and Cyber Law
- Computer ethics: meaning and the Ten Commandments of computer ethics
- Cyber crime: hacking, phishing, cyber bullying, identity theft and software piracy
- Intellectual property, copyright and plagiarism
- Cyber law in Nepal: the Electronic Transactions Act, 2063
- Digital citizenship and safe use of social media
## 13. Computer Virus
- Computer virus: meaning, history and how it spreads
- Types of malware: virus, worm, Trojan horse, spyware, adware and ransomware
- Symptoms of an infected computer
- Antivirus software: how it works and examples
- Protecting a computer: safe browsing, updates, backups and strong passwords
## 14. Computer Network
- Computer network: meaning, advantages and disadvantages
- Network components: server, client, NIC, cables, hub, switch, router and modem
- Transmission media: wired and wireless
- Types of network: LAN, MAN and WAN
- Network topology: bus, ring and star
- The internet as a network of networks
# AREA: Number System, Graphics and Multimedia
## 15. Number System
- Number systems: decimal, binary, octal and hexadecimal
- Converting decimal numbers to binary, octal and hexadecimal
- Converting binary, octal and hexadecimal numbers to decimal
- Converting between binary, octal and hexadecimal
- Bits, bytes and the units of memory
## 16. Computer Graphics
- Computer graphics: meaning and uses
- Raster and vector graphics
- Graphics software: Paint, GIMP, Inkscape and Canva
- Drawing and editing a picture
- Image file formats: BMP, JPEG, PNG, GIF and SVG
## 17. Multimedia
- Multimedia: meaning and elements (text, graphics, audio, video and animation)
- Multimedia hardware and software
- Uses of multimedia in education, entertainment, business and health
- Advantages and disadvantages of multimedia
# AREA: Programming
## 18. Program Design Tools
- Program and programming; steps of program development
- Algorithm: meaning, features and writing algorithms
- Flowchart: symbols, rules and drawing flowcharts
- Sequence, selection and repetition in algorithms and flowcharts
- Pseudocode
## 19. Fundamentals of Computer Programming
- Programming languages: low-level (machine and assembly) and high-level languages
- Language processors: compiler, interpreter and assembler
- Syntax errors, logical errors and run-time errors; testing and debugging
- Common high-level languages: QBASIC, Python, C and Java
- Constants, variables and data types
## 20. Computer Programming using QBASIC
- QBASIC: features and the QBASIC screen
- Character set, constants, variables and operators
- Statements: CLS, REM, LET, INPUT, PRINT and END
- Library functions: mathematical and string functions
- Selection: IF...THEN...ELSE and SELECT CASE
- Loops: FOR...NEXT, WHILE...WEND and DO...LOOP
- Writing, running and debugging simple programs
