अघिल्लो अध्यायमा शब्दको अगाडि-पछाडि **शब्दांश** जोडेर नयाँ शब्द बनाइयो। यहाँ **पूरै शब्द**सँग शब्द जोडिन्छ। एउटै शब्द दोहोर्‍याउँदा **द्वित्व** बन्छ — *घरघर*, *बिस्तारै-बिस्तारै*; दुई फरक शब्द जोडिँदा **समास** बन्छ — *राजकुमार*, *आमाबुबा*, *नीलकण्ठ*। परीक्षामा **शब्दनिर्माण**बाट आउने **३ अङ्क** मध्ये समास सबैभन्दा नियमित प्रश्न हो, किनभने यसको उत्तर **विग्रह** गरेर प्रमाणित गर्न सकिन्छ। कक्षा ११ मा समासका नाम चिनाइएका थिए; यहाँ **प्रधान पद कुन हो** भन्ने एउटै कसोटीबाट छवटै भेद छुट्याउने तरिका सिकिन्छ।

::: key परीक्षाले खोज्ने चार कुरा
**(१)** दिइएको समस्त पदको **विग्रह** गर्न सक्नु — जोडिएको शब्दलाई फुकाएर लेख्नु। **(२)** विग्रह हेरेर **प्रधान पद** पहिचान गर्नु। **(३)** प्रधान पदका आधारमा **समासको भेद** भन्नु। **(४)** द्वित्वका चार किसिम उदाहरणसहित छुट्याउनु।
:::

:::

## 20.2 समास

::: definition समास
दुई वा दुईभन्दा बढी पद आपसमा मिलेर एउटै पद बन्ने प्रक्रियालाई **समास** भनिन्छ। बनेको एउटै शब्दलाई **समस्त पद** र त्यसलाई फुकाएर लेख्ने कामलाई **विग्रह** भनिन्छ।
:::

| पद | नाम |
|---|---|
| अगाडिको पद | **पूर्वपद** |
| पछाडिको पद | **उत्तरपद** |
| जोडिएर बनेको शब्द | **समस्त पद** |
| फुकाएर लेखेको रूप | **विग्रह** |

जस्तै — *राजकुमार* समस्त पद; *राजाको कुमार* विग्रह; *राजा* पूर्वपद; *कुमार* उत्तरपद।

## 20.3 तत्पुरुष समास

::: definition तत्पुरुष समास
**उत्तरपद प्रधान** भई विग्रहमा पूर्वपदसँग कुनै **विभक्ति** लाग्ने समासलाई **तत्पुरुष समास** भनिन्छ।
:::

विभक्तिका आधारमा यसका भेद:

| भेद | विभक्ति | समस्त पद | विग्रह |
|---|---|---|---|
| द्वितीया तत्पुरुष | लाई | स्वर्गप्राप्त | स्वर्गलाई प्राप्त |
| तृतीया तत्पुरुष | ले/द्वारा | रोगपीडित | रोगले पीडित |
| चतुर्थी तत्पुरुष | का लागि | गोशाला | गाईका लागि शाला |
| पञ्चमी तत्पुरुष | बाट/देखि | ऋणमुक्त | ऋणबाट मुक्त |
| षष्ठी तत्पुरुष | को/का/की | राजकुमार | राजाको कुमार |
| सप्तमी तत्पुरुष | मा | गृहप्रवेश | गृहमा प्रवेश |

थप उदाहरण — *पापमुक्त* (पापबाट मुक्त), *गङ्गाजल* (गङ्गाको जल), *विद्यालय* (विद्याको आलय), *वनवास* (वनमा वास), *देशभक्त* (देशप्रति भक्त), *तुलसीकृत* (तुलसीले कृत)।

## 20.4 कर्मधारय समास

::: definition कर्मधारय समास
पूर्वपद **विशेषण** र उत्तरपद **विशेष्य** भई दुवै पद एउटै कारकमा रहने, उत्तरपद प्रधान भएको समासलाई **कर्मधारय समास** भनिन्छ।
:::

| समस्त पद | विग्रह |
|---|---|
| महापुरुष | महान् पुरुष |
| नीलकमल | नीलो कमल |
| परमेश्वर | परम ईश्वर |
| महाराज | महान् राजा |
| कालापानी | कालो पानी |
| सज्जन | सत् जन (असल मानिस) |

::: caution तत्पुरुष र कर्मधारय छुट्याउने कसोटी
विग्रहमा पूर्वपदसँग **विभक्ति** लाग्यो भने **तत्पुरुष** — *राजाको कुमार*। पूर्वपद उत्तरपदको **विशेषण** भयो र विभक्ति लागेन भने **कर्मधारय** — *नीलो कमल*। *नीलकमल* मा "नीलोको कमल" भन्न मिल्दैन, त्यसैले यो कर्मधारय हो। कर्मधारय वास्तवमा तत्पुरुषकै एक उपभेद मानिन्छ, तर परीक्षामा छुट्टै नाम लेख्नुपर्छ।
:::

## 20.5 द्विगु समास

::: definition द्विगु समास
पूर्वपद **सङ्ख्यावाचक** भई समूह वा समाहार जनाउने, उत्तरपद प्रधान भएको समासलाई **द्विगु समास** भनिन्छ।
:::

| समस्त पद | विग्रह |
|---|---|
| चौबाटो | चार बाटोको समूह |
| त्रिभुवन | तीन भुवनको समाहार |
| पञ्चतत्त्व | पाँच तत्त्वको समूह |
| सप्ताह | सात दिनको समूह |
| दशावतार | दश अवतारको समूह |
| नवरत्न | नौ रत्नको समूह |
| तीनतले | तीन तलाको |

## 20.6 द्वन्द्व समास

::: definition द्वन्द्व समास
**दुवै पद प्रधान** भई विग्रहमा *र*, *अनि* वा *वा* लाग्ने समासलाई **द्वन्द्व समास** भनिन्छ।
:::

| समस्त पद | विग्रह |
|---|---|
| आमाबुबा | आमा र बुबा |
| दालभात | दाल र भात |
| नाककान | नाक र कान |
| हातखुट्टा | हात र खुट्टा |
| लोग्नेस्वास्नी | लोग्ने र स्वास्नी |
| राजारानी | राजा र रानी |
| दिनरात | दिन र रात |
| सुखदुःख | सुख र दुःख |

## 20.7 बहुव्रीहि समास

::: definition बहुव्रीहि समास
दुवै पदमध्ये कुनै पनि प्रधान नभई **तिनले जनाउने तेस्रो कुनै अर्थ** प्रधान हुने समासलाई **बहुव्रीहि समास** भनिन्छ।
:::

| समस्त पद | विग्रह | कसलाई जनाउँछ |
|---|---|---|
| दशानन | दश आनन भएको | रावण |
| पीताम्बर | पहेँलो अम्बर भएको | कृष्ण |
| चक्रपाणि | चक्र पाणि (हात) मा भएको | विष्णु |
| लम्बोदर | लामो उदर भएको | गणेश |
| नीलकण्ठ | नीलो कण्ठ भएको | शिव |
| चतुर्भुज | चार भुजा भएको | विष्णु |
| पितामह | पिताको पिता | बाजे |

::: caution बहुव्रीहिको एउटै पहिचान — तेस्रो कुरा
*नीलकण्ठ* लाई कर्मधारय पनि पढ्न सकिन्छ (*नीलो कण्ठ*), तर त्यो **शिव** लाई जनाउँछ भने बहुव्रीहि हो। कसोटी — **समस्त पदले पूर्वपद वा उत्तरपद कुनैलाई नजनाई तेस्रै कुरालाई जनायो ?** जनायो भने **बहुव्रीहि**। *दशानन* ले न "दश" जनाउँछ न "आनन" — **रावण** जनाउँछ, त्यसैले बहुव्रीहि।
:::

## 20.8 अव्ययीभाव समास

::: definition अव्ययीभाव समास
पूर्वपद **अव्यय** भई पूरै समस्त पद अव्यय (क्रियायोगी) बन्ने समासलाई **अव्ययीभाव समास** भनिन्छ। यसमा **पूर्वपद प्रधान** हुन्छ।
:::

| समस्त पद | विग्रह |
|---|---|
| यथाशक्ति | शक्तिअनुसार |
| यथासमय | समयअनुसार |
| प्रतिदिन | हरेक दिन |
| आजीवन | जीवनभरि |
| आमरण | मृत्युसम्म |
| निर्विघ्न | विघ्नबिना |
| भरपेट | पेटभरि |

## 20.9 समास पहिचानको चार-चरण विधि

परीक्षामा जुनसुकै समस्त पद आए पनि यही क्रम लगाउनुहोस् — अनुमान गर्नु पर्दैन।

| चरण | प्रश्न | निष्कर्ष |
|---|---|---|
| १ | पूर्वपद **अव्यय** हो ? (यथा, प्रति, आ, निर्, भर) | हो भने **अव्ययीभाव** — यहीँ रोकिनुहोस् |
| २ | समस्त पदले **तेस्रै कुरा** जनायो ? | जनायो भने **बहुव्रीहि** |
| ३ | विग्रहमा ***र*** लाग्यो ? | लाग्यो भने **द्वन्द्व** |
| ४ | पूर्वपद **सङ्ख्या** हो ? **विशेषण** हो ? कि **विभक्ति** लाग्यो ? | क्रमशः **द्विगु**, **कर्मधारय**, **तत्पुरुष** |

नमुना — *आजीवन*। चरण १: *आ* अव्यय हो → **अव्ययीभाव**, सकियो।
नमुना — *पीताम्बर*। चरण १: *पीत* अव्यय होइन। चरण २: कृष्णलाई जनायो → **बहुव्रीहि**।
नमुना — *नवरत्न*। चरण १, २, ३ मा पर्दैन। चरण ४: *नव* सङ्ख्या हो → **द्विगु**।

::: tip उत्तरमा सधैँ विग्रह लेख्नुहोस्
"समासको भेद लेख्नुहोस्" भन्ने प्रश्नमा भेदको नाम मात्र लेख्दा पूरा अङ्क आउँदैन। **विग्रह + भेद + कारण** — तीनै लेख्नुहोस्। जस्तै: *ऋणमुक्त* = **ऋणबाट मुक्त** (विग्रह), **पञ्चमी तत्पुरुष** (भेद), किनभने पूर्वपदसँग **बाट** विभक्ति लाग्यो (कारण)।
:::

::: example विग्रह गरेर भेद तय गर्ने
**प्रश्न.** *"चक्रपाणि"* को विग्रह गरी समासको भेद कारणसहित लेख्नुहोस्।

**समाधान.**
१. विग्रह — *चक्र पाणि (हात) मा भएको*।
२. यसले "चक्र" पनि जनाउँदैन, "पाणि" पनि जनाउँदैन।
३. यसले **विष्णु** भन्ने तेस्रै कुरा जनायो।
४. तेस्रो अर्थ प्रधान भएकाले यो **बहुव्रीहि समास** हो।

**उत्तर.** बहुव्रीहि समास — चक्र हातमा भएका, अर्थात् विष्णु।
:::

::: example मिल्दोजुल्दो जोडी छुट्याउने
**प्रश्न.** *"नीलकमल"* र *"नीलकण्ठ"* — दुवैमा *नील* छ; भेद उही हो कि फरक ?

**समाधान.**
१. *नीलकमल* = *नीलो कमल*। यसले साँच्चै **कमल** नै जनाउँछ → उत्तरपद प्रधान → **कर्मधारय समास**।
२. *नीलकण्ठ* = *नीलो कण्ठ भएको*। यसले कण्ठ जनाउँदैन, **शिव** जनाउँछ → तेस्रो अर्थ प्रधान → **बहुव्रीहि समास**।

**उत्तर.** भेद फरक — पहिलो कर्मधारय, दोस्रो बहुव्रीहि। पूर्वपद उही भए पनि **समस्त पदले कसलाई जनायो** भन्ने कुराले भेद तय गर्छ।
:::

::: example द्वित्व कि समास
**प्रश्न.** *"हल्लाखल्ला"*, *"हातखुट्टा"*, *"टुकटुक"* — यी तीनलाई छुट्याई किसिम लेख्नुहोस्।

**समाधान.**
१. *हल्लाखल्ला* — *खल्ला* आफैँमा अर्थपूर्ण शब्द होइन, *हल्ला* कै फेरिएको रूप हो → **आंशिक द्वित्व**।
२. *हातखुट्टा* — *हात* र *खुट्टा* दुवै फरक अर्थ भएका शब्द हुन्, विग्रहमा *र* लाग्छ → **द्वन्द्व समास**।
३. *टुकटुक* — आवाजको नक्कल हो → **अनुकरणात्मक द्वित्व**।
:::

## पाठको सार

- **द्वित्व** = उही वा मिल्दोजुल्दो शब्द दोहोर्‍याउनु। चार किसिम — **पूर्ण** (घरघर), **आंशिक** (उल्टोपुल्टो), **अनुकरणात्मक** (झमझम), **प्रतिध्वन्यात्मक** (किताब-सिताब)।
- **समास** = दुई फरक पद जोडिएर एउटै पद बन्नु। जोडिएको रूप **समस्त पद**, फुकाएको **विग्रह**।
- भेद तय गर्ने एउटै कसोटी — **विग्रह गरेपछि कुन पद प्रधान ?**
- **उत्तरपद प्रधान** — **तत्पुरुष** (विभक्ति लाग्छ: राजकुमार), **कर्मधारय** (पूर्वपद विशेषण: नीलकमल), **द्विगु** (पूर्वपद सङ्ख्या: चौबाटो)।
- **दुवै पद प्रधान** — **द्वन्द्व** (विग्रहमा *र*: आमाबुबा)।
- **अन्य पद प्रधान** — **बहुव्रीहि** (तेस्रो कुरा जनाउँछ: दशानन = रावण)।
- **पूर्वपद प्रधान** — **अव्ययीभाव** (पूर्वपद अव्यय, पूरै पद अव्यय बन्छ: यथाशक्ति)।
- पहिचानको क्रम — **अव्यय ? तेस्रो अर्थ ? *र* ? अनि सङ्ख्या/विशेषण/विभक्ति** — यही चार चरणले सबै भेद छुट्याउँछ।
- तत्पुरुषका छ उपभेद विभक्तिका आधारमा — द्वितीया, तृतीया, चतुर्थी, पञ्चमी, षष्ठी, सप्तमी।

::: note उत्तर
**२१.** **पूर्ण द्वित्व** — उही शब्द जस्ताको तस्तै: *घरघर, ठुला ठुला*। **आंशिक द्वित्व** — दोस्रो पदमा वर्ण फेरिन्छ: *उल्टोपुल्टो, हल्लाखल्ला*। **अनुकरणात्मक द्वित्व** — आवाज/गतिको नक्कल: *झमझम, टुकटुक*। **प्रतिध्वन्यात्मक द्वित्व** — दोस्रो पद निरर्थक: *किताब-सिताब, पानी-सानी*।
**२२.** **उत्तरपद प्रधान** — *तत्पुरुष* (राजकुमार), *कर्मधारय* (नीलकमल), *द्विगु* (चौबाटो)। **दुवै पद प्रधान** — *द्वन्द्व* (आमाबुबा)। **अन्य पद प्रधान** — *बहुव्रीहि* (दशानन = रावण)। **पूर्वपद प्रधान** — *अव्ययीभाव* (यथाशक्ति)।
**२३.** कसोटी — **विग्रहमा पूर्वपदसँग विभक्ति लाग्यो कि लागेन ?** लाग्यो भने **तत्पुरुष**: *राजकुमार* = राजा**को** कुमार; *गृहप्रवेश* = गृह**मा** प्रवेश। नलागी पूर्वपद उत्तरपदको **विशेषण** भयो भने **कर्मधारय**: *नीलकमल* = नीलो कमल; *महापुरुष* = महान् पुरुष। *नीलकमल* लाई "नीलोको कमल" भन्न मिल्दैन, त्यसैले त्यो तत्पुरुष होइन।
**२४.** **कसोटी** — समस्त पदले पूर्वपद वा उत्तरपद कुनैलाई नजनाई **तेस्रै कुरा**लाई जनायो भने त्यो बहुव्रीहि हो। **उदाहरण** — *दशानन* (दश आनन भएको = **रावण**), *पीताम्बर* (पहेँलो अम्बर भएको = **कृष्ण**), *लम्बोदर* (लामो उदर भएको = **गणेश**)। यीमध्ये कुनैले पनि "आनन", "अम्बर" वा "उदर" जनाउँदैन।
**२५.** **द्वितीया** — *स्वर्गप्राप्त* = स्वर्ग**लाई** प्राप्त। **तृतीया** — *रोगपीडित* = रोग**ले** पीडित। **चतुर्थी** — *गोशाला* = गाई**का लागि** शाला। **पञ्चमी** — *ऋणमुक्त* = ऋण**बाट** मुक्त। **षष्ठी** — *राजकुमार* = राजा**को** कुमार। **सप्तमी** — *गृहप्रवेश* = गृह**मा** प्रवेश।
:::
