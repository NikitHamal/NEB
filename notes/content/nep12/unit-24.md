::: key परीक्षाले खोज्ने चार कुरा
**(१)** प्रत्यक्ष र अप्रत्यक्ष उक्ति **चिन्नु**। **(२)** पाँच चरणको नियम लगाएर **परिवर्तन** गर्नु — वाक्यभेदअनुसार फरक-फरक। **(३)** दिइएको वाक्यको **उद्देश्य र विधेय** छुट्याएर **विस्तार** गर्नु। **(४)** नेपाली **वर्णक्रम**अनुसार शब्द मिलाउनु र शब्दकोशीय प्रविष्टि पढ्नु।
:::

## 24.1 उक्ति र उक्ति परिवर्तन

::: definition उक्ति
कसैले भनेको कुरा उल्लेख गर्ने तरिकालाई **उक्ति** भनिन्छ। वक्ताको कुरा **जस्ताको तस्तै** उद्धरण चिह्नभित्र राख्दा **प्रत्यक्ष उक्ति**, र त्यसलाई **आफ्नै शब्दमा** ढालेर लेख्दा **अप्रत्यक्ष उक्ति** हुन्छ।
:::

| पक्ष | प्रत्यक्ष उक्ति | अप्रत्यक्ष उक्ति |
|---|---|---|
| उद्धरण चिह्न | हुन्छ | हुँदैन |
| योजक | चाहिँदैन | *कि, भनेर, भन्ने* चाहिन्छ |
| सर्वनाम | वक्ताको दृष्टिले | लेखकको दृष्टिले |
| काल | वक्ताले भनेकै | मुख्य क्रियाअनुसार सर्ने |
| नमुना | उसले भन्यो, "म जान्छु।" | उसले आफू जाने कुरा भन्यो। |

### सर्वनाम र समय-स्थानवाचक पदको तालिका

| प्रत्यक्ष | अप्रत्यक्ष |
|---|---|
| म / मैले | ऊ / उसले / आफू |
| हामी | उनीहरू |
| तिमी | (श्रोता जो हो त्यही) |
| मेरो | आफ्नो / उसको |
| आज | त्यस दिन |
| भोलि | भोलिपल्ट / अर्को दिन |
| हिजो | अघिल्लो दिन |
| अहिले | त्यति बेला |
| यहाँ | त्यहाँ |
| यो / यी | त्यो / ती |

::: caution *आफू* कहिले प्रयोग गर्ने
अप्रत्यक्ष उक्तिमा कर्ता र उद्धृत कुराको वक्ता **एउटै व्यक्ति** हो भने **आफू/आफ्नो** राख्नुपर्छ। *"रामले भन्यो, «म जान्छु।»"* → **रामले आफू जाने कुरा भन्यो।** यहाँ *"रामले ऊ जाने कुरा भन्यो"* लेख्दा *ऊ* कोही अर्को व्यक्ति देखिन्छ — अर्थ बिग्रन्छ।
:::

::: caution काल सधैँ पछाडि सर्दैन
चरण ४ को अपवाद दुई छन्। **(क)** मुख्य क्रिया **वर्तमान** भए उद्धृत क्रिया सर्दैन — *"ऊ भन्छ, «म जान्छु।»"* → *ऊ आफू जान्छु भन्छ।* **(ख)** उद्धृत कुरा **शाश्वत सत्य** भए सर्दैन — *"शिक्षकले भने, «पृथ्वी गोलो छ।»"* → *शिक्षकले पृथ्वी गोलो **छ** भनी बताए* (*थियो* होइन)।
:::

## 24.3 वाक्यभेदअनुसार उक्ति परिवर्तन

| वाक्यभेद | योजक / क्रिया | प्रत्यक्ष | अप्रत्यक्ष |
|---|---|---|---|
| कथनात्मक | कि / भन्ने कुरा **भन्यो** | उसले भन्यो, "म जान्छु।" | उसले आफू जाने कुरा भन्यो। |
| प्रश्नवाचक | भनेर / कि ... **सोध्यो** | उसले सोध्यो, "तिमी कहाँ जान्छौ?" | उसले म कहाँ जान्छु भनेर सोध्यो। |
| आज्ञार्थ | ...न **भन्यो / लगायो / आदेश दियो** | शिक्षकले भने, "पाठ पढ।" | शिक्षकले पाठ पढ्न भने। |
| इच्छार्थ | **कामना गर्‍यो / आशीर्वाद दियो** | आमाले भनिन्, "सफल होऊ।" | आमाले सफल हुने आशीर्वाद दिइन्। |
| विस्मयादिबोधक | **आश्चर्य / हर्ष व्यक्त गर्‍यो** | उसले भन्यो, "वाह! कति राम्रो!" | उसले त्यो निकै राम्रो भएको भन्दै आश्चर्य व्यक्त गर्‍यो। |

::: tip क्रिया नफेरी उक्ति फेरिँदैन
धेरै विद्यार्थी उद्धरण चिह्न मात्र हटाएर *"उसले भन्यो, तिमी कहाँ जान्छौ"* लेख्छन्। प्रश्नवाचक वाक्यको अप्रत्यक्षमा **भन्यो** होइन **सोध्यो** चाहिन्छ; आज्ञार्थमा **भन्यो/लगायो**; इच्छार्थमा **कामना गर्‍यो**। मुख्य क्रिया नफेरी परिवर्तन अधुरो हुन्छ।
:::

## 24.4 उद्देश्य-विधेय विस्तार

::: definition उद्देश्य र विधेय
वाक्यमा **जसका बारेमा** केही भनिन्छ त्यो **उद्देश्य**, र त्यसका बारेमा **जे भनिन्छ** त्यो **विधेय**। दुवैलाई थप पदले फैलाउन सकिन्छ — त्यही **विस्तार** हो।
:::

| अङ्ग | विस्तारक | नमुना |
|---|---|---|
| **उद्देश्य** | विशेषण | **राम्रो** केटा |
| | निर्देशक/सङ्ख्यावाचक | **त्यो, दुई** केटा |
| | सम्बन्धवाचक पद | **मेरो साथी** राम |
| | समानाधिकरण | राम, **मेरो भाइ**, |
| | विशेषण उपवाक्य | **जो मिहिनेत गर्छ** त्यो केटा |
| **विधेय** | कर्म | **पाठ** पढ्यो |
| | करण / सम्प्रदान | **कलमले**, **रामलाई** |
| | अधिकरण | **विद्यालयमा** |
| | क्रियाविशेषण | **बिहानै, छिटो** |
| | क्रियाविशेषण उपवाक्य | **जब घण्टी बज्यो** |

**क्रमशः विस्तार** —

| चरण | वाक्य |
|---|---|
| मूल | राम गयो। |
| +उद्देश्य विस्तार | **मेरो साथी** राम गयो। |
| +थप | मेरो साथी **राम्रो केटा** राम गयो। |
| +विधेय विस्तार | ... राम **विद्यालय** गयो। |
| +थप | ... राम **बिहानै साथीसँग** विद्यालय गयो। |

पूरा — **मेरो साथी राम्रो केटा राम बिहानै साथीसँग विद्यालय गयो।**
उद्देश्य = *मेरो साथी राम्रो केटा राम*; विधेय = *बिहानै साथीसँग विद्यालय गयो*।

## 24.5 शब्दकोशीय प्रयोग

नेपाली शब्दकोशमा शब्द **नेपाली वर्णक्रम**अनुसार मिलाइएका हुन्छन् —

**स्वर:** अ, आ, इ, ई, उ, ऊ, ऋ, ए, ऐ, ओ, औ, अं, अः
**व्यञ्जन:** क, ख, ग, घ, ङ · च, छ, ज, झ, ञ · ट, ठ, ड, ढ, ण · त, थ, द, ध, न · प, फ, ब, भ, म · य, र, ल, व · श, ष, स, ह

::: definition शब्दकोशीय क्रम
पहिले **पहिलो वर्ण**को क्रम हेरिन्छ; उही भए **दोस्रो वर्ण**, त्यसपछि तेस्रो — यसरी क्रमशः। वर्णमा लागेको **मात्रा**को क्रम पनि माथिकै स्वरक्रमअनुसार हुन्छ (क, का, कि, की, कु, कू, के, कै, को, कौ)।
:::

## 24.6 शुद्ध र अशुद्ध — जोडीमा हेर्नुहोस्

| × अशुद्ध | ✓ शुद्ध | किन |
|---|---|---|
| उसले भन्यो कि "ऊ जान्छ।" | उसले भन्यो कि ऊ जान्छ। | अप्रत्यक्षमा उद्धरण नलाग्ने |
| उसले भन्यो, म जान्छु। | उसले भन्यो, "म जान्छु।" | प्रत्यक्षमा उद्धरण चाहिने |
| रामले ऊ जाने कुरा भन्यो | रामले **आफू** जाने कुरा भन्यो | वक्ता र कर्ता उही |

| कि, का, क, की | **क, का, कि, की** | मात्राक्रम स्वरअनुसार |
| कमल, कपाल, कलम | **कपाल, कमल, कलम** | दोस्रो वर्ण प, म, ल |
| घर, गाउँ, गीत | **गाउँ, गीत, घर** | ग अघि, घ पछि |
| ना. = नाता | ना. = **नाम** | कोशीय संक्षेप |
| सं. = सङ्ख्या | सं. = **संस्कृत** | स्रोत भाषा जनाउने |
| नेपाली बृहत् शब्दकोश — त्रि.वि.को | — **नेपाल प्रज्ञा-प्रतिष्ठान**को | प्रकाशक |
| उद्धरण हटाए मात्र अप्रत्यक्ष हुन्छ | पाँचै चरण चाहिन्छ | अधुरो परिवर्तन |

::: example कथनात्मक उक्ति परिवर्तन
**प्रश्न.** *"रामले भन्यो, «म भोलि काठमाडौँ जान्छु।»"* — अप्रत्यक्ष उक्तिमा लेख्नुहोस्।

**समाधान.**
१. उद्धरण चिह्न हटाउने।
२. *भन्यो* पछि **कि** वा *भन्ने कुरा* जोड्ने।
३. *म* → **आफू** (कर्ता र वक्ता उही राम हुन्)।
४. *जान्छु* → **जाने** (मुख्य क्रिया भूत भएकाले)।
५. *भोलि* → **भोलिपल्ट**।

**उत्तर.** **रामले आफू भोलिपल्ट काठमाडौँ जाने कुरा भन्यो।**
:::

::: example प्रश्नवाचक र आज्ञार्थ
**प्रश्न.** (क) *"उसले सोध्यो, «तिमी कहाँ जान्छौ?»"* (ख) *"शिक्षकले भने, «पाठ पढ।»"* — अप्रत्यक्षमा लेख्नुहोस्।

**समाधान.**
(क) प्रश्नवाचक हो — मुख्य क्रिया **सोध्यो** नै रहन्छ, *भनेर* जोडिन्छ, *तिमी* श्रोता (म) भएकाले **म** हुन्छ, *?* हटेर *।* आउँछ।
**उत्तर.** **उसले म कहाँ जान्छु भनेर सोध्यो।**

(ख) आज्ञार्थ हो — क्रिया *पढ* लाई **-न** लगाएर *पढ्न* बनाइन्छ र मुख्य क्रिया **भने/लगाए** राखिन्छ।
**उत्तर.** **शिक्षकले पाठ पढ्न भने।** (वा *शिक्षकले पाठ पढ्न लगाए।*)
:::

::: example शब्दकोशीय क्रम
**प्रश्न.** यी शब्दलाई शब्दकोशीय क्रममा मिलाउनुहोस् — *कलम, कमल, कपाल, गाउँ, घर, गीत।*

**समाधान.** पहिले पहिलो वर्ण — **क** (३ वटा), **ग** (२ वटा), **घ** (१ वटा)।
*क*-वालामा दोस्रो वर्ण हेर्ने — **प** (कपाल), **म** (कमल), **ल** (कलम); वर्णक्रममा प < म < ल।
*ग*-वालामा — *गाउँ* मा *गा* (आ-मात्रा), *गीत* मा *गी* (ई-मात्रा); स्वरक्रममा आ < ई।

**उत्तर.** **कपाल, कमल, कलम, गाउँ, गीत, घर।**
:::

## पाठको सार

- **प्रत्यक्ष उक्ति** = वक्ताको कुरा उद्धरण चिह्नभित्र जस्ताको तस्तै; **अप्रत्यक्ष उक्ति** = आफ्नै शब्दमा, उद्धरण चिह्नबिना।
- परिवर्तनका **पाँच चरण** — उद्धरण चिह्न हटाउने, *कि/भनेर* जोड्ने, सर्वनाम फेर्ने, काल पछाडि सार्ने, समय-स्थानवाचक पद फेर्ने।
- कर्ता र वक्ता एउटै भए **आफू/आफ्नो** प्रयोग गर्ने।
- वाक्यभेदअनुसार मुख्य क्रिया फेरिन्छ — कथनमा **भन्यो**, प्रश्नमा **सोध्यो**, आज्ञामा **भन्यो/लगायो**, इच्छामा **कामना गर्‍यो**, विस्मयमा **आश्चर्य व्यक्त गर्‍यो**।
- **उद्देश्य** = कर्ता पक्ष (विशेषण, सम्बन्धवाचक पद, विशेषण उपवाक्यले फैलिने); **विधेय** = क्रिया पक्ष (कर्म, कारक, क्रियाविशेषण, उपवाक्यले फैलिने)।
- शब्दकोशमा **नेपाली वर्णक्रम** — स्वरपछि व्यञ्जन; मात्राक्रम पनि स्वरक्रमअनुसार। प्रविष्टिमा शीर्ष शब्द, कोटि (**ना., वि., क्रि.**), स्रोत (**सं., फा., अ.**), अर्थ र पर्याय हुन्छन्।

## अभ्यास

**अप्रत्यक्ष उक्तिमा लेख्नुहोस् (१ अङ्क)**

1. रामले भन्यो, "म भोलि जान्छु।" <span class="marks">[1]</span>
2. उसले सोध्यो, "तिमी कहाँ बस्छौ?" <span class="marks">[1]</span>
3. शिक्षकले भने, "पाठ पढ।" <span class="marks">[1]</span>
4. आमाले भनिन्, "सफल होऊ।" <span class="marks">[1]</span>
5. सीताले भनी, "मैले आज पुस्तक किनेँ।" <span class="marks">[1]</span>

::: note उत्तर
**१.** **रामले आफू भोलिपल्ट जाने कुरा भन्यो।**
**२.** **उसले म कहाँ बस्छु भनेर सोध्यो।** — प्रश्न भएकाले *सोध्यो*, *?* हट्यो।
**३.** **शिक्षकले पाठ पढ्न भने।** — आज्ञार्थमा क्रियामा *-न*।
**४.** **आमाले सफल हुने आशीर्वाद दिइन्।** — इच्छार्थ।
**५.** **सीताले आफूले त्यस दिन पुस्तक किनेको कुरा भनी।** — *मैले* → *आफूले*, *आज* → *त्यस दिन*।
:::

**प्रत्यक्ष उक्तिमा लेख्नुहोस् (१ अङ्क)**

6. उसले आफू घर जाने कुरा भन्यो। <span class="marks">[1]</span>
7. शिक्षकले विद्यार्थीलाई चुप लाग्न भने। <span class="marks">[1]</span>
8. उसले म कति बेला आउँछु भनेर सोध्यो। <span class="marks">[1]</span>

::: note उत्तर
**६.** **उसले भन्यो, "म घर जान्छु।"**
**७.** **शिक्षकले विद्यार्थीलाई भने, "चुप लाग।"**
**८.** **उसले सोध्यो, "तिमी कति बेला आउँछौ?"**
:::

**उद्देश्य र विधेय छुट्याउनुहोस् (१ अङ्क)**

9. मेरो साथी राम विद्यालय गयो। <span class="marks">[1]</span>
10. त्यो राम्रो केटा बिहानै हिँड्यो। <span class="marks">[1]</span>
11. जो मिहिनेत गर्छ, त्यो विद्यार्थी सफल हुन्छ। <span class="marks">[1]</span>

::: note उत्तर
**९.** उद्देश्य — **मेरो साथी राम**; विधेय — **विद्यालय गयो**।
**१०.** उद्देश्य — **त्यो राम्रो केटा**; विधेय — **बिहानै हिँड्यो**।
**११.** उद्देश्य — **जो मिहिनेत गर्छ, त्यो विद्यार्थी**; विधेय — **सफल हुन्छ**।
:::

**शब्दकोशीय क्रममा मिलाउनुहोस् (१ अङ्क)**

12. कलम, कमल, कपाल <span class="marks">[1]</span>
13. घर, गाउँ, गीत <span class="marks">[1]</span>
14. की, क, कि, का <span class="marks">[1]</span>
15. सहर, शहीद, षड्यन्त्र <span class="marks">[1]</span>

::: note उत्तर
**१२.** **कपाल, कमल, कलम** — दोस्रो वर्ण प < म < ल।
**१३.** **गाउँ, गीत, घर** — ग अघि घ पछि; *गा* (आ) अघि *गी* (ई)।
**१४.** **क, का, कि, की** — मात्राक्रम अ, आ, इ, ई।
**१५.** **शहीद, षड्यन्त्र, सहर** — वर्णक्रममा श, ष, स।
:::

**छोटो उत्तर दिनुहोस् (३ अङ्क)**

16. प्रत्यक्ष र अप्रत्यक्ष उक्तिबिचको भिन्नता उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
17. उक्ति परिवर्तनका पाँच चरण उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
18. वाक्यभेदअनुसार अप्रत्यक्ष उक्तिको मुख्य क्रिया कसरी फेरिन्छ? पाँच नमुना दिनुहोस्। <span class="marks">[3]</span>
19. उद्देश्य र विधेय के हुन्? *"राम गयो।"* लाई दुवैतिरबाट विस्तार गरी देखाउनुहोस्। <span class="marks">[3]</span>
20. शब्दकोशीय प्रविष्टिमा कस्ता सूचना हुन्छन्? एउटा नमुनासहित लेख्नुहोस्। <span class="marks">[3]</span>

::: note उत्तर
**१६.** वक्ताले भनेको कुरा **जस्ताको तस्तै** उद्धरण चिह्नभित्र राखिएमा **प्रत्यक्ष उक्ति** — *रामले भन्यो, "म भोलि जान्छु।"* त्यही कुरा लेखकले **आफ्नै शब्दमा**, उद्धरण चिह्नबिना, *कि/भनेर* जोडेर लेखेमा **अप्रत्यक्ष उक्ति** — *रामले आफू भोलिपल्ट जाने कुरा भन्यो।* प्रत्यक्षमा सर्वनाम र काल वक्ताको दृष्टिले रहन्छ, अप्रत्यक्षमा लेखकको दृष्टिले फेरिन्छ।
**१७.** **(१)** उद्धरण चिह्न हटाउने। **(२)** *कि / भनेर / भन्ने कुरा* जोड्ने। **(३)** सर्वनाम फेर्ने — *म* → *आफू/ऊ*। **(४)** काल एक तह पछाडि सार्ने — *जान्छु* → *जाने*। **(५)** समय-स्थानवाचक पद फेर्ने — *भोलि* → *भोलिपल्ट*, *यहाँ* → *त्यहाँ*। नमुना — *रामले भन्यो, "म भोलि यहाँ आउँछु।"* → **रामले आफू भोलिपल्ट त्यहाँ आउने कुरा भन्यो।**
**१८.** **कथनात्मक** — *भन्यो / भन्ने कुरा भन्यो*: *उसले आफू जाने कुरा भन्यो।* **प्रश्नवाचक** — *सोध्यो*: *उसले म कहाँ जान्छु भनेर सोध्यो।* **आज्ञार्थ** — *भन्यो / लगायो / आदेश दियो*: *शिक्षकले पाठ पढ्न भने।* **इच्छार्थ** — *कामना गर्‍यो / आशीर्वाद दियो*: *आमाले सफल हुने आशीर्वाद दिइन्।* **विस्मयादिबोधक** — *आश्चर्य / हर्ष व्यक्त गर्‍यो*: *उसले त्यो दृश्य निकै राम्रो भएको भन्दै आश्चर्य व्यक्त गर्‍यो।*
**१९.** वाक्यमा **जसका बारेमा** केही भनिन्छ त्यो **उद्देश्य**, **जे भनिन्छ** त्यो **विधेय**। *"राम गयो।"* मा उद्देश्य *राम*, विधेय *गयो*। उद्देश्यलाई सम्बन्धवाचक पद र विशेषणले — *मेरो साथी राम्रो केटा राम*; विधेयलाई क्रियाविशेषण, करण र अधिकरणले — *बिहानै साथीसँग विद्यालय गयो*। पूरा वाक्य — **मेरो साथी राम्रो केटा राम बिहानै साथीसँग विद्यालय गयो।**
**२०.** शब्दकोशीय प्रविष्टिमा **शीर्ष शब्द**, **व्याकरणिक कोटि** (*ना., सर्व., वि., क्रि., क्रि.वि., अव्य.*), **स्रोत भाषा** (*सं., फा., अ., अङ्.*), **अर्थ** र प्रायः **पर्याय** तथा **प्रयोग वाक्य** हुन्छन्। नमुना — **कमल  ना. [सं.]  पानीमा फुल्ने एक सुन्दर फूल; पद्म।** यहाँ *कमल* शीर्ष शब्द, *ना.* नाम कोटि, *[सं.]* संस्कृत स्रोत, बाँकी अर्थ र पर्याय हुन्। नेपालीको आधिकारिक कोश **नेपाली बृहत् शब्दकोश** (नेपाल प्रज्ञा-प्रतिष्ठान) हो।
:::
