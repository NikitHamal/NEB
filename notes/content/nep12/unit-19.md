*हार* एउटा शब्द हो। अगाडि *प्र-* जोड्नुहोस् — *प्रहार*। *आ-* जोड्नुहोस् — *आहार*। *सम्-* जोड्नुहोस् — *संहार*। मूल उही, अर्थ पूरै फरक। अनि *लेख्-* धातुमा *-आइ* जोड्दा *लेखाइ*, *-अक* जोड्दा *लेखक* बन्छ। यसरी थोरै जगबाट धेरै शब्द बनाउने प्रक्रियालाई **शब्दनिर्माण** भनिन्छ र परीक्षामा यसबाट **३ अङ्क** आउँछ। यसै अध्यायमा **गजलको संरचना** पनि छ — छन्दजस्तै कडा नियम भएको काव्यविधा, जसमा हरेक पारिभाषिक शब्दको आफ्नै ठाउँ हुन्छ।

::: key परीक्षाले खोज्ने चार कुरा
**(१)** दिइएको शब्दलाई **उपसर्ग + मूल + प्रत्यय** मा टुक्र्याउन सक्नु। **(२)** प्रत्यय **कृत्** हो कि **तद्धित** छुट्याउन सक्नु — धातुमा लागे कृत्, नाम/विशेषणमा लागे तद्धित। **(३)** एउटै उपसर्ग वा प्रत्ययबाट **तीन-चार नयाँ शब्द** बनाउन सक्नु। **(४)** गजलको **मत्ला, मक्ता, काफिया, रदीफ, बहर, तखल्लुस** नमुनामा देखाएर चिनाउन सक्नु।
:::

## 19.3 प्रत्यय

::: definition प्रत्यय
शब्द वा धातुको **पछाडि** जोडिएर नयाँ शब्द बनाउने शब्दांशलाई **प्रत्यय** भनिन्छ। **धातु**मा लाग्नेलाई **कृत् प्रत्यय**, **नाम/विशेषण**मा लाग्नेलाई **तद्धित प्रत्यय** भनिन्छ।
:::

### कृत् प्रत्यय — धातुमा लाग्ने

| प्रत्यय | बन्ने वर्ग | उदाहरण |
|---|---|---|
| -आइ | भाववाचक नाम | लेख् + आइ = लेखाइ; पढ् + आइ = पढाइ |
| -अक/-क | कर्तृवाचक नाम | लेख् + अक = लेखक; गा + क = गायक |
| -ने | विशेषण/कर्तृवाचक | गर्ने, पढ्ने, हिँड्ने |
| -एको | विशेषण | गरेको, पढेको, भनेको |
| -नु | क्रियार्थक नाम | गर्नु, पढ्नु, खानु |
| -न | भाववाचक नाम | दर्शन, गमन, लेखन |
| -आहा | स्वभाववाचक | लुटाहा, झगडाहा, रिसाहा |
| -दो/-तो | विशेषण | बग्दो, चल्दो, डर लाग्दो |
| -आउ | नाम | बिगार + आउ → बिगारउ; चढाउ, बनाउ |
| -आवट | भाववाचक नाम | बनावट, सजावट, मिलावट |

### तद्धित प्रत्यय — नाम/विशेषणमा लाग्ने

| प्रत्यय | बन्ने वर्ग | उदाहरण |
|---|---|---|
| -ता | भाववाचक नाम | मानव + ता = मानवता; सुशीलता, मित्रता |
| -त्व | भाववाचक नाम | मातृ + त्व = मातृत्व; गुरुत्व, महत्त्व |
| -पन/-पना | भाववाचक नाम | बालकपन, ठुलोपना, मिठोपन |
| -इलो | विशेषण | रस + इलो = रसिलो; माटिलो, बलियो |
| -आलु | स्वभाववाचक विशेषण | दया + आलु = दयालु; कृपालु, श्रद्धालु |
| -वान्/-मान् | विशेषण | धनवान्, बुद्धिमान्, शक्तिमान् |
| -इक | सम्बन्धवाचक विशेषण | समाज + इक = सामाजिक; धार्मिक, शारीरिक |
| -ई | सम्बन्धवाचक | नेपाल + ई = नेपाली; विद्यार्थी, अङ्ग्रेजी |
| -दार (फारसी) | स्वामित्व | जग्गादार, दुकानदार, इज्जतदार |
| -वाला | स्वामित्व | गाउँवाला, दूधवाला, घरवाला |
| -खोर (फारसी) | खाने, लिने | घुसखोर, हरामखोर |
| -ची (तुर्की) | गर्ने व्यक्ति | तोपची, मस्किची, खजानची |

::: caution कृत् र तद्धित छुट्याउने एउटै कसोटी
**जग धातु हो कि शब्द ?** *लेखाइ* को जग *लेख्-* **धातु** हो → **कृत् प्रत्यय**। *नेपाली* को जग *नेपाल* **नाम** हो → **तद्धित प्रत्यय**। *-आइ* र *-ई* सुन्दा उस्तै लागे पनि जग फरक भएकाले वर्ग फरक हुन्छ। जगमा *-नु* लगाउँदा क्रिया बन्छ भने त्यो धातु हो।
:::

## 19.4 गजलको संरचना

::: definition गजल
प्रत्येक दुई-दुई हरफ मिलेर स्वतन्त्र अर्थ दिने, समान लय, तुक र दोहोरिने शब्दमा बाँधिएका शेरहरूको समूहलाई **गजल** भनिन्छ। यो मूलतः अरबी-फारसी काव्यपरम्पराबाट उर्दूहुँदै नेपालीमा भित्रिएको विधा हो।
:::

**मोतीराम भट्ट** (सन् १८६६–१८९६) लाई नेपाली गजलका **प्रवर्तक** मानिन्छ। बनारस बसाइका क्रममा उनले गजल गायन र सितारवादन सिके र नेपालीमा लेख्नुअघि नै करिब चार सय सायरी रचिसकेका थिए। राणा दरबारमा उर्दू गजल सुनेपछि उनले नेपालीमा गजल लेख्न र गाउन थाले। उनको प्रभावमा **लक्ष्मीदत्त पन्त, गोपीनाथ लोहनी र नरदेव पाण्डे** ले यो विधा अँगाले; पछि **शम्भुप्रसाद ढुङ्गेल, भीमनिधि तिवारी** र **माबिबि शाह (महेन्द्र)** ले गजललाई नेपाली कवितामा प्रमुख स्थान दिलाए। आधुनिक कालमा वि.सं. २०३६ मा **मधुपर्क** पत्रिकामा प्रकाशित **ज्ञानुवाकर पौडेल**को "मुक्तक" शीर्षकको रचनालाई गजल संरचनाभित्र प्रवेश गरेको बिन्दु मानिन्छ।

### गजलका पारिभाषिक शब्द

| शब्द | अर्थ |
|---|---|
| **मिसरा** | गजलको एउटा हरफ। माथिल्लोलाई *मिसरा-ए-उला*, तल्लोलाई *मिसरा-ए-सानी* भनिन्छ। |
| **शेर** | दुई मिसरा मिलेर बनेको एकाइ; हरेक शेर आफैँमा स्वतन्त्र कविता हुन्छ। |
| **मत्ला** | गजलको **पहिलो शेर**, जसका दुवै मिसरामा काफिया र रदीफ आउँछन्। यसैका आधारमा पूरा गजलको रदीफ, काफिया र बहर तय हुन्छ। |
| **मक्ता** | गजलको **अन्तिम शेर**। |
| **काफिया** | मत्लापछिका हरेक शेरको दोस्रो मिसरामा दोहोरिने **तुक** (अनुप्रासयुक्त शब्द)। यो **अनिवार्य** हुन्छ। |
| **रदीफ** | काफियापछि जस्ताको तस्तै **दोहोरिने शब्द वा शब्दसमूह**। यो **अनिवार्य होइन**। |
| **बहर** | शेरको **वजन** अर्थात् लय वा छन्द। नेपाली गजलमा प्रयुक्त शास्त्रीय लयलाई नै बहर भनिन्छ। |
| **तखल्लुस** | मक्तामा प्रयोग हुने कविको **उपनाम**। यो पनि **अनिवार्य होइन**। |

::: caution तीन कुरा अनिवार्य छैनन्
परीक्षामा "गजलका अनिवार्य तत्त्व" सोधिएमा **काफिया** र **बहर** (लय) लेख्नुहोस्; **रदीफ** र **तखल्लुस** दुवै **ऐच्छिक** हुन्। रदीफ नभएको गजललाई *गैरमुरद्दफ* र रदीफ भएकोलाई *मुरद्दफ* गजल भनिन्छ। यो भेद नजानेर "रदीफ अनिवार्य हो" लेख्नु सामान्य गल्ती हो।
:::

## 19.5 शुद्ध र अशुद्ध — जोडीमा हेर्नुहोस्

| × अशुद्ध | ✓ शुद्ध | किन |
|---|---|---|
| *लेखाइ* — तद्धित प्रत्यय | *लेखाइ* — कृत् प्रत्यय | जग *लेख्-* धातु हो |
| *नेपाली* — कृत् प्रत्यय | *नेपाली* — तद्धित प्रत्यय | जग *नेपाल* नाम हो |
| *मानवता* — कृत् | *मानवता* — तद्धित | जग *मानव* नाम हो |
| *गायक* — तद्धित | *गायक* — कृत् | जग *गा-* धातु हो |
| *प्रहार* मा *प्रह-* उपसर्ग | *प्रहार* मा *प्र-* उपसर्ग | मूल *हार* |
| *संहार* मा *स-* उपसर्ग | *संहार* मा *सम्-* उपसर्ग | *सम् + हार* |
| *अनुवाद* मा *अ-* उपसर्ग | *अनुवाद* मा *अनु-* उपसर्ग | *अनु + वाद* |
| *दयालु* मा *-लु* प्रत्यय | *दयालु* मा *-आलु* प्रत्यय | *दया + आलु* |
| *सामाजिक* मा *-क* | *सामाजिक* मा *-इक* | *समाज + इक* |
| *बुद्धिमान* | *बुद्धिमान्* | *-मान्* हलन्तसहित |
| *उपसर्ग एक्लै प्रयोग हुन्छ* | *उपसर्ग एक्लै प्रयोग हुँदैन* | परिभाषा |
| *रदीफ अनिवार्य हो* | *रदीफ ऐच्छिक हो* | गैरमुरद्दफ गजल हुन्छ |
| *तखल्लुस अनिवार्य हो* | *तखल्लुस ऐच्छिक हो* | नभए पनि गजल बन्छ |
| *मत्ला अन्तिम शेर हो* | *मत्ला पहिलो शेर हो* | परिभाषा |
| *मक्ता पहिलो शेर हो* | *मक्ता अन्तिम शेर हो* | परिभाषा |
| *शेर भनेको एक हरफ* | *शेर भनेको दुई मिसरा* | परिभाषा |
| *बहर भनेको तुक* | *बहर भनेको लय/वजन* | तुक त काफिया हो |
| *काफिया भनेको दोहोरिने शब्द* | *काफिया भनेको तुक मिल्ने शब्द* | दोहोरिने त रदीफ हो |
| *गजल छन्दरहित हुन्छ* | *गजल बहर (लय) मा बाँधिन्छ* | नियमबद्ध विधा |
| *मोतीराम भट्ट आधुनिक गजलकार* | *मोतीराम भट्ट गजलका प्रवर्तक* | उन्नाइसौँ शताब्दी |
| *अछुत* मा *अछ-* उपसर्ग | *अछुत* मा *अ-* उपसर्ग | *अ + छुत* |
| *गैरकानुनी* मा उपसर्ग मात्र | *गैर-* उपसर्ग र *-ई* प्रत्यय दुवै | दुवै लागेको |
| *बनावट* मा तद्धित | *बनावट* मा कृत् (*-आवट*) | जग *बन्-* धातु |
| *ठुलोपना* मा कृत् | *ठुलोपना* मा तद्धित (*-पना*) | जग *ठुलो* विशेषण |
| *मिसरा-ए-सानी माथिल्लो हरफ* | *मिसरा-ए-सानी तल्लो हरफ* | माथिल्लो *उला* हो |

::: example शब्द टुक्र्याउने
**प्रश्न.** *"अपमानित"*, *"निर्दोषी"*, *"सुशीलता"* — यी शब्दलाई उपसर्ग, मूल र प्रत्ययमा छुट्याई प्रत्ययको किसिम लेख्नुहोस्।

**समाधान.**
१. **अपमानित** = *अप* (उपसर्ग) + *मान* (मूल) + *इत* (प्रत्यय)। जग *मान* नाम हो → **तद्धित**।
२. **निर्दोषी** = *निर्* (उपसर्ग) + *दोष* (मूल) + *ई* (प्रत्यय)। जग *दोष* नाम हो → **तद्धित**।
३. **सुशीलता** = *सु* (उपसर्ग) + *शील* (मूल) + *ता* (प्रत्यय)। जग *शील* नाम हो → **तद्धित**।
:::

::: example एउटै जगबाट धेरै शब्द
**प्रश्न.** धातु *लेख्-* बाट पाँच शब्द बनाई प्रत्यय देखाउनुहोस्।

**समाधान.**
*लेख् + अक* = **लेखक** (कर्तृवाचक नाम) · *लेख् + आइ* = **लेखाइ** (भाववाचक नाम) · *लेख् + न* = **लेखन** (भाववाचक नाम) · *लेख् + ने* = **लेख्ने** (विशेषण) · *लेख् + एको* = **लेखेको** (विशेषण)। पाँचै **कृत् प्रत्यय** हुन्, किनभने जग धातु हो।
:::

::: example गजलको संरचना देखाउने
**प्रश्न.** *"इ सानै उमेर्देखि मन हर्न लागे / यिनै सुन्दरीले जुलुम् गर्न लागे।"* — यसमा शेर, मत्ला, काफिया र रदीफ देखाउनुहोस्।

**समाधान.**
१. दुई मिसरा मिलेर एउटा **शेर** बनेको छ।
२. यो गजलको **पहिलो शेर** भएकाले **मत्ला** हो; त्यसैले दुवै मिसरामा काफिया र रदीफ छन्।
३. **काफिया** = *हर्न* र *गर्न* — तुक मिल्ने शब्द।
४. **रदीफ** = *लागे* — काफियापछि जस्ताको तस्तै दोहोरिएको शब्द।
५. रदीफ भएकाले यो **मुरद्दफ** गजल हो।
:::

## पाठको सार

- **उपसर्ग** शब्दको अगाडि, **प्रत्यय** पछाडि जोडिन्छ; दुवै एक्लै प्रयोग हुँदैनन्।
- तत्सम उपसर्ग — *प्र, परा, अप, सम्, अनु, अव, निस्/निर्, दुस्/दुर्, वि, आ, नि, अधि, अति, सु, उत्, अभि, प्रति, परि, उप*।
- नेपाली/आगन्तुक उपसर्ग — *अ-, अन-, ना-, कु-, अध-, भर-, बे-, गैर-, हर-, बद-, सर-*।
- **कृत् प्रत्यय** धातुमा लाग्छ (*लेखाइ, लेखक, लेखन, बनावट*); **तद्धित प्रत्यय** नाम/विशेषणमा लाग्छ (*मानवता, नेपाली, दयालु, सामाजिक*)। कसोटी — **जग धातु हो कि शब्द ?**
- **गजल**: दुई मिसरा = **शेर**; पहिलो शेर = **मत्ला**; अन्तिम शेर = **मक्ता**; तुक = **काफिया** (अनिवार्य); दोहोरिने शब्द = **रदीफ** (ऐच्छिक); लय/वजन = **बहर**; कविको उपनाम = **तखल्लुस** (ऐच्छिक)।
- **मोतीराम भट्ट** नेपाली गजलका प्रवर्तक; वि.सं. २०३६ मा *मधुपर्क* मा छापिएको **ज्ञानुवाकर पौडेल**को रचनालाई आधुनिक गजल संरचनाको प्रवेशबिन्दु मानिन्छ।

**छोटो उत्तर दिनुहोस् (३ अङ्क)**

21. उपसर्ग र प्रत्ययबिचको भिन्नता तीन-तीन उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>

23. गजलका छ पारिभाषिक शब्द परिभाषासहित लेख्नुहोस्। <span class="marks">[3]</span>
24. *"इ सानै उमेर्देखि मन हर्न लागे / यिनै सुन्दरीले जुलुम् गर्न लागे।"* — यसमा मत्ला, काफिया र रदीफ देखाउनुहोस्। <span class="marks">[3]</span>
25. उपसर्ग र प्रत्यय दुवै लागेका पाँच शब्द लेखी टुक्र्याउनुहोस्। <span class="marks">[3]</span>

::: note उत्तर
**२१.** **उपसर्ग** शब्दको **अगाडि** जोडिन्छ — *प्र + हार = प्रहार*, *सु + गन्ध = सुगन्ध*, *कु + कर्म = कुकर्म*। **प्रत्यय** शब्दको **पछाडि** जोडिन्छ — *मानव + ता = मानवता*, *लेख् + अक = लेखक*, *दया + आलु = दयालु*। दुवै एक्लै प्रयोग हुँदैनन्; उपसर्गले प्रायः अर्थ फेर्छ भने प्रत्ययले पदवर्गसमेत फेर्न सक्छ।
**२२.** कसोटी — **जग धातु हो कि शब्द ?** जग **धातु** भए **कृत्**: *लेख् + आइ = लेखाइ*, *गा + अक = गायक*, *बन् + आवट = बनावट*। जग **नाम वा विशेषण** भए **तद्धित**: *मानव + ता = मानवता*, *नेपाल + ई = नेपाली*, *ठुलो + पना = ठुलोपना*। जगमा *-नु* लगाउँदा क्रिया बन्छ भने त्यो धातु हो।
**२३.** **मिसरा** — गजलको एउटा हरफ। **शेर** — दुई मिसरा मिलेको स्वतन्त्र एकाइ। **मत्ला** — गजलको पहिलो शेर, जसले रदीफ, काफिया र बहर तय गर्छ। **मक्ता** — अन्तिम शेर। **काफिया** — तुक मिल्ने अनुप्रासिक शब्द, अनिवार्य। **रदीफ** — काफियापछि जस्ताको तस्तै दोहोरिने शब्द, ऐच्छिक। (थप — **बहर**: शेरको लय/वजन; **तखल्लुस**: मक्तामा आउने कविको उपनाम।)
**२४.** यी दुई मिसरा मिलेर एउटा **शेर** बनेको छ र यो गजलको पहिलो शेर भएकाले **मत्ला** हो। **काफिया** = *हर्न* र *गर्न* — तुक मिल्ने शब्द। **रदीफ** = *लागे* — काफियापछि जस्ताको तस्तै दोहोरिएको शब्द। रदीफ भएकाले यो **मुरद्दफ** गजल हो।
**२५.** **अपमानित** = अप + मान + इत। **निर्दोषी** = निर् + दोष + ई। **सुशीलता** = सु + शील + ता। **गैरकानुनी** = गैर + कानुन + ई। **प्रगतिशील** = प्र + गति + शील।
:::
