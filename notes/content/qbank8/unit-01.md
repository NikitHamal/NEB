This question bank is a practice tool, not an unofficial exam leak and not a list of questions guaranteed to appear. Every item is original and follows the Grade 8 learning scope. Use it to retrieve ideas from memory, identify a precise gap and improve the next answer.

::: key The three-pass routine
**Pass 1 — attempt:** answer without notes.  
**Pass 2 — check:** compare with the marking points, not only the final word.  
**Pass 3 — repair:** write one corrected answer and schedule a short retry after one or two days.
:::

## 1.1 What a high-quality answer shows

| Question command | What the answer needs | Common weak response |
|---|---|---|
| Define | exact meaning, not only an example | giving an unrelated sentence |
| State/List | requested number of correct points | writing one point for a two-point question |
| Explain | a reason and a clear link | repeating the question |
| Compare | both sides and one stated difference | describing only one side |
| Calculate | method, working, answer and unit | writing only a number |
| Write/Create | audience, purpose, structure and accurate language | ideas with no clear order |

## 1.2 A self-marking method

After answering, underline each marking point you have genuinely included. If the question is worth three marks, look for three separately creditable ideas. Do not award yourself a mark for a point that is only implied. For writing tasks, check purpose, organisation and correctness separately.

::: example Turn a vague answer into a creditable one
**Question.** Why is a fair test important? <span class="marks">[2]</span>

**Weak answer.** “It is important for science.”

**Stronger answer.** “A fair test changes one factor while keeping other important conditions the same. This makes the result more reliable because the changed factor is the best explanation for a difference.”
:::

## 1.3 Weekly revision loop

```figure caption="A short weekly loop builds memory more effectively than reading the same page repeatedly."
import matplotlib.pyplot as plt
from matplotlib.patches import FancyBboxPatch
fig, ax = plt.subplots(figsize=(5.2, 2.35))
steps = ['Learn', 'Close notes', 'Answer', 'Check', 'Repair', 'Retry later']
for index, step in enumerate(steps):
    x = index * 0.94
    ax.add_patch(FancyBboxPatch((x, 0.78), 0.76, 0.43, boxstyle='round,pad=0.03', fc='#f9edf1', ec=ACCENT, lw=1.0))
    ax.text(x + 0.38, 0.995, step, ha='center', va='center', fontsize=7.6, weight='bold')
    if index < len(steps)-1:
        ax.annotate('', xy=(x + 0.9, 0.995), xytext=(x + 0.78, 0.995), arrowprops=dict(arrowstyle='->', color=MUTED, lw=1.0))
ax.text(2.45, 0.32, 'Keep an error list: concept, mistake, corrected rule, retry date.', ha='center', fontsize=8.7, color=INK)
ax.set_xlim(-0.1, 5.55); ax.set_ylim(0, 1.55); ax.axis('off')
```

## Practice questions

1. A 3-mark question asks for three effects of poor sanitation. How many separately clear effects should your answer contain? <span class="marks">[1]</span>
2. Which answer command requires you to show similarities or differences between two ideas? <span class="marks">[1]</span>
3. Rewrite this answer so it gives a reason: “We should protect biodiversity because it is good.” <span class="marks">[2]</span>
4. Make a five-day revision plan that includes one attempt, one repair and one retry for Mathematics and Nepali. <span class="marks">[4]</span>

::: note Answers
**1.** Three separately clear effects.  
**2.** Compare.  
**3.** A strong answer links biodiversity to balanced ecosystems, useful resources or the survival of living things; any accurate reasoned version earns credit.  
**4.** A valid plan gives specific days and includes all three actions for both subjects.
:::
