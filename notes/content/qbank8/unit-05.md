Use precise science language. A conclusion must state what the collected evidence supports, not what you hoped would happen.

1. Put these in order: conclusion, question, data record, fair method. <span class="marks">[2]</span>
2. State the independent variable in an investigation of water amount on bean-plant height. <span class="marks">[1]</span>
3. State the dependent variable in the same investigation. <span class="marks">[1]</span>
4. Give two conditions that should be controlled in that investigation. <span class="marks">[2]</span>
5. Why should two groups use the same type and number of seeds? <span class="marks">[2]</span>
6. Write one neutral survey question about the time learners spend reading each week. <span class="marks">[2]</span>
7. A survey finds that learners who carry water bottles also report more exercise. Explain why this does not prove that carrying a bottle causes exercise. <span class="marks">[3]</span>

::: note Answer key
**1.** Question, fair method, data record, conclusion.  
**2.** Amount of water.  
**3.** Plant height.  
**4.** Same seed type and soil, for example.  
**5.** It prevents seed differences from confusing the result.  
**6.** It should be clear, measurable and not push respondents toward an answer.  
**7.** Other factors may explain both patterns; a correlation alone does not establish cause.
:::
