नेपालीमा नयाँ शब्द चार प्रक्रियाबाट बन्छन् — उपसर्ग, प्रत्यय, समास र द्वित्व। यी चारैलाई मिलाएर **शब्दनिर्माण**बाट ४ अङ्क आउँछ। यो एकाइ पहिलो प्रक्रिया **उपसर्ग**को हो। उपसर्ग सानो शब्दांश हो जो शब्दको अगाडि बसेर त्यसको अर्थ बदल्छ — *मान* बाट *सम्मान* र *अपमान* दुवै बन्छन्, अर्थ भने ठिक उल्टो।

::: definition उपसर्ग
शब्दको **अगाडि** जोडिएर त्यसको अर्थमा परिवर्तन ल्याउने तर आफैँ स्वतन्त्र प्रयोग नहुने शब्दांशलाई उपसर्ग भनिन्छ।
:::

## 19.1 उपसर्गको पहिचान

**तीन कुरा जाँच्नुहोस्:**

1. **स्थान** — उपसर्ग सधैँ शब्दको अगाडि आउँछ। पछाडि आउने प्रत्यय हो।
2. **स्वतन्त्रता** — उपसर्ग एक्लै बोल्दा अर्थ दिँदैन। *अप*, *प्रति*, *सम्* एक्लै केही होइनन्।
3. **अर्थ परिवर्तन** — उपसर्ग जोडिएपछि मूल शब्दको अर्थ बदलिन्छ वा तीव्र हुन्छ।

| मूल शब्द | उपसर्ग | नयाँ शब्द | अर्थमा के भयो |
|---|---|---|---|
| मान | अप | अपमान | उल्टो अर्थ (इज्जत → बेइज्जत) |
| मान | सम् | सम्मान | तीव्र अर्थ (इज्जत → ठुलो इज्जत) |
| हार | प्र | प्रहार | नयाँ अर्थ (हार → आक्रमण) |
| डर | नि | निडर | अभाव (डर → डर नभएको) |
| कानुनी | गैर | गैरकानुनी | निषेध |

## 19.5 उपसर्ग जोड्दा हुने रूप परिवर्तन

उपसर्ग जोडिँदा प्रायः सन्धि लाग्छ, र उपसर्गको रूप देखिनेगरी फेरिन्छ। रूप फेरिए पनि उपसर्ग त्यही हो — विग्रह गर्दा मूल रूप नै लेख्नुपर्छ।

| उपसर्ग | मूल शब्द | जोडिएपछि | के भयो |
|---|---|---|---|
| सम् | मान | सम्मान | *म्* अघि *म्* यथावत् रह्यो |
| सम् | योग | संयोग | *म्* शिरबिन्दु भयो |
| सम् | कल्प | सङ्कल्प | *म्* को *ङ्* भयो |
| उत् | नति | उन्नति | *त्* को *न्* भयो |
| उत् | लेख | उल्लेख | *त्* को *ल्* भयो |
| निस् | फल | निष्फल | *स्* को *ष्* भयो |
| निर् | आश | निराश | *र्* लोप भई स्वर दीर्घ भयो |
| दुस् | कर | दुष्कर | *स्* को *ष्* भयो |
| अति | अन्त | अत्यन्त | *इ* को *य्* भयो |
| प्रति | एक | प्रत्येक | *इ* को *य्* भयो |
| अधि | अध्ययन | अध्ययन | *इ* को *य्* भयो |

::: caution रूप फेरिएको उपसर्ग चिन्नुहोस्
*संयोग* मा उपसर्ग *सं* होइन, **सम्** हो। *उन्नति* मा *उन्* होइन, **उत्** हो। *निराश* मा *नि* होइन, **निर्** हो। विग्रहमा फेरिएको रूप लेखे अङ्क काटिन्छ।
:::

## 19.6 एउटै मूल शब्दबाट धेरै शब्द

उपसर्गको सबैभन्दा ठुलो उपयोग यही हो — एउटै मूल शब्दबाट दर्जनौँ नयाँ शब्द बन्छन्। परीक्षामा "यो मूल शब्दबाट चार शब्द बनाउनुहोस्" भन्ने प्रश्न यसै आधारमा आउँछ।

| मूल शब्द | उपसर्गसहित बनेका शब्द |
|---|---|
| हार | प्रहार, आहार, विहार, संहार, उपहार, परिहार |
| मान | सम्मान, अपमान, अभिमान, अनुमान, परिमाण |
| गति | प्रगति, दुर्गति, सद्गति, अवगति, विगत |
| कार | उपकार, अपकार, प्रतिकार, आकार, विकार, संस्कार |
| योग | प्रयोग, संयोग, वियोग, उपयोग, नियोग |
| ज्ञान | विज्ञान, अज्ञान, सुज्ञान, प्रज्ञा |
| हरण | अपहरण, आहरण, संहरण, परिहरण |
| वाद | विवाद, संवाद, अनुवाद, प्रतिवाद, अपवाद |

::: memory निषेध जनाउने उपसर्गको सूची
एउटै काम — *नभएको* जनाउन — नेपालीमा धेरै उपसर्ग छन्: **अ** (अथाह), **अन** (अनमेल), **नि/निर्** (निडर, निर्दोष), **वि** (वियोग), **बे** (बेहोस), **ना** (नालायक), **ला** (लाचार), **गैर** (गैरकानुनी)। यीमध्ये कुन लाग्छ भन्ने मूल शब्दको स्रोतले तय गर्छ — तत्सम शब्दसँग तत्सम उपसर्ग, आगन्तुकसँग आगन्तुक।
:::

::: example उपसर्ग छुट्याउने चरणबद्ध विधि
**प्रश्न.** *अनुशासन*, *निर्दोष*, *बेरोजगार*, *अधमरो* — उपसर्ग छुट्याई अर्थ लेख्नुहोस्।

**समाधान.**
१. **मूल शब्द खोज्ने.** शब्दबाट अगाडिको भाग हटाएर बाँकी भाग स्वतन्त्र शब्द हो कि होइन जाँच्ने।
२. **उपसर्ग चिन्ने.** हटाइएको भाग तालिकामा छ कि छैन हेर्ने।
३. **अर्थ लेख्ने.**

| शब्द | उपसर्ग | मूल शब्द | अर्थ |
|---|---|---|---|
| अनुशासन | अनु | शासन | नियमअनुसार चल्ने व्यवस्था |
| निर्दोष | निर् | दोष | दोष नभएको |
| बेरोजगार | बे | रोजगार | रोजगार नभएको |
| अधमरो | अध | मरो (मर्नु) | आधा मरेको |
:::

::: example एउटै उपसर्ग, धेरै शब्द
**प्रश्न.** *प्रति* उपसर्ग लगाएर चार शब्द बनाई अर्थ लेख्नुहोस्।

**समाधान.**
१. **अर्थ सम्झने.** *प्रति* का दुई अर्थ छन् — (क) विपरीत, उल्टो; (ख) प्रत्येक, हरेक।
२. **शब्द बनाउने:**

| शब्द | विग्रह | अर्थ | कुन अर्थ लाग्यो |
|---|---|---|---|
| प्रतिकार | प्रति + कार | बदला लिनु | विपरीत |
| प्रतिवेदन | प्रति + वेदन | विवरण पेस गर्नु | तिर, सामु |
| प्रतिदिन | प्रति + दिन | हरेक दिन | प्रत्येक |
| प्रतिज्ञा | प्रति + ज्ञा | दृढ वचन | निश्चय |

**निष्कर्ष.** एउटै उपसर्गका एकभन्दा बढी अर्थ हुन सक्छन्; कुन अर्थ लाग्यो भन्ने मूल शब्दले तय गर्छ।
:::

::: example उपसर्ग कि उपसर्ग होइन?
**प्रश्न.** *सुदूर*, *सुत्केरी*, *सुपारी* — तीनै *सु* ले सुरु हुन्छन्। तीनैमा *सु* उपसर्ग हो?

**समाधान.**
१. *सुदूर* — हटाए *दूर* बाँकी रहन्छ, जो स्वतन्त्र शब्द हो; *सु* ले "धेरै" अर्थ थप्यो → **उपसर्ग हो**।
२. *सुत्केरी* — हटाए *त्केरी* बाँकी रहन्छ, जो कुनै शब्द होइन → **उपसर्ग होइन**, यो मूल शब्द हो।
३. *सुपारी* — हटाए *पारी* बाँकी रहन्छ, तर *सुपारी* को अर्थ *पारी* सँग कुनै सम्बन्ध छैन → **उपसर्ग होइन**।

**जाँचको सूत्र.** उपसर्ग हटाउँदा (क) बाँकी भाग अर्थपूर्ण शब्द हुनुपर्छ, र (ख) नयाँ शब्दको अर्थ त्यही मूल शब्दसँग जोडिनुपर्छ। दुवै सर्त पूरा भए मात्र उपसर्ग हो।
:::

::: caution विद्यार्थीले गर्ने वास्तविक गल्ती
- **उपसर्ग र प्रत्यय साटिने।** उपसर्ग अगाडि (*अप*मान), प्रत्यय पछाडि (लेख*क*)।
- **शब्दको पहिलो अक्षरलाई नै उपसर्ग भन्ने।** *सुपारी*, *सुत्केरी*, *अनार* मा *सु*, *अन* उपसर्ग होइनन्।
- **सन्धि भएको उपसर्ग नचिन्ने।** *निर् + आश = निराश*, *सम् + मान = सम्मान*, *उत् + नति = उन्नति*, *अति + अन्त = अत्यन्त*। सन्धिले रूप फेरिए पनि उपसर्ग त्यही हो।
- **मिसमास जोडी बनाउने।** *गैरविद्वान्*, *बेसम्मान* जस्ता जोडी नेपालीमा चल्दैनन् — आगन्तुक उपसर्ग आगन्तुक वा नेपाली शब्दसँग मात्र जोडिन्छ।
- **दुई उपसर्ग एकैचोटि लगाउँदा क्रम बिगार्ने।** *अन् + उपयोगी = अनुपयोगी* (*उपअनयोगी* होइन)।
:::

::: tip परीक्षामा छोटोमा पूरा अङ्क
प्रश्न प्रायः "उपसर्ग थपी नयाँ शब्द बनाउनुहोस्" वा "उपसर्ग छुट्याउनुहोस्" भन्ने आउँछ। उत्तरमा **विग्रह देखाउनुहोस्** — *निराश = निर् + आश*। विग्रह नदेखाए आधा अङ्क जान्छ। सन्धिले रूप फेरिएको भए मूल उपसर्ग नै लेख्नुहोस्, फेरिएको रूप होइन।
:::

## पाठको सार

- शब्दनिर्माणका चार प्रक्रिया: उपसर्ग, प्रत्यय, समास, द्वित्व।
- उपसर्ग शब्दको अगाडि आउँछ, एक्लै अर्थ दिँदैन, र मूल शब्दको अर्थ बदल्छ।
- संस्कृत उपसर्ग बाइस — प्र, परा, अप, सम्, अनु, अव, निस्/निर्, दुस्/दुर्, वि, आ, नि, अधि, अपि, अति, सु, उत्, अभि, प्रति, परि, उप।
- नेपाली उपसर्ग: अ, अन, अध, उन, कु, भर, नि, सु, पर।
- आगन्तुक उपसर्ग: बे, बद, ला, गैर, हर, ना, कम (फारसी–अरबी); सब, हेड (अङ्ग्रेजी)।
- उपसर्ग हो कि होइन जाँच्न — हटाउँदा बाँकी भाग अर्थपूर्ण शब्द हुनुपर्छ र अर्थ जोडिनुपर्छ।
- उत्तरमा सधैँ विग्रह देखाउने: *अपमान = अप + मान*।

14. शब्दको अगाडि जोडिने शब्दांशलाई ………… भनिन्छ। <span class="marks">[1]</span>
15. *उन्नति* मा ………… उपसर्ग छ। <span class="marks">[1]</span>
16. *बेइमान* मा प्रयुक्त उपसर्ग ………… भाषाबाट आएको हो। <span class="marks">[1]</span>
17. *अधमरो* को उपसर्ग *अध* को अर्थ ………… हो। <span class="marks">[1]</span>

::: note उत्तर
**१४.** उपसर्ग — पछाडि जोडिने भए प्रत्यय हुन्थ्यो।
**१५.** उत् — *उत् + नति = उन्नति*, सन्धिले *त्* को *न्* भयो।
**१६.** फारसी — *बे* फारसी उपसर्ग हो।
**१७.** आधा — जस्तै *अधकल्चो*, *अधबैँसे*।
:::

**छोटो उत्तर दिनुहोस् (३ अङ्क)**

18. उपसर्ग भनेको के हो? पहिचानका तीन आधार उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
19. *अप*, *सु* र *अनु* उपसर्गका अर्थ र प्रत्येकका दुई-दुई उदाहरण लेख्नुहोस्। <span class="marks">[3]</span>
20. नेपाली र आगन्तुक उपसर्गका तीन-तीन उदाहरण अर्थसहित लेख्नुहोस्। <span class="marks">[3]</span>
21. *सुपारी* मा *सु* उपसर्ग होइन भन्ने कसरी थाहा हुन्छ? जाँचको विधि लेख्नुहोस्। <span class="marks">[3]</span>
22. सन्धि भएका उपसर्गयुक्त तीन शब्दको विग्रह गर्नुहोस् — *सम्मान, अत्यन्त, निष्फल*। <span class="marks">[3]</span>

::: note उत्तर
**१८.** शब्दको अगाडि जोडिएर अर्थ बदल्ने तर आफैँ स्वतन्त्र नहुने शब्दांश उपसर्ग हो। आधार — (क) स्थान: सधैँ अगाडि (*अप*मान); (ख) स्वतन्त्रता: एक्लै अर्थ दिँदैन (*अप* एक्लै केही होइन); (ग) अर्थ परिवर्तन: *मान* बाट *अपमान* बन्दा अर्थ उल्टियो।
**१९.** *अप* = खराब/विपरीत — अपमान, अपकार। *सु* = राम्रो/सजिलो — सुशासन, सुगम। *अनु* = पछि/अनुसार — अनुसरण, अनुवाद।
**२०.** नेपाली — *कु* (खराब): कुबाटो; *अध* (आधा): अधमरो; *भर* (पूरा): भरपेट। आगन्तुक — *बे* (नभएको): बेहोस; *गैर* (विपरीत): गैरकानुनी; *हर* (प्रत्येक): हरदिन।
**२१.** दुई सर्त जाँच्ने — (क) *सु* हटाउँदा बाँकी *पारी* अर्थपूर्ण शब्द त हो, तर (ख) *सुपारी* को अर्थ *पारी* सँग कुनै सम्बन्ध छैन। दोस्रो सर्त पूरा नभएकाले *सु* यहाँ उपसर्ग होइन; *सुपारी* मूल (रूढ) शब्द हो।
**२२.** सम्मान = सम् + मान; अत्यन्त = अति + अन्त (*इ + अ = य*, यण् सन्धि); निष्फल = निस् + फल (*स्* को *ष्* भयो, विसर्ग सन्धि)।
:::

26. तल दिइएको अनुच्छेदबाट उपसर्गयुक्त चार शब्द टिपी विग्रह गर्नुहोस् — *काठमाडौँका अधिकांश विद्यार्थी दसैँमा घर फर्कन्छन्। यातायात महँगो हुँदा कतिपय बेरोजगार युवा निराश हुन्छन्, तर गैरसरकारी संस्थाको सहयोगले उनीहरूको प्रगति रोकिँदैन।* <span class="marks">[3]</span>

::: note उत्तर
**२३.** प्रहार, आहार, विहार, संहार — चारै शब्दमा मूल *हार* यथावत् छ, उपसर्गले मात्र अर्थ फेरेको छ।
**२४.** उपकार, अपकार, प्रतिकार, संस्कार — *उप* ले भलाइ, *अप* ले हानि, *प्रति* ले बदला जनायो।
**२५.** प्रयोग, संयोग, वियोग, उपयोग — *वि* ले छुट्टिनु, *सम्* ले मिल्नु जनाएकाले अर्थ ठिक उल्टो भयो।
**२६.** अधिकांश = अधि + कांश; बेरोजगार = बे + रोजगार; निराश = निर् + आश; गैरसरकारी = गैर + सरकारी; प्रगति = प्र + गति (कुनै चार लेखे पुग्छ)।
:::
