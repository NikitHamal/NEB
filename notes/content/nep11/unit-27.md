यो अध्याय कुनै एउटा प्रश्नको अध्याय होइन — यो **पूरै प्रश्नपत्रभरि फैलिएको** अध्याय हो। विशिष्टीकरण तालिकामा **शब्दस्रोत र शब्दकोश**का २ अङ्क र **शब्दनिर्माण**का ४ अङ्क छुट्टै छन्, तर यसको प्रयोग त्यतिमै सीमित छैन। **पठनबोध (८ अङ्क)** मा "यस अनुच्छेदको … शब्दको अर्थ लेख्नुहोस्" सोधिन्छ, **पाठगत बोध (८ अङ्क)** मा हरेक पाठको शब्दभण्डार अभ्यास आउँछ, र **स्वतन्त्र रचना (८ अङ्क)** मा उखान-टुक्काको सही प्रयोगले नै उत्तरलाई साधारणबाट राम्रो बनाउँछ। छोटकरीमा — यो अध्याय जति पूरा हुन्छ, प्रश्नपत्रभरि त्यति अङ्क बढ्छ।

::: key यस अध्यायको मूल्य तालिकाको पूर्णतामा छ
यहाँका तालिका पढेर बुझ्ने होइन, **दोहोर्‍याएर कण्ठ पार्ने** हुन्। दिनको एक तालिका, हप्तामा एक दोहोर्‍याइ — यही तरिका काम लाग्छ। परीक्षामा सोधिने रूप तीन प्रकारका हुन्छन्: **(१)** शब्द दिएर अर्थ/पर्याय/विपरीत माग्ने, **(२)** उखान वा टुक्का दिएर अर्थ र **वाक्यमा प्रयोग** माग्ने, र **(३)** अङ्ग्रेजी पारिभाषिक शब्दको नेपाली रूप माग्ने। तेस्रो प्रकारमा **वाक्य प्रयोग नबिर्सनुहोस्** — अर्थ मात्र लेखे आधा अङ्क जान्छ।
:::

## 27.1 शब्दभण्डार र त्यसका स्रोत

::: definition शब्दभण्डार

:::

:::

## 27.4 अनेकार्थी शब्द

एउटै शब्दले प्रसङ्गअनुसार फरक-फरक अर्थ दिन्छ भने त्यसलाई **अनेकार्थी** शब्द भनिन्छ। परीक्षामा यस्ता शब्द दिएर **"दुई फरक अर्थमा वाक्य बनाउनुहोस्"** भनिन्छ — त्यसैले अर्थ मात्र कण्ठ गर्नु पर्याप्त छैन, वाक्य बनाउन आउनुपर्छ।

::: example उत्तर लेख्ने ढाँचा
**प्रश्न :** 'कर' शब्दलाई दुई फरक अर्थमा वाक्यमा प्रयोग गर्नुहोस्। <span class="marks">[२]</span>
**उत्तर :** (क) **कर** = हात — *राजाले शिशुको शिरमा आफ्नो **कर** राखे।* (ख) **कर** = तिरो — *हरेक नागरिकले समयमै **कर** बुझाउनुपर्छ।*
ध्यान दिनुहोस् — अर्थ कोष्ठमा छुट्टै लेखेर मात्र पूरा अङ्क आउँछ।
:::

| अर्थ | माने; धन; प्रयोजन | यो शब्दको **अर्थ** नबुझी **अर्थ** खर्च गर्नु मूर्खता हो। |

## 27.5 उखान

लोकजीवनको लामो अनुभवबाट निस्किएको, कुनै पूरा कुरा छोटो वाक्यमा भन्ने र वक्ताको आफ्नै रूपमा जस्ताको तस्तै दोहोरिने कथनलाई **उखान** भनिन्छ। उखान आफैँमा **पूरा वाक्य** हुन्छ र यसको रूप फेरिँदैन।

::: definition उखान र टुक्काको भेद

:::

| कागलाई बेल पाक्यो हर्ष न विस्मात् | काम नलाग्ने कुराले खुसी पनि दुःख पनि दिँदैन |
| अगुल्टाले हानेको कुकुर बिजुली चम्कँदा तर्सन्छ | एक पटक ठुलो चोट खाएको मानिस सानो सङ्केतमै डराउँछ |
| अचानोको पीर खुकुरीलाई थाहा हुँदैन | पीडा भोग्नेको दुःख नभोग्नेले बुझ्दैन |
| आकाशको फल आँखा तरी मर | नपाइने कुराको लालच गर्नु व्यर्थ हुन्छ |
| घाँटी हेरी हाड निल्नु | आफ्नो क्षमता हेरेर मात्र काम थाल्नु |
| बोल्नेको पिठो बिक्छ, नबोल्नेको चामल पनि बिक्दैन | आफ्नो कुरा राख्न सक्नेले नै अवसर पाउँछ |
| आँप खानु कि रुख गन्नु | मुख्य प्रयोजनमा ध्यान दिनुपर्छ, बेकारको हिसाबमा होइन |
| बाँदरको हातमा नरिवल | अयोग्यको हातमा बहुमूल्य वस्तु पर्नु |
| हात्ती आयो हात्ती आयो फुस्सा | ठुलो हल्ला भएको कुरा केही पनि नहुनु |
| जस्तो देश उस्तै भेष | ठाउँअनुसार आफूलाई ढाल्नुपर्छ |
| दैव पनि बलियाको पक्षमा | शक्तिशालीलाई परिस्थितिले पनि साथ दिन्छ |
| नदी किनारको रुख | जुनसुकै बेला नष्ट हुन सक्ने अनिश्चित अवस्था |
| आफू भलो त जगत् भलो | आफ्नो मन सफा भए संसार पनि राम्रो देखिन्छ |
| जसको शक्ति, उसैको भक्ति | शक्तिशाली हुनेलाई नै सबैले मान्छन् |
| एउटै हातले ताली बज्दैन | झगडा वा काम दुवैतिरको सहभागिताबिना हुँदैन |
| हात्ती छिर्‍यो, पुच्छर अड्कियो | ठुलो काम सकिएर सानो कुरामा अड्किनु |
| अति भएपछि खति हुन्छ | कुनै पनि कुरा हदभन्दा बढी भएपछि हानि गर्छ |
| हतारको काम, लतारको फल | हतार गरेर गरेको कामको नतिजा राम्रो हुँदैन |
| चिन्ता चिता समान | चिन्ताले मानिसलाई बिस्तारै नष्ट गर्छ |
| जोगी भएपछि सहर कुदाइ किन | जिम्मेवारी लिएपछि त्यसैमा स्थिर हुनुपर्छ |
| जुन जोगी आए पनि कानै चिरेका | नेतृत्व फेरिए पनि अवस्था उस्तै रहनु |
| दुई डुङ्गामा खुट्टा | दुवैतिर बराबर लागेर कतै पनि नपुग्नु |
| बिरालोको घाँटीमा घन्टी कसले बाँध्ने | कठिन र जोखिमपूर्ण काम गर्न कोही अगाडि नसर्नु |
| डुब्नेलाई कुँडोको सहारा | सङ्कटमा परेकाले सानो सहारालाई पनि ठुलो ठान्छ |
| बाघको मुखमा परेको मृग | उम्कनै नसक्ने सङ्कटमा पर्नु |
| मन लागे महादेव, नलागे धोबीघाट | मन लागे जे पनि राम्रो, नलागे जे पनि नराम्रो |
| सानो मुखले ठुलो कुरा | आफ्नो हैसियतभन्दा माथिको कुरा गर्नु |
| हिमाल हेरेर आँसु झार्नु | आफूले केही गर्न नसकी निरीह भई बस्नु |

## 27.6 टुक्का

शब्दको सामान्य अर्थभन्दा फरक, **लाक्षणिक अर्थ** दिने वाक्यांशलाई **टुक्का** (मुहावरा) भनिन्छ। टुक्का आफैँमा अपूर्ण हुन्छ; कर्ता, काल र आदरका अनुसार क्रिया फेरेर वाक्यमा मिलाउनुपर्छ।

::: caution टुक्का लेख्दा अङ्क गुम्ने सबैभन्दा ठुलो कारण
प्रश्नले **"अर्थ खुल्ने गरी वाक्यमा प्रयोग गर्नुहोस्"** भन्छ। धेरै विद्यार्थी टुक्कालाई जस्ताको तस्तै वाक्यमा घुसाउँछन् — *"उसले खुट्टा तान्नु गर्‍यो"* — यो गलत हो। क्रियालाई वाक्यअनुसार फेर्नुहोस् : *"उसले मेरो **खुट्टा तान्यो**।"* अझ राम्रो हुन्छ, वाक्यको प्रसङ्गले नै टुक्काको अर्थ झल्काओस्।
:::

| टुक्का | अर्थ | वाक्य प्रयोग |
|---|---|---|
| आँखा चिम्लनु | मर्नु; जानाजान वास्ता नगर्नु | हजुरबुबाले ९० वर्षको उमेरमा **आँखा चिम्लनुभयो**। |
| आँखाको तारो हुनु | सबैभन्दा प्यारो हुनु | जेठी छोरी बुबाको **आँखाको तारो** थिइन्। |
| आँखा देखाउनु | धम्क्याउनु | सानालाई **आँखा देखाएर** काम गराउने बानी राम्रो होइन। |
| आकाश खस्नु | अचानक ठुलो विपत् आइपर्नु | नतिजा सुन्नेबित्तिकै उसको टाउकोमा **आकाश खस्यो**। |
| उँधोमुन्टो लाग्नु | लज्जित हुनु | चोरी पक्राउ परेपछि ऊ **उँधोमुन्टो लाग्यो**। |
| कन्जुस्याइँ गर्नु | अनावश्यक कञ्जुसी देखाउनु | औषधि किन्नमा समेत उसले **कन्जुस्याइँ गर्‍यो**। |
| कान भर्नु | कसैविरुद्ध चुक्ली लगाउनु | छिमेकीले हाकिमको **कान भरे**। |
| कान खाइदिनु | बढी बोलेर दिक्क बनाउनु | दिनभरिको गनगनले उसले मेरो **कान खाइदियो**। |
| कम्मर कस्नु | दृढ सङ्कल्पसाथ तयार हुनु | परीक्षा नजिकिएपछि सबै विद्यार्थी **कम्मर कसे**। |
| कुम थाप्नु | जिम्मेवारी लिनु | दाजुको मृत्युपछि उसले घरको भार **कुम थाप्यो**। |
| खुट्टा तान्नु | अगाडि बढ्न नदिनु, अवरोध गर्नु | नेपालीहरू एकअर्काको **खुट्टा तान्न** छाड्नुपर्छ। |
| खोपीको देउता हुनु | नाम मात्रको, अधिकारविहीन हुनु | अधिकार नदिए अध्यक्ष **खोपीको देउता** बन्छन्। |
| गम खानु | विचार गर्नु, सोच्नु | प्रस्ताव सुनेर उनले लामो **गम खाए**। |
| गाँठो पर्नु | समस्या वा मनमुटाव उत्पन्न हुनु | सानो कुरामा दुई साथीबिच **गाँठो पर्‍यो**। |
| घिउ चामल हुनु | अत्यन्त मिलेर बस्नु | विवाहपछि ती दुई **घिउ चामल** भए। |
| घाँटी रेट्नु | ठुलो अन्याय गर्नु, ठग्नु | बिचौलियाले किसानको **घाँटी रेटे**। |
| चट्याङ पर्नु | अप्रत्याशित दुर्घटना हुनु | खबर सुन्नेबित्तिकै परिवारमा **चट्याङ पर्‍यो**। |
| छक्का पञ्जा हुनु | अति चलाख र धूर्त हुनु | त्यो मान्छे व्यापारमा **छक्का पञ्जा** छ। |
| जिब्रो टोक्नु | गल्ती भएको महसुस गरी पछुताउनु | गुरुकै अगाडि गाली गरेपछि उसले **जिब्रो टोक्यो**। |
| जुँगामा ताउ लगाउनु | घमण्ड देखाउनु | जित्नेबित्तिकै उसले **जुँगामा ताउ लगायो**। |
| टाउको दुखाइ हुनु | झन्झटको विषय बन्नु | फोहोर व्यवस्थापन नगरपालिकाको **टाउको दुखाइ** भएको छ। |
| ठिक पार्नु | सजाय दिनु, सिधा बनाउनु | बदमासी गरे प्रहरीले **ठिक पार्छ**। |
| डाँको छोड्नु | ठुलो स्वरले रुनु | आमाको सम्झना आएर बच्चाले **डाँको छोड्यो**। |
| ढाड सेक्नु | अत्यधिक शोषण गर्नु | ब्याजले किसानको **ढाड सेक्यो**। |
| ताउरमाउर गर्नु | अस्तव्यस्त र हतारिँदै गर्नु | समय घर्केपछि ऊ **ताउरमाउर गर्न** थाल्यो। |
| दाँत देखाउनु | निरीह भई हाँस्नु, गिड्गिडाउनु | पक्राउ परेपछि उसले **दाँत देखायो**। |
| दाल गल्नु | चाल वा योजना सफल हुनु | इमानदार हाकिमसँग उसको **दाल गलेन**। |
| धुलो चटाउनु | बुरी तरहले हराउनु | फाइनलमा हाम्रो टोलीले प्रतिद्वन्द्वीलाई **धुलो चटायो**। |
| नाक काटिनु | इज्जत जानु | छोराको व्यवहारले बुबाको **नाक काटियो**। |
| नाक राख्नु | इज्जत जोगाउनु | उसले जिल्लाकै **नाक राख्यो**। |
| नुन खाएको सम्झनु | उपकार सम्झेर वफादार हुनु | **नुन खाएको सम्झेर** उसले साथीलाई धोका दिएन। |
| पानी पानी हुनु | अत्यन्त लज्जित हुनु | झूट पक्राउ परेपछि ऊ **पानी पानी भयो**। |
| पानी माथिको ओभानो हुनु | दोषी भएर पनि निर्दोष देखिन खोज्नु | सबै थाहा हुँदाहुँदै ऊ **पानी माथिको ओभानो** बन्न खोज्यो। |
| पेट पाल्नु | जीविका चलाउनु | ज्याला मजदुरी गरेर उसले **पेट पाल्यो**। |
| बाल नदिनु | वास्ता नगर्नु | जति सम्झाए पनि उसले **बाल दिएन**। |
| मुख छोप्नु | लाजले अनुहार लुकाउनु | प्रश्न सोध्नेबित्तिकै उसले **मुख छोप्यो**। |
| मुख बिगार्नु | नराम्रो बोल्नु | सभामा **मुख बिगार्नु** शोभनीय होइन। |
| मन खिन्न हुनु | उदास हुनु | साथीको बिदाइले सबैको **मन खिन्न भयो**। |
| रगत पसिना एक गर्नु | अथक परिश्रम गर्नु | बुबाआमाले **रगत पसिना एक गरेर** पढाए। |
| रुखो हुनु | निष्ठुर र कठोर व्यवहार देखाउनु | दुःखमा परेकासँग **रुखो** नबन्नुहोस्। |
| लात खानु | अपमानित हुनु | बारम्बार **लात खाएर** पनि उसले इमान छाडेन। |
| हात धुनु | गुमाउनु | ढिलो गर्दा उसले अवसरबाट **हात धुनुपर्‍यो**। |
| हात हाल्नु | कुनै काममा संलग्न हुनु; कुट्न थाल्नु | नजानेको कुरामा **हात हाल्नु** हुँदैन। |
| हात्ती मार्नु | ठुलो काम फत्ते गर्नु | एउटा परीक्षा पास गरेर **हात्ती मारेँ** नठान्नू। |
| हुर्मत लिनु | बेइज्जत गर्नु | सार्वजनिक ठाउँमा कसैको **हुर्मत लिनु** हुँदैन। |

## 27.7 पारिभाषिक शब्द

कुनै निश्चित विषय वा पेसाभित्र **एउटै निश्चित अर्थ** दिने गरी तय गरिएको शब्दलाई **पारिभाषिक शब्द** (प्राविधिक शब्द) भनिन्छ। सामान्य शब्दको अर्थ प्रसङ्गअनुसार फेरिन सक्छ, तर पारिभाषिक शब्दको अर्थ त्यस विषयभित्र फेरिँदैन — यही यसको विशेषता हो।

::: definition पारिभाषिक शब्दका तीन लक्षण
**(१) एकार्थकता** — एउटा विषयभित्र एउटै अर्थ (कानुनमा *"वादी"* भनेको मुद्दा हाल्ने पक्ष मात्र हो)। **(२) विषयबद्धता** — त्यही विषयमा मात्र त्यो अर्थ लाग्छ (*"वंशाणु"* जीवविज्ञानको मात्र शब्द हो)। **(३) निश्चितता** — अनुवाद वा प्रयोग गर्दा मनपरी पर्याय राख्न मिल्दैन।
:::

### (क) प्रशासनसम्बन्धी

| पारिभाषिक शब्द | अर्थ |
|---|---|
| निजामती सेवा | सरकारी प्रशासन चलाउने स्थायी कर्मचारी सेवा (Civil Service) |
| दरबन्दी | कुनै कार्यालयमा स्वीकृत भएको पदको निश्चित सङ्ख्या |
| अख्तियार | कानुनले दिएको अधिकार वा जिम्मेवारी |
| तोक आदेश | माथिल्लो अधिकारीले कागजमै लेखेर दिने निर्देशन |
| चलानी | कार्यालयबाट बाहिर पठाइने पत्रको दर्ता र क्रम |
| दर्ता | कार्यालयमा भित्रिएको पत्र अभिलेखमा चढाउने काम |
| बोधार्थ | जानकारीका लागि पत्रको प्रति पठाइने व्यवस्था |
| जवाफदेहिता | गरेको कामको उत्तर दिनुपर्ने दायित्व (Accountability) |
| पारदर्शिता | निर्णय र कामकारबाही सबैले देख्न सक्ने खुला अवस्था |
| सुशासन | न्यायपूर्ण, पारदर्शी र जनमुखी शासन व्यवस्था |
| सङ्गठन संरचना | कार्यालयभित्रको पद र तहको व्यवस्थित ढाँचा |
| वृत्ति विकास | कर्मचारीको तालिम, बढुवा र क्षमता विकासको प्रक्रिया |
| बजेट | आय र व्ययको पूर्वअनुमानित वार्षिक विवरण |

## Chapter summary

::: key एक नजरमा
**शब्दभण्डार** = भाषामा उपलब्ध सबै शब्दको समष्टि; स्रोतका आधारमा **तत्सम, तद्भव, आगन्तुक, अनुकरणात्मक** र **जनजातीय/मौलिक**।

**पर्यायवाची** = एउटै अर्थ दिने शब्द (आकाश — गगन, नभ, अम्बर)। परीक्षामा कम्तीमा तीन पर्याय लेख्नुहोस्; तत्समको ठाउँमा तत्सम राख्नुहोस्।

**विपरीतार्थी** = उल्टो अर्थ दिने शब्द। दुई तरिका — छुट्टै शब्द (जय × पराजय) र उपसर्ग (सफल × असफल)। हरेकमा *अ-* जोडेर पुग्दैन।

**अनेकार्थी** = एउटै शब्दका धेरै अर्थ (कर = हात/तिरो/किरण)। उत्तरमा अर्थ कोष्ठमा छुट्याएर दुईवटा छुट्टै वाक्य बनाउनुहोस्।

**उखान** = पूरा वाक्य, स्वतन्त्र, रूप नफेरिने, लोकअनुभवको निचोड। **टुक्का** = वाक्यांश, लाक्षणिक, क्रिया जोडेर वाक्यमा ढाल्नुपर्ने। परीक्षामा यी दुईको भिन्नता प्रायः सोधिन्छ।

**पारिभाषिक शब्द** = निश्चित विषयभित्र निश्चित अर्थ दिने शब्द; लक्षण — **एकार्थकता, विषयबद्धता, निश्चितता**।
:::

**प**र्यायवाची → **वि**परीतार्थी → **अ**नेकार्थी → **उ**खान → **टु**क्का → **पा**रिभाषिक। यही क्रममा दोहोर्‍याउनुहोस्; परीक्षामा पनि प्रायः यही क्रममा सोधिन्छ।
:::

## Practice questions

**१. तलका शब्दका तीन-तीन ओटा पर्यायवाची लेख्नुहोस् : सूर्य, नदी, घर, आँखा** <span class="marks">[२]</span>

**उत्तर :** **सूर्य** — सूरज, भानु, रवि, दिनकर। **नदी** — सरिता, तटिनी, तरङ्गिणी। **घर** — गृह, निवास, सदन, भवन। **आँखा** — नेत्र, नयन, लोचन, चक्षु।

**२. तलका शब्दका विपरीतार्थी लेख्नुहोस् : आय, कृतज्ञ, उत्कर्ष, जङ्गम, सापेक्ष** <span class="marks">[२]</span>

**उत्तर :** आय × **व्यय**; कृतज्ञ × **कृतघ्न**; उत्कर्ष × **अपकर्ष**; जङ्गम × **स्थावर**; सापेक्ष × **निरपेक्ष**।

**३. 'पत्र' र 'फल' शब्दलाई दुई-दुई फरक अर्थमा वाक्यमा प्रयोग गर्नुहोस्।** <span class="marks">[२]</span>

**उत्तर :**
**पत्र** (क) *पात* — हिउँदमा रूखका **पत्र** झर्छन्। (ख) *चिठी* — हुलाकीले मेरो नाममा आएको **पत्र** ल्याइदिए।
**फल** (क) *रूखको फल* — बगैँचाको आँपको **फल** पाकिसक्यो। (ख) *नतिजा* — मिहिनेतको **फल** ढिलो भए पनि मीठो हुन्छ।

**४. उखान र टुक्काबिचको भिन्नता चार बुँदामा लेख्नुहोस्।** <span class="marks">[४]</span>

**उत्तर :**
(क) **रूप** — उखान पूरा वाक्य हुन्छ (*"नाच्न नजान्ने आँगन टेढो"*), टुक्का वाक्यांश मात्र हुन्छ (*"खुट्टा तान्नु"*)।
(ख) **स्वतन्त्रता** — उखान आफैँ उभिन सक्छ; टुक्का क्रिया जोडेर वाक्यमा नमिलाई अपूर्ण रहन्छ।
(ग) **परिवर्तनशीलता** — उखानको रूप जस्ताको तस्तै रहन्छ; टुक्काको क्रिया कर्ता, काल र आदरअनुसार फेरिन्छ (*खुट्टा तान्यो / तान्नुभयो / तान्नेछ*)।
(घ) **प्रयोजन** — उखानले लोकअनुभवको निचोड वा उपदेश दिन्छ; टुक्काले कुनै भाव वा क्रियालाई लाक्षणिक र प्रभावकारी बनाउँछ।

**५. तलका टुक्काको अर्थ लेखी अर्थ खुल्ने गरी वाक्यमा प्रयोग गर्नुहोस् : (क) कान भर्नु (ख) कम्मर कस्नु (ग) आँखाको तारो हुनु (घ) धुलो चटाउनु** <span class="marks">[४]</span>

**उत्तर :**
(क) **कान भर्नु** = कसैविरुद्ध चुक्ली लगाउनु। — *ईर्ष्यालु सहकर्मीले हाकिमको **कान भरेपछि** उसको बढुवा रोकियो।*
(ख) **कम्मर कस्नु** = दृढ सङ्कल्पसाथ तयार हुनु। — *परीक्षा एक महिना मात्र बाँकी रहेपछि सबै विद्यार्थी पढाइमा **कम्मर कसे**।*
(ग) **आँखाको तारो हुनु** = सबैभन्दा प्यारो हुनु। — *पढाइमा अब्बल भएकाले ऊ शिक्षकहरूको **आँखाको तारो** थियो।*
(घ) **धुलो चटाउनु** = बुरी तरहले हराउनु। — *फाइनल खेलमा हाम्रो टोलीले प्रतिद्वन्द्वीलाई **धुलो चटायो**।*

**६. तलका उखानको अर्थ खुलाउनुहोस् : (क) हुने बिरुवाको चिल्लो पात (ख) चोरलाई चौतारो, साधुलाई सुली (ग) अचानोको पीर खुकुरीलाई थाहा हुँदैन (घ) एक थुकी सुकी, सय थुकी नदी** <span class="marks">[४]</span>

**उत्तर :**
(क) भविष्यमा ठुलो र सफल हुने व्यक्तिका लक्षण सानै उमेरदेखि देखिन थाल्छन्।
(ख) समाजमा अन्याय हुँदा दोषीले सुविधा र सम्मान पाउँछ भने निर्दोषले दुःख र सजाय भोग्नुपर्छ।
(ग) दुःख भोग्नेको पीडा त्यो नभोग्नेले बुझ्न सक्दैन।
(घ) एक्लै गर्दा नगण्य देखिने योगदान सबै मिलेर गर्दा ठुलो शक्ति बन्छ।

**७. पारिभाषिक शब्द भनेको के हो? यसका तीन लक्षण उदाहरणसहित लेख्नुहोस्।** <span class="marks">[४]</span>

**उत्तर :** कुनै निश्चित विषय, पेसा वा शास्त्रभित्र एउटै निश्चित अर्थ दिने गरी तय गरिएको शब्दलाई **पारिभाषिक शब्द** भनिन्छ। यसका लक्षण :
(क) **एकार्थकता** — त्यस विषयभित्र त्यसको एउटै अर्थ हुन्छ; जस्तै कानुनमा *"प्रतिवादी"* भनेको जसका विरुद्ध मुद्दा दायर गरिएको छ, त्यही पक्ष मात्र हो।
(ख) **विषयबद्धता** — शब्द आफ्नो विषयक्षेत्रसँग बाँधिएको हुन्छ; *"वंशाणु"* जीवविज्ञानको, *"दरबन्दी"* प्रशासनको र *"धरौटी"* कानुनको शब्द हो।
(ग) **निश्चितता** — मनपरी पर्याय राखेर फेर्न मिल्दैन; *"निवृत्तिभरण"* को ठाउँमा *"बुढेसकालको पैसा"* लेख्न मिल्दैन।

**८. तलका अङ्ग्रेजी शब्दका नेपाली पारिभाषिक रूप लेख्नुहोस् : Accountability, Ecosystem, Constitution, Curriculum, Vaccine, Audit** <span class="marks">[३]</span>

**उत्तर :** Accountability — **जवाफदेहिता**; Ecosystem — **पारिस्थितिक प्रणाली**; Constitution — **संविधान**; Curriculum — **पाठ्यक्रम**; Vaccine — **खोप**; Audit — **लेखा परीक्षण**।

**९. तत्सम र तद्भव शब्दबिचको भिन्नता उदाहरणसहित छोटकरीमा लेख्नुहोस्।** <span class="marks">[२]</span>

**उत्तर :** संस्कृतबाट कुनै परिवर्तनबिना जस्ताको तस्तै नेपालीमा आएका शब्द **तत्सम** हुन् — जल, अग्नि, हस्त, नेत्र, दुग्ध। संस्कृतबाटै आए पनि उच्चारणका क्रममा रूप बदलिएर आएका शब्द **तद्भव** हुन् — पानी (< जल होइन, *पानीय*), आगो (< अग्नि), हात (< हस्त), आँखा (< अक्षि), दूध (< दुग्ध)। अर्थ उही भए पनि स्रोत-रूपको फरकले वर्ग छुट्टिन्छ।

**१०. तलको अनुच्छेद पढी दिइएका शब्दका पर्यायवाची लेख्नुहोस्।** <span class="marks">[३]</span>

> साँझपख **पर्वत**को टुप्पोमा **सूर्य** अस्ताउँदै थियो। **आकाश**मा रातो **बादल** छरिएको थियो र तल **नदी** सुस्तरी बगिरहेकी थिइन्। त्यही दृश्य हेर्दै एउटा **चरा** गुँडतिर फर्कियो।

**उत्तर :** **पर्वत** — हिमाल, गिरि, शैल, अचल। **सूर्य** — रवि, भानु, दिनकर, आदित्य। **आकाश** — गगन, नभ, अम्बर, व्योम। **बादल** — मेघ, जलद, घन, अम्बुद। **नदी** — सरिता, तटिनी, तरङ्गिणी। **चरा** — पक्षी, खग, विहग, पखेरु।
