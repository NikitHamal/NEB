एकाइ १५ मा रूप फेर्ने चार विकारी पदवर्ग पढियो। यहाँ रूप नफेर्ने पाँच **अविकारी** पदवर्ग पढिन्छ — नामयोगी, क्रियायोगी, संयोजक, विस्मयादिबोधक र निपात। यी पद वाक्यमा जहाँ राखे पनि उस्तै रहन्छन्, तर वाक्यको अर्थ यिनैले बाँध्छन्। एकाइको दोस्रो भाग **शब्द रूपायन** हो — पाठ्यक्रम विकास केन्द्र ग्रिडमा रूपायन र पदसङ्गतिबाट ३ अङ्क छुट्टै छ।

::: key पाँच अविकारी पद एकै वाक्यमा
**"ओहो !** रामले **पनि** कोशी**सम्म** **छिटो** पुग्यो, **तर** थाक्यो।" — *ओहो* विस्मयादिबोधक, *पनि* निपात, *सम्म* नामयोगी, *छिटो* क्रियायोगी, *तर* संयोजक। एउटै वाक्यले पाँचै देखाउँछ; यही वाक्य सम्झे पाँचै पदवर्ग सम्झिन्छ।
:::

## 16.1 नामयोगी

::: definition नामयोगी
नाम वा सर्वनामको **पछाडि** आएर त्यसको अन्य पदसँगको सम्बन्ध देखाउने अविकारी पदलाई नामयोगी भनिन्छ।
:::

| भेद | नामयोगी | उदाहरण वाक्य |
|---|---|---|
| स्थानवाचक | माथि, मुनि, भित्र, बाहिर, नजिक, वरिपरि | किताब टेबुल**माथि** छ। |
| कालवाचक | अघि, पछि, सम्म, भित्र | दसैँ**पछि** विद्यालय खुल्छ। |
| करणवाचक | द्वारा, बाट, मार्फत | कोशी**बाट** पानी ल्याइयो। |
| निमित्तवाचक | लागि, निम्ति, खातिर | विद्यार्थीका**लागि** छात्रवृत्ति छ। |
| तुलनावाचक | भन्दा, जस्तो, सरह | पोखरा काठमाडौँ**भन्दा** शान्त छ। |
| सहार्थक | सँग, सँगै, समेत | म साथी**सँग** गएँ। |
| विरोधवाचक | विरुद्ध, विपरीत | निर्णय**विरुद्ध** उजुरी पर्‍यो। |
| अभाववाचक | बिना, बाहेक | टिकट**बिना** यात्रा गर्न पाइँदैन। |

::: caution नामयोगी कि विभक्ति?
विभक्ति (ले, लाई, को, मा) नामसँग टाँसिएर आउँछ र नामको रूप नै बदल्छ। नामयोगी छुट्टै शब्द हो र नामपछि थपिन्छ मात्र। *रामलाई* मा *लाई* विभक्ति हो; *रामका लागि* मा *लागि* नामयोगी हो। सोधिएमा "नामयोगी" लेख्नुअघि त्यो शब्द एक्लै अर्थ दिन्छ कि दिँदैन जाँच्नुहोस्।
:::

## 16.2 क्रियायोगी (क्रियाविशेषण)

::: definition क्रियायोगी
क्रियापदको विशेषता — कहिले, कहाँ, कसरी, कति — बताउने अविकारी पदलाई क्रियायोगी वा क्रियाविशेषण भनिन्छ।
:::

| भेद | प्रश्न | उदाहरण | वाक्य |
|---|---|---|---|
| कालवाचक | कहिले? | आज, भोलि, सधैँ, बिहान, अहिले | ऊ **भोलि** आउँछ। |
| स्थानवाचक | कहाँ? | यहाँ, त्यहाँ, तल, माथि, अगाडि | उनी **त्यहाँ** बसे। |
| रीतिवाचक | कसरी? | बिस्तारै, छिटो, राम्ररी, एक्कासि | ऊ **बिस्तारै** हिँड्यो। |
| परिमाणवाचक | कति? | धेरै, थोरै, अलिकति, निकै | पानी **धेरै** पर्‍यो। |
| निषेधवाचक | — | न, नाइँ, कदापि | ऊ **कदापि** आउँदैन। |
| प्रश्नवाचक | — | किन, कसरी, कहिले | तिमी **किन** ढिलो आयौ? |

**पहिचानको उपाय.** क्रियापदलाई "कसरी? कहिले? कहाँ? कति?" सोध्नुहोस् — जवाफ दिने पद क्रियायोगी हो। विशेषणले नामको विशेषता बताउँछ, क्रियायोगीले क्रियाको।

## 16.3 संयोजक

::: definition संयोजक
दुई शब्द, दुई पदावली वा दुई वाक्यलाई जोड्ने अविकारी पदलाई संयोजक (समुच्चयबोधक) भनिन्छ।
:::

| भेद | संयोजक | उदाहरण वाक्य |
|---|---|---|
| संयोजक (जोड्ने) | र, अनि, तथा, एवम् | राम **र** सीता आए। |
| वियोजक (छनोट) | वा, कि, अथवा | चिया **वा** कफी लिनुहुन्छ? |
| विरोधवाचक | तर, तैपनि, यद्यपि | ऊ पढ्यो, **तर** उत्तीर्ण भएन। |
| कारणवाचक | किनभने, किनकि | ऊ आएन, **किनभने** बिरामी थियो। |
| परिणामवाचक | त्यसैले, अतः, यसैले | बाटो बन्द थियो, **त्यसैले** ढिलो भयो। |
| सर्तवाचक | यदि…भने, जति…त्यति | **यदि** पढ्यौ **भने** उत्तीर्ण हुन्छौ। |

## 16.4 विस्मयादिबोधक

::: definition विस्मयादिबोधक
मनको अचानक आएको भाव — हर्ष, शोक, आश्चर्य, घृणा, सम्बोधन — जनाउने र प्रायः विस्मयादिबोधक चिह्न (!) सँगै आउने अविकारी पदलाई विस्मयादिबोधक भनिन्छ।
:::

| भाव | पद | वाक्य |
|---|---|---|
| हर्ष | वाह !, आहा !, साबास ! | **वाह !** कति राम्रो दृश्य। |
| शोक | अहो !, हाय !, ओहो ! | **हाय !** ऊ बितिहाल्यो। |
| आश्चर्य | अरे !, ए !, ओहो ! | **अरे !** तिमी कहिले आयौ? |
| घृणा | छि !, धत् ! | **छि !** कस्तो फोहोर। |
| सम्बोधन | ए !, हे !, ओ ! | **ए** भाइ ! यता आऊ। |
| स्वीकार | हस् !, ल ! | **ल !** जाऔँ। |

## 16.5 निपात

::: definition निपात
वाक्यमा कुनै पदको अर्थमा जोड, शङ्का, स्वीकार, निषेध वा आदर थप्ने तर आफैँ वाक्यको अङ्ग नबन्ने सानो अविकारी पदलाई निपात भनिन्छ।
:::

| भेद | निपात | वाक्य |
|---|---|---|
| बलदायक (जोड दिने) | नै, त, पो, सम्म, मात्र, पनि | रामले **नै** गर्‍यो। |
| स्वीकारार्थक | हो, हस्, हवस्, ल | **हो**, म जान्छु। |
| निषेधार्थक | होइन, अहँ, नाइँ | **होइन**, त्यो मेरो होइन। |
| प्रश्नार्थक | कि, र, नि, हो ? | तिमी जान्छौ **कि** ? |
| आदरार्थक | ज्यू, हजुर, है | गुरु**ज्यू**, नमस्कार। |
| अनिश्चयार्थक | होला, कि क्या हो | ऊ आउँछ **होला**। |
| विनयार्थक | न, है, ल | यता आऊ **न**। |

::: tip निपात चिन्ने जाँच
**निपात हटाउनुहोस् — वाक्य व्याकरणसम्मत नै रहन्छ, अर्थको जोड मात्र घट्छ।** *रामले नै गर्‍यो* → *रामले गर्‍यो* (ठिकै छ)। तर नामयोगी हटाए वाक्य बिग्रन्छ: *टेबुलमाथि किताब छ* → *टेबुल किताब छ* (बिग्रियो)। यही एउटा जाँचले निपात र नामयोगी छुट्टिन्छ।
:::

```figure caption="पाँच अविकारी पदवर्ग — प्रत्येकले वाक्यमा गर्ने काम।"
matplotlib.rcParams['font.family'] = 'sans-serif'
matplotlib.rcParams['font.sans-serif'] = ['Noto Sans Devanagari', 'Inter', 'DejaVu Sans']
fig, ax = plt.subplots(figsize=(5.1, 3.1))
ax.axis('off')

def box(x, y, txt, w=2.0, h=0.46, fc='white', ec=INK, fs=8.8):
    ax.add_patch(matplotlib.patches.FancyBboxPatch(
        (x - w/2, y - h/2), w, h, boxstyle='round,pad=0.04',
        fc=fc, ec=ec, lw=1.0, zorder=3))
    ax.text(x, y, txt, ha='center', va='center', fontsize=fs, color=INK, zorder=4)

box(2.0, 5.4, 'अविकारी पद (५)', w=2.7, fc='#eef4fb', ec=ACCENT, fs=9.2)
rows = [('नामयोगी', 'नामपछि आई सम्बन्ध देखाउँछ', 'घरभित्र'),
        ('क्रियायोगी', 'क्रियाको विशेषता बताउँछ', 'बिस्तारै हिँड्यो'),
        ('संयोजक', 'दुई पद वा वाक्य जोड्छ', 'राम र सीता'),
        ('विस्मयादिबोधक', 'अचानकको भाव जनाउँछ', 'वाह !'),
        ('निपात', 'अर्थमा जोड थप्छ', 'रामले नै')]
for i, (name, work, ex) in enumerate(rows):
    yy = 4.55 - i * 0.82
    ax.plot([0.75, 1.02], [yy, yy], color=MUTED, lw=0.9, zorder=1)
    box(2.05, yy, name, w=2.05)
    ax.text(3.30, yy, work, ha='left', va='center', fontsize=8.3, color=MUTED)
    ax.text(3.30, yy - 0.30, ex, ha='left', va='center', fontsize=8.1, color=ACCENT)
ax.plot([0.75, 0.75], [5.17, 4.55 - 4 * 0.82], color=MUTED, lw=0.9, zorder=1)
ax.set_xlim(0.3, 8.6)
ax.set_ylim(0.85, 5.75)
```

## 16.6 शब्द रूपायन

::: definition रूपायन
वाक्यमा प्रयोग हुँदा लिङ्ग, वचन, पुरुष, आदर, विभक्ति, काल वा पक्षअनुसार शब्दको रूप फेरिने प्रक्रियालाई रूपायन भनिन्छ। रूप फेर्ने पद विकारी, नफेर्ने अविकारी।
:::

### नामको रूपायन — विभक्ति तालिका

| कारक | विभक्ति | उदाहरण (*राम*) | उदाहरण (*घर*) |
|---|---|---|---|
| कर्ता | ले / ० | रामले, राम | घरले, घर |
| कर्म | लाई / ० | रामलाई | घर |
| करण | ले, द्वारा | रामद्वारा | घरले |
| सम्प्रदान | लाई, का लागि | रामलाई, रामका लागि | घरका लागि |
| अपादान | बाट, देखि | रामबाट | घरबाट |
| सम्बन्ध | को, का, की | रामको, रामका, रामकी | घरको |
| अधिकरण | मा, तिर | राममा | घरमा |
| सम्बोधन | ए, हे, ओ | हे राम ! | — |

### सर्वनामको रूपायन

```figure caption="एउटै सर्वनाम *म* विभक्तिअनुसार कसरी रूप फेर्छ — रूपायनको नमुना।"
matplotlib.rcParams['font.family'] = 'sans-serif'
matplotlib.rcParams['font.sans-serif'] = ['Noto Sans Devanagari', 'Inter', 'DejaVu Sans']
fig, ax = plt.subplots(figsize=(4.8, 3.2))
ax.axis('off')

cx, cy, R = 0.0, 0.0, 1.0
ax.add_patch(plt.Circle((cx, cy), 0.42, fc='#eef4fb', ec=ACCENT, lw=1.4, zorder=4))
ax.text(cx, cy, 'म', ha='center', va='center', fontsize=14, color=INK, zorder=5)

spokes = [(90, 'मैले', 'कर्ता  + ले'),
          (150, 'मलाई', 'कर्म  + लाई'),
          (210, 'मबाट', 'अपादान  + बाट'),
          (270, 'मेरो', 'सम्बन्ध  + को'),
          (330, 'ममा', 'अधिकरण  + मा'),
          (30, 'मसँग', 'सहार्थ  + सँग')]
for ang, word, tag in spokes:
    a = np.deg2rad(ang)
    x1, y1 = cx + 0.46 * np.cos(a), cy + 0.46 * np.sin(a)
    x2, y2 = cx + 1.02 * np.cos(a), cy + 1.02 * np.sin(a)
    ax.annotate('', xy=(x2, y2), xytext=(x1, y1),
                arrowprops=dict(arrowstyle='-|>', color=MUTED, lw=1.0))
    xl, yl = cx + 1.42 * np.cos(a), cy + 1.42 * np.sin(a)
    ax.text(xl, yl + 0.07, word, ha='center', va='center', fontsize=10.2, color=INK)
    ax.text(xl, yl - 0.20, tag, ha='center', va='center', fontsize=7.8, color=MUTED)
ax.set_xlim(-2.35, 2.35)
ax.set_ylim(-2.00, 1.95)
```

| सर्वनाम | कर्ता (+ले) | कर्म (+लाई) | सम्बन्ध (+को) | अधिकरण (+मा) |
|---|---|---|---|---|
| म | मैले | मलाई | मेरो | ममा |
| हामी | हामीले | हामीलाई | हाम्रो | हामीमा |
| तँ | तैँले | तँलाई | तेरो | तँमा |
| तिमी | तिमीले | तिमीलाई | तिम्रो | तिमीमा |
| तपाईं | तपाईंले | तपाईंलाई | तपाईंको | तपाईंमा |
| ऊ | उसले | उसलाई | उसको | उसमा |
| उनी | उनले | उनलाई | उनको | उनमा |
| यो | यसले | यसलाई | यसको | यसमा |
| त्यो | त्यसले | त्यसलाई | त्यसको | त्यसमा |
| को | कसले | कसलाई | कसको | कसमा |

**ध्यान दिनुहोस्** — *म → मैले*, *ऊ → उसले*, *यो → यसले* मा मूल शब्द नै बदलिन्छ। यसलाई **अनियमित रूपायन** भनिन्छ र यही ठाउँमा गल्ती हुन्छ (*म ले* वा *ऊ ले* अशुद्ध)।

### विशेषण र क्रियापदको रूपायन

| पद | रूपायनको आधार | नमुना |
|---|---|---|
| विशेषण (*-ओ* अन्त्य) | लिङ्ग, वचन | राम्रो केटो, राम्री केटी, राम्रा केटाहरू |
| विशेषण (अन्य) | फेरिँदैन | मेहनती केटो, मेहनती केटी |
| क्रियापद | पुरुष, लिङ्ग, वचन, आदर, काल, पक्ष | गएँ, गयौ, गयो, गइन्, जानुभयो |

### आदरको रूपायन

नेपालीमा आदर क्रियापदको पुच्छरमा देखिन्छ। एउटै धातु *आउनु* को चार तह हेर्नुहोस् — यो तालिका "शुद्ध गरी लेख्नुहोस्" भन्ने प्रश्नमा सिधै काम लाग्छ।

| तह | सर्वनाम | वर्तमान | भूत | आज्ञा |
|---|---|---|---|---|
| निम्न | तँ | आउँछस् | आइस् | आइज |
| सामान्य | तिमी | आउँछौ | आयौ | आऊ |
| आदरार्थी | तपाईं | आउनुहुन्छ | आउनुभयो | आउनुहोस् |
| उच्च आदरार्थी | हजुर | आउनुहुन्छ | आउनुभयो | आइबक्सियोस् |

नियम एउटै हो — **जुन तहको सर्वनाम, त्यही तहको क्रियापद।** सर्वनाम लुकेको वाक्यमा पनि यो मिलान अनिवार्य छ: *गुरु कक्षामा आउनुभयो* (*गुरु कक्षामा आयो* अशुद्ध)।

::: example पदवर्ग पहिचान — मिश्रित वाक्य
**प्रश्न.** "अहो ! दसैँपछि पनि पोखरामा पानी बिस्तारै पर्‍यो, तर बाटो बन्द भएन।" — प्रत्येक अविकारी पदको पदवर्ग र भेद लेख्नुहोस्।

**समाधान.**

| पद | पदवर्ग | भेद | कारण |
|---|---|---|---|
| अहो | विस्मयादिबोधक | आश्चर्य | अचानकको भाव, ! सँगै आयो |
| पछि | नामयोगी | कालवाचक | *दसैँ* नामपछि आएर समय देखायो |
| पनि | निपात | बलदायक | हटाए पनि वाक्य ठिकै रहन्छ |
| बिस्तारै | क्रियायोगी | रीतिवाचक | "कसरी पर्‍यो?" को जवाफ |
| तर | संयोजक | विरोधवाचक | दुई वाक्य जोड्दै विरोध देखायो |
:::

::: example रूपायन चरणबद्ध
**प्रश्न.** "………… (ऊ) ………… (म) किताब दियो।" — कोष्ठकका सर्वनामको उपयुक्त रूपायन गर्नुहोस्।

**समाधान.**
१. **कर्ता पहिचान.** *ऊ* कर्ता हो; *दियो* सकर्मक क्रियापदको भूतकाल हो → कर्तामा *ले* अनिवार्य।
२. **अनियमित रूप लगाउने.** *ऊ + ले* = *उसले* (*ऊले* होइन)।
३. **सम्प्रदान पहिचान.** *म* लाई किताब दिइयो → *म + लाई* = *मलाई*।
४. **पदसङ्गति जाँच.** कर्ता तृतीय पुरुष एकवचन, क्रियापद *दियो* — मिल्यो।

**उत्तर.** उसले मलाई किताब दियो।
:::

::: example निपात कि नामयोगी?
**प्रश्न.** "ऊ काठमाडौँसम्म गयो" र "उसले दुई घण्टासम्म पर्खियो" — दुवैमा *सम्म* को पदवर्ग एउटै हो?

**समाधान.**
१. पहिलो वाक्यबाट *सम्म* हटाऔँ — *ऊ काठमाडौँ गयो*। वाक्य ठिकै छ, तर "कहाँसम्म" भन्ने सीमा हरायो; *सम्म* ले नाम *काठमाडौँ* सँग सम्बन्ध देखाइरहेको छ → **नामयोगी**।
२. दोस्रो वाक्यबाट हटाऔँ — *उसले दुई घण्टा पर्खियो*। अर्थ उस्तै रह्यो, जोड मात्र घट्यो → यहाँ *सम्म* **निपात** (बलदायक) हो।

**निष्कर्ष.** एउटै शब्द फरक वाक्यमा फरक पदवर्गको हुन सक्छ। पदवर्ग शब्दको होइन, **वाक्यमा त्यसले गर्ने कामको** नाम हो।
:::

::: caution विद्यार्थीले गर्ने वास्तविक गल्ती
- **विशेषण र क्रियायोगी साटिने।** *राम्रो* विशेषण (राम्रो केटो), *राम्ररी* क्रियायोगी (राम्ररी पढ्यो)।
- **नामयोगीलाई विभक्ति भन्ने।** *लाई, ले, को, मा* विभक्ति; *लागि, सम्म, भन्दा, सँग* नामयोगी।
- **सर्वनामको अनियमित रूप बिर्सिने।** *ऊले, योले, कोले* अशुद्ध; *उसले, यसले, कसले* शुद्ध।
- **तिम्रो/तपाईंको साटिने।** *तिमी → तिम्रो*, तर *तपाईं → तपाईंको* (तपाईंंको होइन)।
- **विस्मयादिबोधकपछि चिह्न नलगाउने।** *वाह !* मा चिह्न अनिवार्य छ।
:::

## पाठको सार

- अविकारी पदवर्ग पाँच: नामयोगी, क्रियायोगी, संयोजक, विस्मयादिबोधक, निपात। यी रूप फेर्दैनन्।
- नामयोगी नामपछि आएर सम्बन्ध देखाउँछ; हटाए वाक्य बिग्रन्छ।
- क्रियायोगीले क्रियाको कहिले–कहाँ–कसरी–कति बताउँछ।
- संयोजकले दुई पद वा वाक्य जोड्छ; विस्मयादिबोधकले अचानकको भाव जनाउँछ।
- निपातले अर्थमा जोड थप्छ; हटाए पनि वाक्य व्याकरणसम्मत रहन्छ — यही छुट्याउने जाँच हो।
- रूपायन भनेको लिङ्ग, वचन, पुरुष, आदर, विभक्ति, काल र पक्षअनुसार शब्दको रूप फेरिनु हो।
- अनियमित रूपायन सम्झनैपर्छ: म → मैले, ऊ → उसले, यो → यसले, को → कसले।

## अभ्यास

**रेखाङ्कित पदको पदवर्ग र भेद लेख्नुहोस् (१ अङ्क)**

1. किताब टेबुल**माथि** छ। <span class="marks">[1]</span>
2. ऊ **बिस्तारै** हिँड्यो। <span class="marks">[1]</span>
3. राम **र** सीता विद्यालय गए। <span class="marks">[1]</span>
4. **वाह !** कस्तो राम्रो रारा ताल। <span class="marks">[1]</span>
5. उसले **नै** काम सिध्यायो। <span class="marks">[1]</span>
6. ऊ आएन, **किनभने** बाटो बन्द थियो। <span class="marks">[1]</span>
7. विद्यार्थीका**लागि** रु. ५०० छात्रवृत्ति छ। <span class="marks">[1]</span>

::: note उत्तर
**१.** नामयोगी, स्थानवाचक — नाम *टेबुल* पछि आई ठाउँ देखायो।
**२.** क्रियायोगी, रीतिवाचक — "कसरी हिँड्यो?" को जवाफ।
**३.** संयोजक, संयोजक (जोड्ने) — दुई नाम जोड्यो।
**४.** विस्मयादिबोधक, हर्ष — अचानकको खुसी जनायो।
**५.** निपात, बलदायक — हटाए पनि वाक्य ठिकै रहन्छ, जोड मात्र घट्छ।
**६.** संयोजक, कारणवाचक — कारण देखाउँदै दुई वाक्य जोड्यो।
**७.** नामयोगी, निमित्तवाचक — कसका निम्ति भन्ने देखायो।
:::

**उपयुक्त रूपायन गरी खाली ठाउँ भर्नुहोस् (१ अङ्क)**

8. ………… (ऊ) चिठी लेख्यो। <span class="marks">[1]</span>
9. ………… (यो) मूल्य कति हो? <span class="marks">[1]</span>
10. ………… (को) यो काम गर्‍यो? <span class="marks">[1]</span>
11. ………… (तिमी) किताब यहीँ छ। <span class="marks">[1]</span>
12. ………… (म) एउटा कुरा भन्नु छ। <span class="marks">[1]</span>

::: note उत्तर
**८.** उसले — सकर्मक भूतकाल भएकाले कर्तामा *ले*; *ऊ* को अनियमित रूप *उस्*।
**९.** यसको — *यो* को सम्बन्ध विभक्ति रूप।
**१०.** कसले — *को* को कर्ता रूप।
**११.** तिम्रो — *तिमी* को सम्बन्ध रूप।
**१२.** मलाई — कामको भोक्ता जनाउन *लाई*।
:::

**शुद्ध गरी लेख्नुहोस् (१ अङ्क)**

13. ऊले मलाई सहयोग गर्‍यो। <span class="marks">[1]</span>
14. यो को मूल्य धेरै छ। <span class="marks">[1]</span>
15. ऊ राम्रो गाउँछ। <span class="marks">[1]</span>
16. तिमी को किताब हरायो। <span class="marks">[1]</span>

::: note उत्तर
**१३.** उसले मलाई सहयोग गर्‍यो। — *ऊ + ले = उसले*, *ऊले* होइन।
**१४.** यसको मूल्य धेरै छ। — *यो + को = यसको*।
**१५.** ऊ राम्ररी गाउँछ। — क्रियाको विशेषता बताउन विशेषण होइन, क्रियायोगी चाहिन्छ।
**१६.** तिम्रो किताब हरायो। — *तिमी + को = तिम्रो*।
:::

**खाली ठाउँ भर्नुहोस् (१ अङ्क)**

17. रूप नफेर्ने पदवर्गलाई ………… पदवर्ग भनिन्छ। <span class="marks">[1]</span>
18. *यदि… भने* ………… संयोजक हो। <span class="marks">[1]</span>
19. वाक्यबाट हटाउँदा पनि वाक्य व्याकरणसम्मत रहने सानो पदलाई ………… भनिन्छ। <span class="marks">[1]</span>

::: note उत्तर
**१७.** अविकारी — यी लिङ्ग, वचन, विभक्तिअनुसार बदलिँदैनन्।
**१८.** सर्तवाचक — सर्त राखेर दुई वाक्य जोड्छ।
**१९.** निपात — यसले अर्थमा जोड मात्र थप्छ।
:::

**छोटो उत्तर दिनुहोस् (३ अङ्क)**

20. नामयोगी र विभक्तिबिचको भिन्नता उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
21. निपातका तीन भेद उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
22. रूपायन भनेको के हो? नाम, सर्वनाम र क्रियापद — तीनैको एक-एक उदाहरण दिनुहोस्। <span class="marks">[3]</span>
23. संयोजकका कुनै तीन भेद वाक्यसहित लेख्नुहोस्। <span class="marks">[3]</span>

::: note उत्तर
**२०.** विभक्ति नामसँग टाँसिन्छ र प्रायः नामको रूप नै बदल्छ (*ऊ → उसले*, *राम → रामलाई*); नामयोगी छुट्टै शब्द हो र नामपछि थपिन्छ (*रामका लागि*, *घरभन्दा*)। विभक्ति सीमित छन् (ले, लाई, को, मा, बाट), नामयोगी धेरै छन्।
**२१.** बलदायक — *रामले नै गर्‍यो*; स्वीकारार्थक — *हो, म जान्छु*; प्रश्नार्थक — *तिमी जान्छौ कि ?*
**२२.** वाक्यमा प्रयोग हुँदा लिङ्ग, वचन, पुरुष, आदर, विभक्ति, काल वा पक्षअनुसार शब्दको रूप फेरिने प्रक्रिया रूपायन हो। नाम — *केटो → केटी → केटाहरू*; सर्वनाम — *म → मैले → मलाई*; क्रियापद — *गयो → गइन् → जानुभयो*।
**२३.** संयोजक (जोड्ने) — *राम र सीता आए*; विरोधवाचक — *ऊ पढ्यो, तर उत्तीर्ण भएन*; परिणामवाचक — *बाटो बन्द थियो, त्यसैले ढिलो भयो*।
:::
