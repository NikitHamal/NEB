शब्दनिर्माणको दोस्रो र सबैभन्दा उपयोगी प्रक्रिया **प्रत्यय** हो। नेपालीका हजारौँ शब्द प्रत्ययबाटै बनेका छन् — *लेख्* धातुबाट *लेखक, लेखन, लेखाइ, लेख्ने*; *सुन्दर* बाट *सुन्दरता*। शब्दनिर्माणका ४ अङ्कमध्ये प्रायः दुई अङ्क प्रत्ययबाटै आउँछ। यहाँ प्रत्ययका दुई ठुला वर्ग — **कृत्** र **तद्धित** — छुट्टाछुट्टै हेरिन्छ।

::: definition प्रत्यय
शब्द वा धातुको **पछाडि** जोडिएर नयाँ शब्द बनाउने शब्दांशलाई प्रत्यय भनिन्छ। धातुमा लाग्ने प्रत्यय **कृत्**, र नाम–विशेषण–सर्वनाममा लाग्ने प्रत्यय **तद्धित** हो।
:::

## 20.1 प्रत्ययका दुई काम

प्रत्ययका दुई फरक भूमिका छुट्याउनुहोस्:

| भूमिका | के गर्छ | उदाहरण |
|---|---|---|
| **व्युत्पादक** (शब्दनिर्माणी) | नयाँ शब्द नै बनाउँछ | लेख् + अक = **लेखक** (नयाँ नाम) |
| **रूपायनी** (विभक्ति) | शब्द उही, रूप मात्र फेर्छ | केटा + हरू = केटाहरू; राम + ले |

यो एकाइमा **व्युत्पादक प्रत्यय** मात्र पढिन्छ। *हरू, ले, लाई, को, मा* प्रत्यय हुँदाहुँदै पनि शब्दनिर्माणी होइनन् — तिनले नयाँ शब्द बनाउँदैनन्, पदको रूप मात्र फेर्छन्।

## 20.2 कृत् प्रत्यय

**धातु** (क्रियाको मूल रूप) मा लाग्ने प्रत्यय कृत् हो। यसबाट बनेको शब्द **कृदन्त** कहलिन्छ।

| कृत् प्रत्यय | अर्थ/काम | उदाहरण |
|---|---|---|
| -नु | क्रियानाम बनाउने | गर्नु, खानु, पढ्नु, हिँड्नु |
| -न | उद्देश्यबोधक क्रियानाम | गर्न, खान, सुत्न, पढ्न |
| -ने | कर्तृवाचक विशेषण/नाम | गर्ने, लेख्ने, पढ्ने, गाउने |
| -आइ | भाववाचक नाम | पढाइ, लेखाइ, हिँडाइ, बोलाइ |
| -एको | पूर्ण कृदन्त | गरेको, खाएको, भनेको |
| -एर / -ई | पूर्वकालिक क्रिया | गरेर, खाएर, हेरी, गरी |
| -दै | अपूर्ण कृदन्त | गर्दै, खाँदै, हाँस्दै |
| -उवा | कर्ता/स्वभाव जनाउने | खनुवा, डसुवा, पिउवा |
| -आहा | स्वभाव जनाउने | लोभाहा, रिसाहा, झगडाहा |
| -अक | कर्तृवाचक (तत्सम) | लेखक, पाठक, गायक, नायक, दर्शक |
| -अन | भाववाचक (तत्सम) | लेखन, पठन, गमन, दर्शन, भोजन |
| -तव्य | गर्नुपर्ने अर्थ (तत्सम) | कर्तव्य, गन्तव्य, वक्तव्य |
| -ति | भाववाचक (तत्सम) | गति, मति, शक्ति, भक्ति |
| -आलु | स्वभाववाचक विशेषण | सिपालु, निद्रालु, कृपालु |

::: key कृदन्तका चार अर्थभेद
- **कर्तृवाचक** — काम गर्ने व्यक्ति: लेख + अक = **लेखक**, गाउ + ने = **गाउने**।
- **कर्मवाचक** — काम भोग्ने वस्तु: खा + ने = **खाने** (कुरा), पढ् + ने = **पढ्ने** (पुस्तक)।
- **भाववाचक** — काम आफैँ: पढ् + आइ = **पढाइ**, लेख् + अन = **लेखन**।
- **करणवाचक** — काम गर्ने साधन: कोर् + नी = **कोरनी**, बस् + नी = **बस्नी**।
:::

## 20.5 कृत् र तद्धित छुट्याउने विधि

प्रत्यय हटाएपछि बाँकी रहेको आधारमा **-नु** जोडेर हेर्नुहोस्:

- *लेखक* → *लेख* → **लेख्नु** भन्न मिल्छ → आधार धातु हो → **कृत्**।
- *सुन्दरता* → *सुन्दर* → *सुन्दर्नु* भन्न मिल्दैन → आधार विशेषण हो → **तद्धित**।

### प्रत्यय लाग्दा आधारमा हुने परिवर्तन

प्रत्यय जोडिँदा आधार शब्दको रूप पनि फेरिन सक्छ। रूप फेरिए पनि आधार त्यही हो भन्ने बिर्सनु हुँदैन।

| आधार | प्रत्यय | बनेको शब्द | आधारमा के भयो |
|---|---|---|---|
| गाउनु (गै) | -अक | गायक | *ऐ* को *आय्* भयो |
| लामो | -आइ | लम्बाइ | *लामो* को *लम्ब* भयो |
| मिठो | -आस | मिठास | *मिठो* को *मिठ* भयो |
| बुढो | -एसकाल | बुढेसकाल | *ओ* को *ए* भयो |
| हिँड्नु | -आइ | हिँडाइ | धातु यथावत् |
| दृश् | -अन | दर्शन | *दृश्* को *दर्श* भयो |

### अर्थअनुसार तद्धितका भेद

| भेद | अर्थ | उदाहरण |
|---|---|---|
| भाववाचक | गुण वा भाव जनाउने | सुन्दरता, बुढोपन, महत्त्व |
| सम्बन्धवाचक | कुनै वस्तुसँग जोडिएको | सामाजिक, नेपाली, पहाडी |
| युक्तवाचक | भएको, राख्ने | धनवान्, बुद्धिमान्, इमानदार |
| स्त्रीवाचक | स्त्रीलिङ्ग जनाउने | बालिका, लेखिका, बाघिनी |
| ऊनवाचक | सानो वा प्रिय जनाउने | छोरी, बाबु, नानी |
| क्रमवाचक | क्रम जनाउने | पाँचौँ, दसौँ, बीसौँ |

::: memory नु-जाँच
प्रत्यय हटाएर बाँकी भागमा **नु** जोड्नुहोस्। क्रिया बन्यो भने **कृत्**, बनेन भने **तद्धित**। यो एउटै जाँचले परीक्षाको प्रायः हरेक प्रश्न छुट्याइदिन्छ।
:::

::: example प्रत्यय छुट्याउने चरणबद्ध विधि
**प्रश्न.** *पढाइ*, *धनी*, *गायक*, *बुढोपन* — प्रत्यय छुट्याई कृत् कि तद्धित भन्नुहोस्।

**समाधान.**
१. **प्रत्यय हटाउने.**
२. **आधारमा *नु* जोडेर जाँच्ने.**
३. **वर्ग तोक्ने र अर्थ लेख्ने.**

| शब्द | प्रत्यय | आधार | नु-जाँच | वर्ग |
|---|---|---|---|---|
| पढाइ | -आइ | पढ् | पढ्नु ✔ | कृत् (भाववाचक) |
| धनी | -ई | धन | धन्नु ✘ | तद्धित (युक्त अर्थ) |
| गायक | -अक | गै/गा | गाउनु ✔ | कृत् (कर्तृवाचक) |
| बुढोपन | -पन | बुढो | बुढ्नु ✘ | तद्धित (भाववाचक) |
:::

::: example एउटै धातुबाट धेरै शब्द
**प्रश्न.** *लेख्* धातुबाट कृत् प्रत्यय लगाई छ शब्द बनाई अर्थ लेख्नुहोस्।

**समाधान.**

| शब्द | प्रत्यय | अर्थ |
|---|---|---|
| लेखक | -अक | लेख्ने व्यक्ति (कर्तृवाचक) |
| लेखन | -अन | लेख्ने काम (भाववाचक) |
| लेखाइ | -आइ | लेख्ने तरिका (भाववाचक) |
| लेख्ने | -ने | लेख्ने (विशेषण/नाम) |
| लेखिका | -इका | महिला लेखक (स्त्रीवाचक) |
| लेखनी | -नी | लेख्ने साधन (करणवाचक) |

**टिप्पणी.** *लेखिका* मा दुई प्रत्यय क्रमशः लागेका छन् — पहिले *लेख् + अक = लेखक* (कृत्), त्यसपछि *लेखक + इका* (तद्धित)। यसरी एउटै शब्दमा कृत् र तद्धित दुवै हुन सक्छन्।
:::

::: example एउटै प्रत्यय, दुई वर्ग
**प्रश्न.** *पढाइ* र *लम्बाइ* दुवैमा *-आइ* छ। दुवै एउटै वर्गका हुन्?

**समाधान.**
१. *पढाइ* → आधार *पढ्* → *पढ्नु* भन्न मिल्छ → धातु → **कृत् प्रत्यय**।
२. *लम्बाइ* → आधार *लामो/लम्ब* → *लम्बनु* भन्न मिल्दैन → विशेषण → **तद्धित प्रत्यय**।
३. **निष्कर्ष.** प्रत्यय उही भए पनि वर्ग आधारले तय गर्छ, प्रत्ययले होइन। त्यसैले उत्तरमा सधैँ आधार देखाउनुहोस् — *पढाइ = पढ् (धातु) + आइ*।
:::

::: caution विद्यार्थीले गर्ने वास्तविक गल्ती
- **विभक्तिलाई शब्दनिर्माणी प्रत्यय भन्ने।** *केटाहरू*, *रामले*, *घरमा* मा नयाँ शब्द बनेको छैन — यी रूपायन हुन्, शब्दनिर्माण होइन।
- **प्रत्यय लाग्दा आधारको रूप फेरिएको नचिन्ने।** *गाउनु → गायक*, *लामो → लम्बाइ*, *मिठो → मिठास*। रूप फेरिए पनि आधार त्यही हो।
- **कृत् र तद्धित साटिने।** *-आइ*, *-आलु*, *-नी* तीनै वर्गमा भेटिन्छन्; नु-जाँच नगरी अनुमान नलगाउनुहोस्।
- **उपसर्ग र प्रत्यय एउटै ठान्ने।** *अपमान* उपसर्गयुक्त हो, *मानव* प्रत्ययका लागि होइन; *अपमानित* मा दुवै छन् — *अप* (उपसर्ग) + *मान* + *इत* (प्रत्यय)।
- **तत्सम प्रत्यय नेपाली शब्दमा जोड्ने।** *बुढोता*, *ठुलोत्व* चल्दैन; *बुढोपन*, *ठुलोपन* चल्छ। तत्सम प्रत्यय तत्सम आधारसँग मात्र।
:::

::: tip परीक्षामा छोटोमा पूरा अङ्क
"प्रत्यय छुट्याउनुहोस्" भन्ने प्रश्नमा **तीन कुरा** लेख्नुहोस् — आधार, प्रत्यय, वर्ग। जस्तै: *सुन्दरता = सुन्दर (विशेषण) + ता, तद्धित।* तीनैमध्ये एउटा छुटे अङ्क काटिन्छ। "शब्द बनाउनुहोस्" भन्ने प्रश्नमा विग्रहसहित लेख्नुहोस्।
:::

## पाठको सार

- प्रत्यय शब्दको पछाडि जोडिन्छ; उपसर्ग अगाडि।
- व्युत्पादक प्रत्ययले नयाँ शब्द बनाउँछ, रूपायनी प्रत्यय (हरू, ले, लाई) ले रूप मात्र फेर्छ।
- **कृत् प्रत्यय** धातुमा लाग्छ — नु, न, ने, आइ, एको, एर, अक, अन, तव्य, आलु।
- कृदन्तका चार अर्थभेद: कर्तृवाचक, कर्मवाचक, भाववाचक, करणवाचक।
- **तद्धित प्रत्यय** नाम–विशेषण–सर्वनाममा लाग्छ — ता, त्व, पन, इलो, इक, ई, वान्, इका।
- आगन्तुक प्रत्यय: दार, खोर, बाज, गिरी, वाला, ची, इस्ट।
- छुट्याउने उपाय — **नु-जाँच**: आधारमा *नु* लागे कृत्, नलागे तद्धित।

**खाली ठाउँ भर्नुहोस् (१ अङ्क)**

15. धातुमा लाग्ने प्रत्ययलाई ………… भनिन्छ। <span class="marks">[1]</span>
16. *बुढोपन* मा ………… प्रत्यय छ। <span class="marks">[1]</span>
17. *घुसखोर* को *-खोर* ………… भाषाबाट आएको प्रत्यय हो। <span class="marks">[1]</span>
18. कृत् प्रत्यय लागेर बनेको शब्दलाई ………… भनिन्छ। <span class="marks">[1]</span>

::: note उत्तर
**१५.** कृत् प्रत्यय — नाम-विशेषणमा लागे तद्धित हुन्थ्यो।
**१६.** -पन — नेपाली भाववाचक तद्धित प्रत्यय।
**१७.** फारसी — *-दार*, *-बाज*, *-गिरी* पनि फारसी नै हुन्।
**१८.** कृदन्त — तद्धित लागेकोलाई तद्धितान्त भनिन्छ।
:::

**छोटो उत्तर दिनुहोस् (३ अङ्क)**

19. कृत् र तद्धित प्रत्ययबिचको भिन्नता दुई-दुई उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
20. कृदन्तका चार अर्थभेद उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
21. *लेख्* धातुबाट पाँच शब्द बनाई प्रत्यय देखाउनुहोस्। <span class="marks">[3]</span>
22. व्युत्पादक र रूपायनी प्रत्ययको भिन्नता उदाहरणसहित स्पष्ट पार्नुहोस्। <span class="marks">[3]</span>
23. *पढाइ* र *चौडाइ* मा एउटै प्रत्यय हुँदाहुँदै वर्ग फरक किन? <span class="marks">[3]</span>
24. आगन्तुक प्रत्यय लागेका चार शब्द बनाई स्रोत भाषा लेख्नुहोस्। <span class="marks">[3]</span>
25. तल दिइएको अनुच्छेदबाट प्रत्यययुक्त चार शब्द टिपी विग्रह गर्नुहोस् — *पोखराका विद्यार्थीको पढाइ राम्रो छ। तिनीहरूको लेखनमा सरलता र सामाजिक चेतना देखिन्छ।* <span class="marks">[3]</span>
26. कृत् र तद्धित दुवै प्रत्यय लागेका दुई शब्द देखाई क्रम स्पष्ट पार्नुहोस्। <span class="marks">[3]</span>

::: note उत्तर
**१९.** कृत् धातुमा लाग्छ — *पढ् + आइ = पढाइ*, *लेख् + अक = लेखक*। तद्धित नाम–विशेषणमा लाग्छ — *सुन्दर + ता = सुन्दरता*, *रस + इलो = रसिलो*। छुट्याउने उपाय नु-जाँच हो।
**२०.** कर्तृवाचक — लेखक (लेख्ने व्यक्ति); कर्मवाचक — खाने (खाइने कुरा); भाववाचक — लेखाइ (लेख्ने काम); करणवाचक — लेखनी (लेख्ने साधन)।
**२१.** लेखक (-अक), लेखन (-अन), लेखाइ (-आइ), लेख्ने (-ने), लेखनी (-नी)।
**२२.** व्युत्पादकले नयाँ शब्द बनाउँछ — *लेख् + अक = लेखक*, अब यो नयाँ नाम हो। रूपायनीले रूप मात्र फेर्छ — *लेखक + हरू = लेखकहरू*, शब्द उही रह्यो। शब्दकोशमा *लेखक* छ, *लेखकहरू* छैन।
**२३.** प्रत्ययले होइन, आधारले वर्ग तय गर्छ। *पढाइ* को आधार *पढ्* धातु हो (*पढ्नु* बन्छ) → कृत्। *चौडाइ* को आधार *चौडा* विशेषण हो (*चौड्नु* बन्दैन) → तद्धित।
**२४.** इमानदार (फारसी), घुसखोर (फारसी), दादागिरी (फारसी), टाइपिस्ट (अङ्ग्रेजी)।
**२५.** पढाइ = पढ् + आइ (कृत्); लेखन = लेख् + अन (कृत्); सरलता = सरल + ता (तद्धित); सामाजिक = समाज + इक (तद्धित)।
**२६.** *लेखिका* = लेख् + अक (कृत्) + इका (तद्धित); *दर्शनीय* = दृश् + अन (कृत्) + ईय (तद्धित)। क्रम सधैँ कृत् पहिले, तद्धित पछि — किनभने तद्धित नामैमा मात्र लाग्छ, र नाम कृत्ले बनाउँछ।
:::

**थप छोटो उत्तर (३ अङ्क)**

31. तद्धित प्रत्ययका कुनै चार अर्थभेद उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
32. प्रत्यय जोडिँदा आधार शब्दको रूप फेरिने तीन उदाहरण देखाई के फेरियो लेख्नुहोस्। <span class="marks">[3]</span>

::: note उत्तर
**३१.** भाववाचक — सुन्दरता (गुण जनायो); सम्बन्धवाचक — सामाजिक (समाजसँग जोडियो); युक्तवाचक — बुद्धिमान् (बुद्धि भएको); स्त्रीवाचक — लेखिका (स्त्रीलिङ्ग जनायो)।
**३२.** गाउनु + अक = गायक (*ऐ* को *आय्*); लामो + आइ = लम्बाइ (*लामो* को *लम्ब*); मिठो + आस = मिठास (*ओ* लोप भयो)। रूप फेरिए पनि आधार उही मानिन्छ।
:::
