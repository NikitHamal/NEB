वाक्यमा प्रयोग भएको शब्दलाई **पद** भनिन्छ, र पदहरूलाई काम अनुसार छुट्याएर बनाइएको समूहलाई **पदवर्ग** भनिन्छ। नेपालीमा नौ पदवर्ग छन्। यीमध्ये चार — नाम, सर्वनाम, विशेषण र क्रियापद — रूप फेर्ने भएकाले **विकारी** भनिन्छन्, र यही एकाइको विषय हुन्। परीक्षामा **पदवर्ग पहिचान**बाट २ अङ्क र **काल–पक्ष–भाव–वाच्य**बाट ५ अङ्क आउँछ; क्रियापदको भाग यी दुवैको जग हो।

::: key परीक्षाको प्रश्न कसरी आउँछ
"रेखाङ्कित पदको पदवर्ग पहिचान गरी भेद लेख्नुहोस्" — एउटा वाक्य दिइन्छ, दुई-तीन पद रेखाङ्कित हुन्छन्। पदवर्ग मात्र नलेख्नुहोस्, **भेद पनि लेख्नुहोस्** — "नाम, व्यक्तिवाचक", "विशेषण, गुणवाचक"। भेद नलेखे आधा अङ्क जान्छ।
:::

## 15.2 नाम

::: definition नाम
कुनै प्राणी, वस्तु, स्थान, गुण वा भावको नाम जनाउने पदलाई नाम (संज्ञा) भनिन्छ।
:::

| भेद | के जनाउँछ | उदाहरण |
|---|---|---|
| व्यक्तिवाचक | एउटै निश्चित व्यक्ति/स्थान/वस्तु | काठमाडौँ, कोशी, भानुभक्त, सगरमाथा |
| जातिवाचक | पूरै जाति वा वर्ग | विद्यार्थी, नदी, सहर, किताब |
| समूहवाचक | धेरैको एउटै झुन्ड | कक्षा, सेना, बथान, सभा |
| द्रव्यवाचक | नापिने–तौलिने पदार्थ | पानी, सुन, दूध, तेल |
| भाववाचक | छुन नसकिने गुण, भाव, अवस्था | मिठास, बुढ्यौली, स्वतन्त्रता, दसैँको रमाइलो |

**पहिचानको उपाय.** पदको अगाडि *यो/त्यो* वा *एउटा* राख्दा अर्थ मिल्छ भने त्यो नाम हो — *त्यो किताब*, *एउटा सहर*। भाववाचक नाम चिन्न *-पन, -आइ, -त्व, -ता, -आस* जस्ता प्रत्यय खोज्नुहोस् — *मीठो → मिठास*, *पढ्नु → पढाइ*, *मानव → मानवता*।

### नामको रूपायन

नामले लिङ्ग, वचन, आदर र विभक्तिअनुसार रूप फेर्छ। यही रूप फेर्ने प्रक्रियालाई **रूपायन** भनिन्छ।

| आधार | भेद | उदाहरण |
|---|---|---|
| लिङ्ग | पुलिङ्ग | छोरा, राजा, मास्टर, बाहुन |
| | स्त्रीलिङ्ग | छोरी, रानी, मास्टर्नी, बाहुनी |
| | नपुंसक (अप्राणिवाचक) | ढुङ्गा, किताब, घर |
| वचन | एकवचन | विद्यार्थी, केटी |
| | बहुवचन | विद्यार्थीहरू, केटीहरू |
| आदर | सामान्य | केटो, साथी |
| | आदरार्थी | गुरुबा, हजुरबुबा, महोदय |
| विभक्ति | कर्ता (ले/०) | रामले, राम |
| | कर्म–सम्प्रदान (लाई) | रामलाई |
| | करण–अपादान (ले/बाट/देखि) | कलमले, घरबाट |
| | सम्बन्ध (को/का/की) | रामको, रामकी |
| | अधिकरण (मा) | घरमा |

**स्त्रीलिङ्ग बनाउने तीन बाटो:**

| तरिका | पुलिङ्ग → स्त्रीलिङ्ग |
|---|---|
| *-ई/-नी* प्रत्यय | छोरा → छोरी, मास्टर → मास्टर्नी, ठाकुर → ठकुर्नी |
| संस्कृत *-आ/-इका* | छात्र → छात्रा, लेखक → लेखिका, अध्यापक → अध्यापिका |
| छुट्टै शब्द | बुबा → आमा, दाजु → दिदी, राजा → रानी, लोग्ने → स्वास्नी |

**वचनका तीन नियम.** (१) गन्ती वा परिमाण जनाउने शब्द अघि आएमा *-हरू* लगाइँदैन — *तीन विद्यार्थी* (*तीन विद्यार्थीहरू* अशुद्ध)। (२) *सबै, धेरै, अनेक* पछि पनि *-हरू* चाहिँदैन — *सबै विद्यार्थी*। (३) अप्राणिवाचक नाममा *-हरू* प्रायः लगाइँदैन — *घरहरू धेरै छन्* भन्दा *धेरै घर छन्* नै स्वाभाविक नेपाली हो।

## 15.3 सर्वनाम

::: definition सर्वनाम
नामको सट्टामा प्रयोग हुने र नाम दोहोरिनबाट जोगाउने पदलाई सर्वनाम भनिन्छ।
:::

| भेद | उदाहरण | वाक्यमा |
|---|---|---|
| पुरुषवाचक | म, हामी, तँ, तिमी, तपाईं, ऊ, उनी, तिनी, वहाँ | **उनी** पोखराबाट आए। |
| निजवाचक | आफू, आफ्नो, आफै | उसले **आफ्नो** काम गर्‍यो। |
| दर्शक (निश्चयवाचक) | यो, त्यो, यी, ती | **त्यो** किताब मेरो हो। |
| प्रश्नवाचक | को, के, कुन, कति, कहाँ | **को** आयो? |
| सम्बन्धवाचक | जो, जे, जुन, जति | **जो** पढ्छ, उसले जान्दछ। |
| अनिश्चयवाचक | कोही, केही, कुनै | **कोही** आएको छैन। |
| परिमाणवाचक | सबै, धेरै, थोरै, जति | **सबै** विद्यार्थी उपस्थित थिए। |

**पुरुषवाचक सर्वनामको आदरको चार तह** — यो तालिका परीक्षामा सिधै काम लाग्छ:

| पुरुष | निम्न | सामान्य | आदरार्थी | उच्च आदरार्थी |
|---|---|---|---|---|
| प्रथम (बोल्ने) | — | म, हामी | — | — |
| द्वितीय (सुन्ने) | तँ | तिमी | तपाईं | हजुर, यहाँ |
| तृतीय (अरू) | ऊ | उनी, तिनी | वहाँ | मौसुफ |

## 15.4 विशेषण

::: definition विशेषण
नाम वा सर्वनामको गुण, सङ्ख्या, परिमाण वा अवस्था बताउने पदलाई विशेषण भनिन्छ। जसको विशेषता बताइन्छ त्यो पद **विशेष्य** हो।
:::

| भेद | के बताउँछ | उदाहरण |
|---|---|---|
| गुणवाचक | गुण, रङ, स्वभाव, अवस्था | राम्रो, कालो, मेहनती, पुरानो |
| सङ्ख्यावाचक | गन्ती | तीन, पाँचौँ, दोब्बर, थोरै |
| परिमाणवाचक | नाप–तौल | एक किलो, आधा, धेरै, रु. ५०० |
| सार्वनामिक | कुन, यो, त्यो (नामअघि आएर) | **यो** घर, **कुन** बाटो |
| निश्चयवाचक | निश्चित गरी देखाउने | उही मान्छे, त्यही बाटो |

**पहिचानको उपाय.** पदपछि "कस्तो? कति? कुन?" सोध्दा जवाफ आउँछ भने त्यो विशेषण हो — *राम्रो घर* (कस्तो घर? राम्रो)।

::: caution विशेषण कि सर्वनाम?
*यो* र *त्यो* दुवै हुन सक्छन्। **नामको अगाडि आयो भने विशेषण** — *यो किताब मेरो हो*। **एक्लै नामको सट्टामा आयो भने सर्वनाम** — *यो मेरो हो*। परीक्षामा यही ठाउँमा सबैभन्दा धेरै अङ्क गुम्छ।
:::

**विशेषणको अवस्था (तुलना):**

| अवस्था | कसरी बनाइन्छ | उदाहरण |
|---|---|---|
| सामान्य | जस्ताको तस्तै | ठुलो |
| तुलनात्मक | *…भन्दा* + विशेषण | कोशी भन्दा ठुलो |
| उत्तम | *सबैभन्दा* + विशेषण | सबैभन्दा ठुलो |

**विशेषण–विशेष्य सङ्गति.** नेपालीमा विशेषण प्रायः विशेष्यअघि आउँछ र *-ओ* मा टुङ्गिने विशेषणले लिङ्ग–वचन मिलाउँछ: *राम्रो केटो*, *राम्री केटी*, *राम्रा केटाहरू*।

### काल, पक्ष र भाव

क्रियापदले **कहिले** (काल), **कति सकियो** (पक्ष) र **कस्तो मनस्थिति** (भाव) — तीनै सूचना बोक्छ।

| काल | अर्थ | उदाहरण (धातु *गर्*) |
|---|---|---|
| वर्तमान | अहिले | ऊ काम गर्छ। |
| भूत | अघि भइसक्यो | ऊ काम गर्‍यो। |
| भविष्यत् | पछि हुनेछ | ऊ काम गर्नेछ। |

| पक्ष | अर्थ | उदाहरण |
|---|---|---|
| सामान्य | सादा सूचना | ऊ पढ्छ। |
| पूर्ण | काम सकिएको | ऊ पढेको छ। |
| अपूर्ण (सातत्य) | काम चलिरहेको | ऊ पढिरहेको छ। |
| अभ्यस्त | बानी बसेको | ऊ बिहान पढ्ने गर्छ। |

| भाव | अर्थ | उदाहरण |
|---|---|---|
| विध्यर्थ (आज्ञार्थ) | आदेश, अनुरोध | तिमी पढ। |
| सम्भावनार्थ | सम्भावना, शङ्का | ऊ आउला। |
| इच्छार्थ | इच्छा, आशीर्वाद | तपाईंको जय होस्। |
| सङ्केतार्थ | सर्त | ऊ आएको भए म जान्थेँ। |

### कर्ता–क्रिया पदसङ्गति

नेपाली वाक्यमा क्रियापदले कर्ताको **पुरुष, लिङ्ग, वचन र आदर**सँग मिल्नुपर्छ। यो मिलानलाई **पदसङ्गति** भनिन्छ, र परीक्षामा "शुद्ध गरी लेख्नुहोस्" भन्ने प्रश्न प्रायः यहीँबाट आउँछ।

| कर्ता | क्रियारूप (भूतकाल, *जानु*) | नमुना वाक्य |
|---|---|---|
| म | गएँ | म पोखरा गएँ। |
| हामी | गयौँ | हामी पोखरा गयौँ। |
| तँ | गइस् | तँ पोखरा गइस्। |
| तिमी | गयौ | तिमी पोखरा गयौ। |
| तपाईं | जानुभयो | तपाईं पोखरा जानुभयो। |
| ऊ (पु.) | गयो | ऊ पोखरा गयो। |
| उनी (स्त्री.) | गइन् | उनी पोखरा गइन्। |
| वहाँ | जानुभयो | वहाँ पोखरा जानुभयो। |
| उनीहरू | गए | उनीहरू पोखरा गए। |

अर्को अनिवार्य नियम — **सकर्मक क्रियापद भूतकालमा हुँदा कर्तामा *ले* विभक्ति लाग्छ**: *उसले चिठी लेख्यो*, तर अकर्मकमा लाग्दैन: *ऊ हिँड्यो*।

::: example रेखाङ्कित पदको पदवर्ग र भेद
**प्रश्न.** "पोखराका **तीन** **मेहनती** विद्यार्थीले **आफ्नो** परियोजना **बुझाए**।" — रेखाङ्कित पदको पदवर्ग र भेद लेख्नुहोस्।

**समाधान.**
१. *तीन* — विद्यार्थीको गन्ती बताउँछ → **विशेषण, सङ्ख्यावाचक**।
२. *मेहनती* — विद्यार्थीको गुण बताउँछ → **विशेषण, गुणवाचक**।
३. *आफ्नो* — कर्ता आफैँतिर फर्किन्छ → **सर्वनाम, निजवाचक**।
४. *बुझाए* — काम जनाउँछ, वाक्य टुङ्ग्याउँछ → **क्रियापद, सकर्मक** (के बुझाए? परियोजना)।
:::

::: example काल, पक्ष र भाव छुट्याउने
**प्रश्न.** "दिदी दसैँमा काठमाडौँ गइरहनुभएको थियो।" — यस वाक्यको क्रियापदको काल, पक्ष र आदर छुट्याउनुहोस्।

**समाधान.**
१. **काल** — *थियो* सहायक क्रियापदले बितेको समय जनाउँछ → **भूतकाल**।
२. **पक्ष** — *गइरहनु* ले काम चलिरहेको देखाउँछ → **अपूर्ण (सातत्य) पक्ष**।
३. **आदर** — *-नुभएको* आदरार्थी रूप हो → **आदरार्थी**।

**उत्तर.** भूतकाल, अपूर्ण पक्ष, आदरार्थी रूप।
:::

::: example भाववाचक नाम बनाउने
**प्रश्न.** तलका पदबाट भाववाचक नाम बनाउनुहोस् — *मीठो, पढ्नु, मानव, बुढो, मित्र*।

**समाधान.**

| मूल पद | पदवर्ग | प्रत्यय | भाववाचक नाम |
|---|---|---|---|
| मीठो | विशेषण | -आस | मिठास |
| पढ्नु | क्रियापद | -आइ | पढाइ |
| मानव | नाम | -ता | मानवता |
| बुढो | विशेषण | -यौली | बुढ्यौली |
| मित्र | नाम | -ता | मित्रता |

**सूत्र.** भाववाचक नाम नाम, विशेषण वा क्रियापद — तीनै वर्गबाट बन्न सक्छ; बनेपछि भने त्यो सधैँ नाम हुन्छ।
:::

::: caution विद्यार्थीले गर्ने वास्तविक गल्ती
- **भाववाचक नामलाई विशेषण भन्ने।** *मिठास* नाम हो, *मीठो* विशेषण हो।
- **आदरको तह नमिल्नु।** *तपाईं आयौ* अशुद्ध — *तपाईं आउनुभयो* शुद्ध। *तिमी आउनुभयो* पनि अशुद्ध — *तिमी आयौ* शुद्ध।
- **लिङ्ग सङ्गति नमिल्नु।** *राम्रो केटी* अशुद्ध — *राम्री केटी* शुद्ध।
- **कर्ताको *ले* छुटाउने।** सकर्मक क्रियापदको भूतकालमा कर्तामा *ले* लाग्छ — *उसले भात खायो* (*ऊ भात खायो* अशुद्ध)।
- **सकर्मक र अकर्मक साटिने।** "के?" सोध्दा जवाफ आयो भने मात्र सकर्मक।
:::

## पाठको सार

- पदवर्ग नौ वटा: विकारी चार (नाम, सर्वनाम, विशेषण, क्रियापद), अविकारी पाँच।
- नामका पाँच भेद: व्यक्तिवाचक, जातिवाचक, समूहवाचक, द्रव्यवाचक, भाववाचक।
- नामको रूपायन लिङ्ग, वचन, आदर र विभक्तिका आधारमा हुन्छ; बहुवचनमा *-हरू* लाग्छ।
- सर्वनामका सात भेद; पुरुषवाचक सर्वनाममा आदरका चार तह — तँ, तिमी, तपाईं, हजुर।
- विशेषणका पाँच भेद; *यो/त्यो* नामअघि आए विशेषण, एक्लै आए सर्वनाम।
- क्रियापद कर्मका आधारमा सकर्मक–अकर्मक–द्विकर्मक; बनोटका आधारमा सरल–संयुक्त–प्रेरणार्थक।
- क्रियापदले काल (वर्तमान, भूत, भविष्यत्), पक्ष (सामान्य, पूर्ण, अपूर्ण, अभ्यस्त) र भाव (विध्यर्थ, सम्भावनार्थ, इच्छार्थ, सङ्केतार्थ) जनाउँछ।

## अभ्यास

**रेखाङ्कित पदको पदवर्ग र भेद लेख्नुहोस् (१ अङ्क)**

1. **सगरमाथा** संसारकै अग्लो हिमाल हो। <span class="marks">[1]</span>
2. उसले **आफ्नो** किताब हरायो। <span class="marks">[1]</span>
3. मलाई **मिठास** मन पर्छ। <span class="marks">[1]</span>
4. बजारमा **धेरै** मानिस थिए। <span class="marks">[1]</span>
5. बालक **हाँस्यो**। <span class="marks">[1]</span>
6. **कोही** पनि आएनन्। <span class="marks">[1]</span>
7. गुरुले विद्यार्थीलाई प्रमाणपत्र **दिनुभयो**। <span class="marks">[1]</span>

::: note उत्तर
**१.** नाम, व्यक्तिवाचक — एउटै निश्चित हिमालको नाम।
**२.** सर्वनाम, निजवाचक — कर्ता आफैँतिर फर्कन्छ।
**३.** नाम, भाववाचक — छुन नसकिने गुण जनाउँछ।
**४.** विशेषण, परिमाणवाचक — "कति मानिस?" को जवाफ।
**५.** क्रियापद, अकर्मक — "के हाँस्यो?" को जवाफ आउँदैन।
**६.** सर्वनाम, अनिश्चयवाचक — निश्चित व्यक्ति जनाउँदैन।
**७.** क्रियापद, द्विकर्मक — विद्यार्थी र प्रमाणपत्र दुई कर्म छन्।
:::

**निर्देशन अनुसार परिवर्तन गर्नुहोस् (१ अङ्क)**

8. *छोरा* — स्त्रीलिङ्ग बनाउनुहोस्। <span class="marks">[1]</span>
9. *लेखक* — स्त्रीलिङ्ग बनाउनुहोस्। <span class="marks">[1]</span>
10. *विद्यार्थी आयो* — आदरार्थी बनाउनुहोस्। <span class="marks">[1]</span>
11. *ऊ पढ्छ* — भूतकालमा लेख्नुहोस्। <span class="marks">[1]</span>
12. *ऊ पढ्छ* — अपूर्ण पक्षमा लेख्नुहोस्। <span class="marks">[1]</span>
13. *ठुलो* — उत्तम अवस्थामा लेख्नुहोस्। <span class="marks">[1]</span>

::: note उत्तर
**८.** छोरी — *-आ* हटेर *-ई* लाग्छ।
**९.** लेखिका — संस्कृत मूलको शब्द भएकाले *-इका* लाग्छ।
**१०.** विद्यार्थी आउनुभयो — *-नुभयो* आदरार्थी क्रियारूप हो।
**११.** ऊ पढ्यो — *-छ* हटेर भूतकालको *-यो* लाग्छ।
**१२.** ऊ पढिरहेको छ — *-इरहेको छ* ले काम चलिरहेको जनाउँछ।
**१३.** सबैभन्दा ठुलो — उत्तम अवस्थामा *सबैभन्दा* जोडिन्छ।
:::

**शुद्ध गरी लेख्नुहोस् (१ अङ्क)**

14. तपाईं कहाँ गयौ? <span class="marks">[1]</span>
15. राम्रो केटी गाउँदै छिन्। <span class="marks">[1]</span>
16. ऊ भात खायो। <span class="marks">[1]</span>
17. हामी सबै विद्यार्थीहरूहरू आयौँ। <span class="marks">[1]</span>

::: note उत्तर
**१४.** तपाईं कहाँ जानुभयो? — *तपाईं* आदरार्थी भएकाले क्रियापद पनि आदरार्थी हुनुपर्छ।
**१५.** राम्री केटी गाउँदै छिन्। — स्त्रीलिङ्ग विशेष्यसँग विशेषण पनि स्त्रीलिङ्ग।
**१६.** उसले भात खायो। — सकर्मक क्रियापदको भूतकालमा कर्तामा *ले* अनिवार्य।
**१७.** हामी सबै विद्यार्थी आयौँ। — *सबै* ले नै बहुवचन जनाइसक्यो, *-हरू* दोहोरिनु हुँदैन।
:::

**खाली ठाउँ भर्नुहोस् (१ अङ्क)**

18. नाम, सर्वनाम, विशेषण र क्रियापदलाई सँगै ………… पदवर्ग भनिन्छ। <span class="marks">[1]</span>
19. क्रियापदको मूल रूपलाई ………… भनिन्छ। <span class="marks">[1]</span>
20. *यो* पद नामको अगाडि आयो भने ………… हुन्छ। <span class="marks">[1]</span>

::: note उत्तर
**१८.** विकारी — यी रूप फेर्छन्।
**१९.** धातु — जस्तै *गर्नु* को धातु *गर्*।
**२०.** विशेषण — एक्लै आए सर्वनाम हुन्थ्यो।
:::

**छोटो उत्तर दिनुहोस् (३ अङ्क)**

21. नामका पाँच भेद उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
22. सकर्मक, अकर्मक र द्विकर्मक क्रियापद छुट्याउने उपाय उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
23. काल र पक्षबिचको भिन्नता उदाहरणसहित स्पष्ट पार्नुहोस्। <span class="marks">[3]</span>
24. विशेषण र सर्वनामको भेद छुट्याउने आधार उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>

::: note उत्तर
**२१.** व्यक्तिवाचक (कोशी), जातिवाचक (नदी), समूहवाचक (सेना), द्रव्यवाचक (पानी), भाववाचक (स्वतन्त्रता)।
**२२.** क्रियापदपछि "के?" सोध्नुहोस् — जवाफ आए सकर्मक (*भात खायो*), नआए अकर्मक (*बच्चा हाँस्यो*), दुई जवाफ आए द्विकर्मक (*गुरुले विद्यार्थीलाई किताब दिनुभयो*)।
**२३.** कालले काम **कहिले** भयो भन्छ (गर्छ, गर्‍यो, गर्नेछ); पक्षले त्यो काम **कति सकियो** भन्छ (पढ्छ = सामान्य, पढेको छ = पूर्ण, पढिरहेको छ = अपूर्ण)। एउटै भूतकालमा पनि पूर्ण र अपूर्ण दुवै पक्ष हुन सक्छन्।
**२४.** नाम वा सर्वनामको अगाडि आएर त्यसको विशेषता बताए विशेषण (*यो घर ठुलो छ*); नामको सट्टामा एक्लै आए सर्वनाम (*यो मेरो हो*)। अर्थात् आधार पदको स्थान र काम हो, रूप होइन।
:::
