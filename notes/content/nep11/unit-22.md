यो एकाइमा शब्दनिर्माणको चौथो प्रक्रिया **द्वित्व** र वर्णस्तरको जोडाइ **सन्धि** — दुवै पढिन्छन्। द्वित्वमा एउटै शब्द दोहोरिएर नयाँ अर्थ दिन्छ (*घरघर*, *बिस्तारै-बिस्तारै*), भने सन्धिमा दुई वर्ण जोडिएर ध्वनि नै फेरिन्छ (*विद्या + आलय = विद्यालय*)। परीक्षामा सन्धि-विच्छेद र सन्धि जोड्ने दुवै किसिमका प्रश्न आउँछन्; द्वित्व प्रायः पहिचान र अर्थका रूपमा सोधिन्छ।

::: definition द्वित्व र सन्धि
एउटै शब्द वा त्यसको मिल्दो रूप दोहोर्‍याएर नयाँ शब्द बनाउने प्रक्रिया **द्वित्व** हो। दुई वर्ण नजिक आउँदा हुने ध्वनि-परिवर्तनलाई **सन्धि**, र जोडिएको शब्द फुकाउनुलाई **सन्धि-विच्छेद** भनिन्छ।
:::

## 22.3 स्वर सन्धि

दुई स्वर नजिक आउँदा हुने परिवर्तन स्वर सन्धि हो। यसका पाँच भेद छन्।

| भेद | नियम | उदाहरण |
|---|---|---|
| **दीर्घ** | अ/आ + अ/आ = आ | हिम + आलय = हिमालय; विद्या + आलय = विद्यालय |
| | इ/ई + इ/ई = ई | कवि + इन्द्र = कवीन्द्र; गिरि + ईश = गिरीश |
| | उ/ऊ + उ/ऊ = ऊ | गुरु + उपदेश = गुरूपदेश; भानु + उदय = भानूदय |
| **गुण** | अ/आ + इ/ई = ए | देव + इन्द्र = देवेन्द्र; गण + ईश = गणेश |
| | अ/आ + उ/ऊ = ओ | सूर्य + उदय = सूर्योदय; महा + उत्सव = महोत्सव |
| | अ/आ + ऋ = अर् | देव + ऋषि = देवर्षि; महा + ऋषि = महर्षि |
| **वृद्धि** | अ/आ + ए/ऐ = ऐ | एक + एक = एकैक; मत + ऐक्य = मतैक्य |
| | अ/आ + ओ/औ = औ | वन + ओषधि = वनौषधि; महा + औषध = महौषध |
| **यण्** | इ/ई + असमान स्वर = य् | अति + अन्त = अत्यन्त; प्रति + एक = प्रत्येक; इति + आदि = इत्यादि |
| | उ/ऊ + असमान स्वर = व् | सु + आगत = स्वागत; अनु + एषण = अन्वेषण |
| | ऋ + असमान स्वर = र् | पितृ + आदेश = पित्रादेश |
| **अयादि** | ए + अ = अय् | ने + अन = नयन; शे + अन = शयन |
| | ऐ + अ = आय् | नै + अक = नायक; गै + अक = गायक |
| | ओ + अ = अव् | पो + अन = पवन; भो + अन = भवन |
| | औ + अ = आव् | पौ + अक = पावक; भौ + उक = भावुक |

::: memory पाँच स्वर सन्धि छिटो सम्झने
**दी-गु-वृ-य-अ** — दीर्घ (उस्तै स्वर मिल्दा), गुण (अ + इ/उ), वृद्धि (अ + ए/ओ), यण् (इ/उ + फरक स्वर, स्वर व्यञ्जन बन्छ), अयादि (ए/ओ + स्वर, अय्/अव् बन्छ)। पहिलो प्रश्न सधैँ — "पहिलो स्वर के, दोस्रो स्वर के?"
:::

## 22.4 व्यञ्जन सन्धि

व्यञ्जनपछि अर्को वर्ण आउँदा हुने परिवर्तन व्यञ्जन सन्धि हो।

| नियम | उदाहरण |
|---|---|
| त् + च = च्च | सत् + चरित्र = सच्चरित्र |
| त् + छ / श = च्छ | उत् + छेद = उच्छेद; उत् + श्वास = उच्छ्वास |
| त् + ज = ज्ज | सत् + जन = सज्जन |
| त् + ल = ल्ल | उत् + लेख = उल्लेख; तत् + लीन = तल्लीन |
| त् + न = न्न | उत् + नति = उन्नति |
| त् + म = न्म | तत् + मय = तन्मय |
| त् + ह = द्ध | उत् + हार = उद्धार |
| म् + क-वर्ग = ङ् | सम् + कल्प = सङ्कल्प |
| म् + च-वर्ग = ञ् | सम् + चय = सञ्चय |
| म् + त-वर्ग = न् | सम् + तोष = सन्तोष |
| म् + प-वर्ग = म् | सम् + पूर्ण = सम्पूर्ण |
| स् → ष् (षत्व) | नि + सिद्ध = निषिद्ध; अभि + सेक = अभिषेक |
| न् → ण् (णत्व) | परि + नाम = परिणाम; प्र + मान = प्रमाण |

## 22.5 विसर्ग सन्धि

विसर्ग (ः) पछि अर्को वर्ण आउँदा हुने परिवर्तन विसर्ग सन्धि हो।

| नियम | उदाहरण |
|---|---|
| ः + च / छ = श् | निः + चय = निश्चय; दुः + चरित्र = दुश्चरित्र |
| ः + त / थ = स् | निः + तेज = निस्तेज; नमः + ते = नमस्ते |
| ः + क / प = ष् | निः + फल = निष्फल; दुः + कर = दुष्कर |
| ः + स्वर वा सघोष व्यञ्जन = र् | निः + आश = निराश; दुः + जन = दुर्जन; निः + धन = निर्धन |
| अः + सघोष = ओ | मनः + रथ = मनोरथ; तपः + बल = तपोबल; यशः + दा = यशोदा |
| ः + स = ः यथावत् | दुः + साहस = दुःसाहस; अन्तः + करण = अन्तःकरण |

::: example सन्धि-विच्छेद चरणबद्ध
**प्रश्न.** *सूर्योदय* को सन्धि-विच्छेद गरी भेद तोक्नुहोस्।

**समाधान.**
१. **जोडिएको ठाउँ खोज्ने.** शब्दको बिचमा *यो* छ — यहीँ जोड भएको हो।
२. **कुन ध्वनि बन्यो हेर्ने.** *ओ* बनेको छ।
३. **नियम सम्झने.** *अ/आ + उ/ऊ = ओ* — यो गुण सन्धि हो।
४. **फुकाउने.** ओ लाई *अ + उ* मा फर्काउने: सूर्य् + अ + उ + दय।
५. **उत्तर.** सूर्योदय = **सूर्य + उदय**, गुण स्वर सन्धि।

**जाँच.** फेरि जोडेर हेर्नुहोस् — सूर्य + उदय → *य* पछिको *अ* र *उ* मिलेर *ओ* भयो → सूर्योदय। मिल्यो।
:::

::: example उस्तै देखिने, फरक भेद
**प्रश्न.** *हिमालय*, *देवेन्द्र*, *मतैक्य*, *अत्यन्त* — चारैको विच्छेद गरी भेद छुट्याउनुहोस्।

**समाधान.**

| शब्द | विच्छेद | मिलेका स्वर | भेद |
|---|---|---|---|
| हिमालय | हिम + आलय | अ + आ = आ | दीर्घ |
| देवेन्द्र | देव + इन्द्र | अ + इ = ए | गुण |
| मतैक्य | मत + ऐक्य | अ + ऐ = ऐ | वृद्धि |
| अत्यन्त | अति + अन्त | इ + अ = य् | यण् |

**निष्कर्ष.** पहिलो स्वर र दोस्रो स्वर कुन-कुन हुन् — यही दुई कुरा थाहा पाए भेद आफैँ निस्कन्छ।
:::

::: example द्वित्व पहिचान
**प्रश्न.** *गाउँगाउँ*, *उल्टोपुल्टो*, *झिलिमिली*, *आमाबुबा* — कुन-कुन द्वित्व हुन्? कुन होइन?

**समाधान.**
१. *गाउँगाउँ* — उही शब्द जस्ताको तस्तै दोहोरियो → **पूर्ण द्वित्व**, अर्थ "हरेक गाउँ"।
२. *उल्टोपुल्टो* — *उल्टो* दोहोरिँदा *उ* को ठाउँमा *पु* भयो → **आंशिक द्वित्व**।
३. *झिलिमिली* — कुनै स्वतन्त्र शब्दको दोहोरो होइन, दृश्यको नक्कल हो → **अनुकरणात्मक द्वित्व**।
४. *आमाबुबा* — यहाँ *आमा* र *बुबा* दुई फरक शब्द छन्, दोहोरो होइन → **द्वित्व होइन, द्वन्द्व समास हो**।

**जाँचको सूत्र.** दुई पद फरक अर्थका स्वतन्त्र शब्द भए समास; एउटै शब्द वा त्यसको मिल्दो रूप दोहोरिए द्वित्व।
:::

::: caution विद्यार्थीले गर्ने वास्तविक गल्ती
- **सन्धि र समास साट्ने।** *हिमालय* सन्धि हो (वर्ण जोडियो), *राजकुमार* समास हो (शब्द जोडियो)। फुकाउने नाम पनि फरक — सन्धि-विच्छेद र विग्रह।
- **द्वित्व र द्वन्द्व समास साट्ने।** *घरघर* द्वित्व, *घरबार* र *आमाबुबा* द्वन्द्व समास।
- **विच्छेदमा गलत स्वर फर्काउने।** *सूर्योदय = सूर्य + ओदय* होइन; *ओ* लाई *अ + उ* मा फर्काएर *सूर्य + उदय* लेख्नुपर्छ।
- **यण् र अयादि उल्टाउने।** पहिलो स्वर *इ/उ* भए यण् (अत्यन्त), पहिलो स्वर *ए/ऐ/ओ/औ* भए अयादि (नयन, नायक)।
- **विसर्गलाई सधैँ *र्* बनाउने।** *निश्चय* मा *श्*, *निष्फल* मा *ष्*, *निस्तेज* मा *स्* हुन्छ — पछिको वर्णले तय गर्छ।
- **हलन्त छुटाउने।** विच्छेदमा *उत् + नति* लेख्नुपर्छ, *उत + नति* होइन।
:::

::: tip परीक्षामा छोटोमा पूरा अङ्क
सन्धिको प्रश्नमा **दुई कुरा** लेख्नुहोस् — विच्छेद र भेदको नाम। जस्तै: *सूर्योदय = सूर्य + उदय (गुण स्वर सन्धि)।* भेद नलेखे आधा अङ्क जान्छ। लेखेपछि फेरि जोडेर जाँच्नुहोस् — जोड्दा उही शब्द बन्यो भने उत्तर पक्का ठिक छ।
:::

## पाठको सार

- द्वित्वका तीन भेद: पूर्ण (घरघर), आंशिक (उल्टोपुल्टो), अनुकरणात्मक (झिलिमिली)।
- द्वित्वले बहुत्व, प्रत्येकता, निरन्तरता, तीव्रता, अनिश्चितता र अनुकरणको अर्थ दिन्छ।
- सन्धिका तीन भेद: स्वर, व्यञ्जन, विसर्ग।
- स्वर सन्धिका पाँच उपभेद: दीर्घ, गुण, वृद्धि, यण्, अयादि।
- व्यञ्जन सन्धिमा *त्* र *म्* का परिवर्तन सबैभन्दा धेरै सोधिन्छन्।
- विसर्ग सन्धिमा पछिको वर्ण हेरेर *श्, स्, ष्, र्, ओ* मध्ये कुन हुने तय हुन्छ।
- सन्धिमा वर्ण जोडिन्छ; समासमा शब्द; द्वित्वमा एउटै शब्द दोहोरिन्छ।

::: note उत्तर
**१.** हिम + आलय — अ + आ = आ, दीर्घ स्वर सन्धि।
**२.** सूर्य + उदय — अ + उ = ओ, गुण सन्धि।
**३.** मत + ऐक्य — अ + ऐ = ऐ, वृद्धि सन्धि।
**४.** अति + अन्त — इ + अ = य्, यण् सन्धि।
**५.** नै + अक — ऐ + अ = आय्, अयादि सन्धि।
**६.** उत् + नति — *त्* को *न्* भयो, व्यञ्जन सन्धि।
**७.** सम् + चय — *म्* को *ञ्* भयो, व्यञ्जन सन्धि।
**८.** निः + चय — विसर्गको *श्* भयो, विसर्ग सन्धि।
**९.** मनः + रथ — *अः* को *ओ* भयो, विसर्ग सन्धि।
**१०.** गुरु + उपदेश — उ + उ = ऊ, दीर्घ सन्धि।
:::

17. ठाउँठाउँ <span class="marks">[1]</span>

::: note उत्तर
**१७.** पूर्ण द्वित्व — उही शब्द जस्ताको तस्तै दोहोरियो, अर्थ "धेरै ठाउँ"।
**१८.** आंशिक द्वित्व — *टे* को ठाउँमा *मे* भयो।
**१९.** अनुकरणात्मक द्वित्व — छिटो चालको नक्कल।
**२०.** पूर्ण द्वित्व — प्रत्येकता जनायो, "हरेक दिन"।

**छोटो उत्तर दिनुहोस् (३ अङ्क)**

21. द्वित्वका तीन भेद उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
22. द्वित्वले दिने कुनै चार अर्थ उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
23. स्वर सन्धिका पाँच भेद एक-एक उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
24. गुण र वृद्धि सन्धि कसरी छुट्याउने? दुई-दुई उदाहरण दिनुहोस्। <span class="marks">[3]</span>
25. यण् र अयादि सन्धिको भिन्नता उदाहरणसहित स्पष्ट पार्नुहोस्। <span class="marks">[3]</span>
26. विसर्ग सन्धिका चार नियम उदाहरणसहित लेख्नुहोस्। <span class="marks">[3]</span>
27. सन्धि, समास र द्वित्वको भिन्नता उदाहरणसहित छुट्याउनुहोस्। <span class="marks">[3]</span>
28. *म्* पछि व्यञ्जन आउँदा हुने चार परिवर्तन उदाहरणसहित देखाउनुहोस्। <span class="marks">[3]</span>

::: note उत्तर
**२१.** पूर्ण — गाउँगाउँ (उही शब्द दोहोरियो); आंशिक — हल्लाखल्ला (एक ध्वनि फेरियो); अनुकरणात्मक — टिकटिक (आवाजको नक्कल)।
**२२.** बहुत्व — ठाउँठाउँ; प्रत्येकता — दिनदिनै; निरन्तरता — बिस्तारै-बिस्तारै; अनिश्चितता — चियासिया।
**२३.** दीर्घ — हिमालय; गुण — देवेन्द्र; वृद्धि — मतैक्य; यण् — अत्यन्त; अयादि — नयन।
**२४.** गुणमा *अ/आ* सँग *इ/उ/ऋ* मिल्छ र *ए/ओ/अर्* बन्छ — देवेन्द्र, सूर्योदय। वृद्धिमा *अ/आ* सँग *ए/ऐ/ओ/औ* मिल्छ र *ऐ/औ* बन्छ — मतैक्य, महौषध। दोस्रो स्वर कस्तो छ, त्यसैले छुट्टिन्छ।
**२५.** यण्मा पहिलो स्वर *इ/उ/ऋ* हुन्छ र त्यो *य्/व्/र्* व्यञ्जन बन्छ — अत्यन्त, स्वागत। अयादिमा पहिलो स्वर *ए/ऐ/ओ/औ* हुन्छ र *अय्/आय्/अव्/आव्* बन्छ — नयन, नायक, पवन।
**२६.** ः + च = श् (निश्चय); ः + त = स् (निस्तेज); ः + प/क = ष् (निष्फल); ः + सघोष वा स्वर = र् (निराश)।
**२७.** सन्धि — वर्ण जोडिन्छ, ध्वनि फेरिन्छ (हिम + आलय = हिमालय)। समास — दुई फरक शब्द जोडिन्छन्, विभक्ति लोप हुन्छ (राजाको कुमार = राजकुमार)। द्वित्व — एउटै शब्द दोहोरिन्छ (घरघर)।
**२८.** म् + क-वर्ग = ङ् (सङ्कल्प); म् + च-वर्ग = ञ् (सञ्चय); म् + त-वर्ग = न् (सन्तोष); म् + प-वर्ग = म् (सम्पूर्ण)।
:::
