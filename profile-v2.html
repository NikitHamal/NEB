What changed, and why

Every phone above scrolls and every tab works. Tap See all on any Overview module to jump to its tab, then try My own to see the private tabs and the profile strength card.

Tabs

Posts, Replies, Resources, About for every account.
Each profile type gets its own peer tabs: Teaches, Programs, Collections, Impact. Nothing important lives behind a single catch-all.

About

Stats, achievements, details, progress and portfolio stacked in one long tab.
About is gone. Overview is a summary of every tab with a See all link, and each module opens the full tab.

Header

Name, badge, bio and counts only.
Header answers who, where and what they offer: role, school, headline, meta line, counts and one strip (Open to, Teaches, Now, Publishes).

Actions

Follow only, edit buried in a menu.
Visitor: Follow and Message (Call on a school). Owner: Edit profile and Share, plus a strength checklist that sends you to the missing tab.

Scroll

Header scrolls away, tabs jump.
The header collapses into a top bar with the avatar and name. The tab rail stays pinned and its pill slides on a spring.

Resources

Cards without a way to open them.
Every resource row and card carries a Read button, so opening a file never needs a second screen.

Rules kept

No shadowsDepth comes from surface containers and a one pixel outline variant.
No rings on picturesAvatars are clipped to one expressive shape per account: cookie, sunny, squircle, burst.
Badges vs chipsVerified and role text have no fill. Chips, counts and status labels keep tonal fills.
No gradients, no emojiCovers are flat tonal containers with a quiet shape motif. Icons are strokes.
Semantic colourEvery colour is a role: primary, secondary, tertiary and the surface ladder. Dark theme swaps the roles only.
Compose mappingHeader becomes one LazyColumn item, the rail stays NebTabRail (scrollable), each type supplies a tab spec and a list of module items.
