## Permanent Rules (Consolidated from Sessions 1 to 100)

1. **No Local Gradle Builds**: Never run `./gradlew` locally; push to `origin main` and verify via GitHub Actions CI. Keep only the latest succeeded Android build run in GitHub Actions.
2. **M3X Design System (`docs/M3X_DESIGN_SYSTEM.md`)**: Zero shadows/elevations, zero emojis, zero gradients, zero profile picture rings, no background fill on role/verification badges, finite radii only (never morph to `0px`), neutral graphite dark theme (`tokens.css` -> `sync_android_palette.py`).
3. **Press, Scroll & Sheet Guards**: Clip before clickable (`NebIndication` handles global state layers); keep >= 4dp/6dp gaps between adjacent tonal tiles; never nest same-axis scrollers (use `nebHorizontalScroll` and `boundedWidth()`); every screen with a back button needs `NebTopBar` or `statusBarsPadding()` (`check_insets.py`); every `LikePill` row uses `nebGhostRowStart()`; `NebModalSheet` pads its body by 22dp unless `fullBleed = true`.
4. **Composers & Notes**: Editable fields hold `RichState`, never raw Markdown markers; formatting changes go through `RichState`; inline images only grow their own paragraph line height and keep a 1.2em caret; note block look (`align`, `tint`, `mark`) goes through `NoteEditorViewModel.setLook`; `Modifier.noteBackdrop` stays before `verticalScroll`.
5. **CSS Bundles**: Edit source modules under `backend_python/web/static/web/css/m3x/` and run `python3 tools/css/bundle.py` (checked in CI by `--check`).
6. **Pathways Dataset (`docs/PATHWAYS_SCHEMA.md`)**: Every figure must come from a named source; when sources disagree, state both in the note; never use em/en dashes (`\u2014`, `\u2013`, `--`) or emojis in Pathways JSON; run `pathways.problems()` and tests before pushing; never hand-edit generated wave files (`wave9.json`, `wave10.json`, `wave13.json`–`wave16.json`, `visa.json`)—edit their builder scripts under `backend_python/tools/pathways/` or add a new wave file.
