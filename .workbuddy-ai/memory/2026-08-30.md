# 2026-08-30

## Optimised the biology + AI 3D simulations (interactive section)

### Where the code actually lives
The "3D simulations" are **not** in the Android app. They are server-side three.js r160
pages under `backend_python/web/static/web/js/interactive/`, served to a remote WebView at
`https://nebians.consica.com.np/interactive/{course}/{lesson}/`. **Editing `app/` does
nothing.** Changes need `manage.py collectstatic` (venv python at `backend_python/.venv`)
to reach `staticfiles/`, but no app update.

### In-scope sims (catalog-registered 3D, from `web/interactive/catalog_*.py`)
- `biology/neb-bio3d` -> the 43-kind system in `core/bio3d-*.js`
- `biology/human-body`, `biology/photosynthesis`, `biology/butterfly-life-cycle`,
  `biology/heart-lungs` (standalone three.js, NOT part of the bio3d system)
- `ai/network-3d`, `ai/neuron`
- The other 6 AI lessons (`perceptron`, `how-ml-learns`, `image-classifier`, `llm-intro`,
  `ethics`, `what-is-ai`) are Canvas 2D, not 3D.
- `biology/flower-dissection|onion-mitosis|leaf-stomata|food-test` are in zero catalog
  entries - dead code.

### Verification harness (gitignored): `backend_python/scratch/sim3d_verify/`
- `bash sync.sh [base]` copies the live tree to `./mod`; `base` restores every file from
  git HEAD so before/after is apples-to-apples. Also builds a `node_modules/three` shim for
  the bare `three` / `three/addons/` importmap specifiers.
- `bash check.sh` - `node --check` over all 135 modules.
- `run.mjs` - all 43 bio3d kinds: draw calls, triangles, build ms, heap leak probe.
- `run-ai.mjs`, `run-bio.mjs` - build + 240 frames + drive every control + dispose.
- `test-pick.mjs`, `test-glb.mjs` - merge/pick correctness incl. an 826-mesh replica.
- Draco-compressed GLBs cannot be decoded under Node (Emscripten in `vm` fails); test with
  synthetic replicas instead.

### Bugs found and fixed along the way
- `ai/ethics.js` had a stray `)` - the **entire module failed to parse** in production.
- `core/bio3d-batch.js` merge double-transformed shared geometries (clone-on-reuse ran after
  the original was already mutated in place). Now pre-scans for shared geometry.
- `applyOrganicDisplacement` cloned geometry without disposing the original - leaked on
  every rebuild.
- `makeLabelSprite` read the canvas 2D context before setting width/height, so the resize
  reset font/fillStyle.
- `photosynthesis.js` cloned the chloroplast material 35x, so the rate-driven glow animated
  a material nothing rendered.
- `heart-lungs.js` cartilage rings were welded to the scene while the trachea bobbed.

### Key design rule learned
Batch **per anatomical/stage group, never across them** - anything merged across two groups
whose visibility or transform is driven separately can never hide or move independently.
Anything animated per-frame (stomata pores, heart/lung organ meshes, wing pivots) must be
tagged `userData.noBatch` first.
